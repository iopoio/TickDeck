## 덱 카피 적용 규칙 (에이전트 명령형 · 10개)

1. **모든 슬라이드 카피는 명사형으로 끝내라.** 종결은 `~전망 / ~예정 / ~예상 / ~부상 / ~확대 / ~필요 / ~가능 / ~중` 계열. 서술형 "~한다." 종결은 본문 전체 0회 실측 — 쓰지 마라.
2. **"습니다"체는 표지·인사말·법적 고지에만.** 본문 슬라이드에서 경어체 금지.
3. **헤드라인은 명사구 한 줄.** 두 형식만: ⓐ `주제 — 핵심 결론 명사구` (KPMG) ⓑ `주제, ~는?` 질문형 (PwC). 동사로 끝나는 헤드라인 금지.
4. **슬라이드 구조 = 리드 요약(2~3문장) → 불릿.** 리드는 그 장 전체를 요약하는 60~100자 문장 2~3개, 불릿은 그 상세.
5. **불릿은 명사(주어)로 시작·명사형으로 종결·마침표 없음.** 하위 불릿은 `또한 / 더불어 / 특히 / 다만 / 이에 따라`로 이어라. 위계는 2단(■→•)까지만.
6. **숫자에는 3종 세트: 시점 + 완충어 + 출처.** `'26년 2분기`처럼 시점 박고, 추정치엔 "약 ~여 개" "~수준" 완충, 슬라이드 하단에 `자료: 기관명 (발간시점)` 병기. 출처 없는 숫자 금지.
7. **단정 수위는 근거 등급으로 정하라(헤지 사다리).** 확정 사실=단정(수상·개최·기록) / 공식 발표 기반=`~할 예정·계획` / 자체 분석=`~할 전망` / 추정=`~할 것으로 예상·보임·관측` / 열린 이슈=`~가능성·귀추가 주목`. 근거 등급보다 세게 말하지 마라.
8. **판단을 세게 걸고 싶으면 제3자에 위임하라.** "Gartner 등은 ~ 필요하다고 분석" 패턴. 자체 워딩으로 "혁명적·게임체인저" 금지 — 4개 문서 통틀어 자체 서술 0회.
9. **은유 마무리 금지.** "여정·항해·지도를 그린다" 류는 본문 0회 실측 (유일한 "여정" 1회 = CEO 인사말). 마무리는 항상 `시사점 → 기업이 할 일(명사형 체크포인트)`로 끝내라.
10. **이모지·느낌표·굵은 강조 남발 금지.** 본문 0회 실측. 강조는 색·배치(디자인)의 일이지 문장 부호의 일이 아니다.

## 축별 실측 근거

### 1. 헤드라인 화법

**명사형·서술어 생략이 기본.** 문장 정보를 다 담아도 끝은 명사.

- "CES 2026 개요 — 혁신 생태계 플랫폼으로서의 CES 역할 부각" (KPMG CES p.4)
- "160여개 국가 참가, 한국 기업수 전년도 기록(1천개) 경신 여부 주목" (KPMG CES p.5)
- "핵심 전략으로서 카브아웃의 구조적 부상" (KPMG M&A p.8)

**PwC 변형 = 질문형.** 명사구 + "~는?" (서술어 생략형 질문):

- "CES가 제시하는 AI 기술 트렌드는?" (PwC p.15)
- "CES 2026, 선도 기업이 제시할 혁신은?" (PwC p.16)

**기호**: 콜론(:)으로 부제 연결 — "CES의 어제와 오늘: 핵심 기술 트렌드 변화" (PwC p.11). 차트 제목에 콜론+따옴표 결론 — "유형별 피지컬 AI 글로벌 시장 보급 전망: '휴머노이드 로보틱스' 적용 성장세가 압도적" (PwC p.22). KPMG는 키워드 라벨 + `▶` 꺾쇠 — "(1) 피지컬 AI ▶ 로보틱스 결합을 통한 산업·일상 속 AI 적용 범위의 확대" (KPMG CES p.12). 길이 = 대체로 20~35자.

### 2. 본문 종결

**명사형 종결 분포 (실측 카운트)**

| 종결 | PwC CES (58p) | KPMG CES (58p) |
|---|---|---|
| ~전망 | 23 | 24 |
| ~예정 | 22 | 47 |
| ~예상 | 10 | (것으로 예상 6) |
| ~한다. (서술형) | **0** | **0** |
| ~습니다 (본문) | 0 (인사말만 10) | 0 (법적 고지만 2) |

- "AI 필두의 신기술 부상 속 혁신의 중요성을 강조. 기존의 틀을 깨고 변화와 창조를 이루어 나가는 혁신가로서의 기업인이 강조되며 (…) 글로벌 기업의 신기술·신제품 대거 등장 예정" (KPMG CES p.4) — 문장 중간도 마침표 후 명사 종결로 끊는다.
- "2026년에는 제품을 넘어 도시와 사무실 등 다양한 공간까지 하나의 지능형 네트워크로 연결되는 방향으로 진화할 전망" (PwC p.11)
- KPMG M&A는 개조식 음슴체 혼용: "구조적 가치 창출 수단으로 자리 잡고 있음" "가치 창출이 가능한 거래를 우선시하는 것으로 나타남" (KPMG M&A p.2·6)

**리듬**: 리드 요약 = 60~100자 장문 2~3개 → 불릿 = 30~60자 → 하위 불릿 = 짧게. 긴 문장은 리드에만 허용.

### 3. 숫자 인용 문법

- 완충어 "약 + ~여": "약 4,500여 개" "약 14만 명 예상" (PwC p.6) / "전망치는 92,883,766대로 1분기 전망치 대비 약 86만 대 감소" (KPMG Auto p.3) — 정밀 수치와 "약" 요약을 한 문장에 같이 쓴다.
- 비교 기준 명시: "'AI' 분야 출품작 전년대비 29% 증가" (PwC p.14) / "폭스바겐의 친환경 자동차 판매량이 현대차그룹 대비 약 16만 대 많을 전망" (KPMG Auto p.13)
- 연도 축약: `'25.Q2 → '26.Q2`, "'26.1.5 월요일" (KPMG). 차트엔 지표명 직접: "CAGR 60.7%" (PwC p.22)
- 단위는 괄호로 분리: "(단위: 대)" "(천 대)"
- **출처 병기 = 매 슬라이드 하단 의무.** PwC 39개 슬라이드 전수 "자료:" 표기 — "자료: CTA, 언론 종합, 삼일PwC경영연구원". KPMG는 "Source: Global Data (2026.03)" — 기관 + 발간 시점. 재가공 시 "재구성" 명시: "Source: CTA, 삼정KPMG 경제연구원 재구성" (KPMG CES p.4)
- 용어 정의는 번호 각주: "1) 인공지능을 구현하기 위한 계층 구조로 (…)" (PwC p.15)
- 설문 그래프엔 주의 각주까지: "(*) 원문의 그래프 표기 방식에 따라 합계가 100이 아님에 유의" (KPMG M&A p.3)

### 4. 불릿 위계

- 위계 2단이 상한: PwC = `■`(리드) → `•`(상세). KPMG = 리드 단락 → `ㆍ` → `-`.
- 불릿 시작 품사 = 명사(기업명·기술명·주제어). 마침표 없음.
- 하위 불릿은 연결부사로 리듬: "이 로봇은 mmWave 레이더 기반 SLAM을 적용해 (…) 스스로 탐색 가능 / **또한** 모듈이 연소 중인 물질을 실시간으로 분류하여 (…) / **더불어** 폐루프 비전-액추에이션 시스템이 (…) 인력 개입 없이 화재를 제압" (KPMG CES p.47)
- 표 안 텍스트는 `• 개요 문장 / - 세부` 2단을 표 셀 안에서도 유지 (PwC p.10 수상기업 성과 표).

### 5. 판단·전망 표현 (헤지 사다리)

실측된 수위, 강한 것부터:

| 수위 | 표현 | 실측 예문 |
|---|---|---|
| 단정 (확정 사실) | ~수상·개최·기록 | "CES 2026 인간안보 부문 최고혁신상 수상" (KPMG CES p.47) |
| 공식 발표 기반 | ~할 예정·계획 | "AMD의 비전을 소개할 예정" (KPMG CES p.7) |
| 자체 분석 | ~할 전망 | "산업과 생활 전반에 깊은 변화를 촉발할 전망" (PwC p.42) |
| 추정 | ~것으로 예상·보임·관측 | "두산로보틱스는 (…) 차세대 솔루션을 선보일 것으로 보임" (KPMG CES p.5) / "거래를 우선순위에 둘 것으로 관측" (KPMG M&A p.3) |
| 열린 이슈 | ~가능성 / 귀추가 주목 | "CES 2026에서 기록을 경신할지 귀추가 주목" (KPMG CES p.5) |
| 제언 | ~필요 / ~해야 함 | "초개인화, 감성 중심 경험 구현 등을 핵심으로 하는 전략 재정의 필요" (PwC p.43) / "전담 거버넌스와 체계적인 분할 모델을 갖춰야 함" (KPMG M&A p.11) |

- 센 판단은 제3자 인용으로: "Gartner 등은 이러한 완전 자율형 구현까지 최소 5~10년 이상의 기술 성숙 기간이 필요하다고 분석" (PwC p.22)
- 대비 구문으로 판단 구조화: "과감함보다는 철저한 절제(Discipline)를, 일회성 성과보다는 재현 가능성(Repeatability)을" (KPMG M&A p.11) — A보다 B 병렬이 결론 문체의 전형.

### 6. 금지 패턴 (역추출 — 4개 문서에 안 나오는 것)

| LLM 버릇 | 실측 |
|---|---|
| 은유 마무리 ("지도를 그린다"·"여정"·"항해") | **본문 0회.** "여정" 유일 1회 = PwC CEO 인사말 ("여러분의 혁신 여정에 든든한 길라잡이"). "지도를 작성" 1회는 SLAM 기술의 문자 그대로 설명. "항해" 0회 |
| "혁명적"·"게임체인저" | 자체 서술 **0회**. "혁명" 유일 1회 = CTA 세션명 인용 ("다가오는 기술 혁명" — 고유명사 표기) |
| 자기참조 "이 보고서는~" | 범위·기준 고지에만 한정: "본 보고서는 CES 2026의 핵심 테마인 AI, 로보틱스 (…) 를 중심으로 작성" (PwC p.13). 자화자찬형 자기참조 0회 |
| 이모지 | 본문 **0회** |
| 느낌표 | 본문 **0회** |
| 경어체 본문 | 0회 (인사말·법적 고지 제외) |

**의외 실측**: 삼일PwC "비밀 노트" 3페이지는 이모지·굵은 강조·"좋은 질문이야!"를 일부러 쓰는데, 매 페이지 하단에 "*본 자료는 AI 말투를 활용한 컨셉으로, 삼일PwC 경영연구원이 각색하였습니다" 각주를 박아 본문과 격리한다. 즉 업계 스스로 LLM 말투를 '본문에 못 쓰는 별도 톤'으로 분류하고 있다는 실측 증거.

### 7. KPMG vs PwC 차이 (참고 1줄씩)

- KPMG = 더 건조. 리드 3줄 요약 → 불릿, 개조식 음슴체(~있음·~나타남) 혼용, "~예정" 빈도 최다(47회).
- PwC = 질문형 헤드라인·영어 슬로건 병기("AI, Everything")·스토리 프레임("Tech Touch") 등 내러티브 장치가 더 많음. 공통 문법(명사 종결·출처 병기·헤지 사다리)은 동일.
