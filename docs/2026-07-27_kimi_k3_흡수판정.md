## ❌ 기각 (우리가 이미 같거나 더 강함)

- 출처 A~D 등급 → 우리 Tier+DWS+순환인용 코드 검출이 상위 호환
- 반대 근거 의무·역신호 박스 → opposing_views_required + counter_signal 100% 이미 강제
- 수치 소스 시트 역추적 → metric_registry + C6(모델이 숫자 못 씀) + 3b 전수 팩트체크가 상위 호환
- 상태 변화 서술 → C3 계약으로 이미 강제 (K3는 관례, 우리는 계약)
- 강조 1회·비교군 회색·시스템 폰트·페이지당 한 주장 → 기존 규칙과 동일
- 레이아웃 4종 고정 → 우리는 PATTERN_LIBRARY + 변주 장부(매 런 다른 시스템)가 목적상 우위
- 수집 15건 상한 → 우리는 상한 대신 verifier 게이트 (코퍼스 두꺼운 게 강점)

## 유보 (취향 충돌)

- K3 "파이 차트 금지" vs 우리 donut 지원 — 각도 비교 부정확 논거는 타당하나 donut은 단일 비율 강조용으로 유지. 계열 3+ 비율엔 이미 누적막대 권장.
