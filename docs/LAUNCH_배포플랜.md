# 배포 플랜 — 4주 검증용

> 원칙: 채널도 실험 대상이다. 3개만 돌리고, 결제가 나온 채널에 몰아준다.
> 모든 신청서의 "어디서 보셨나요" 답 = 채널 성적표의 원천 데이터.

## 채널 3개 (이것만)

| 채널 | 역할 | 비용 |
|---|---|---|
| 스레드 (본진) | 콘텐츠 쌓기 + 오퍼. viral-hooks·anti-ai 세팅 완료 | 시간만 |
| 디스콰이엇 | 메이커/창업자 대상 런칭 공지 + 제작기 | 시간만 |
| 오픈카톡 1~2개 (예창패·공모전 준비방) | 마감 급한 사람 직격. 광고 금지방 주의 — 후기·정보글로 진입 | 시간만 |

유료 광고는 4주 안에는 없음. 오가닉으로 결제가 1건도 안 나오면 광고 태워도 안 나온다.

## 콘텐츠 4종 (스레드 기준)

1. **비포/애프터** — 무료 3건 산출물. 가장 강한 탄약, 주 2회
2. **제작기** — "48시간 안에 정부지원 덱이 나오는 과정" build in public, 주 1회
3. **팁글** — "심사위원은 3번 장표에서 떨어뜨린다" 류 신뢰 구축, 주 1회
4. **오퍼(모집 공지)** — 주 1회만. 오퍼만 반복하면 계정이 광고판 됨

비율 = 정보·과정 3 : 오퍼 1. 실제 글 쓸 때 viral-hooks로 훅 3개 뽑고 anti-ai 돌려서 발행.

## 주간 캐던스 (2026-07-20 시작 · 판정 08-14 · 평일 가동, 주말 = 휴식 또는 보충)

납기 표기는 항상 **영업일 기준 48시간** — 목·금 접수 건이 주말을 침범하지 않게.

**준비 — 7/20(월)~7/21(화)**
- 스레드 프로필 한 줄 정비: "영업일 48시간 완성 · 마음에 안 들면 전액 환불"
- 신청서 Tally/구글폼 이전 + 유입 경로 필수 질문 확인
- 오픈카톡 예창패/공모전 방 2개 찾아서 입장 (눈팅으로 온도 파악)

**1주차 — 무료 3건 모집 + 과정 공개 — 7/22(수)~7/28(화, 평일만)**
- 7/22(수): 스레드 모집 글 ("정가 30만 덱, 첫 3팀은 후기 조건 무료") + 디스콰이엇 동시 게시
- 7/22~7/28: 접수 즉시 제작 착수 (건당 영업일 48h), 진행 과정 제작기 2편 (고객 정보 익명)
- 목표: 7/28(화)까지 3건 완료 + 후기 3개 확보
- 오픈카톡은 이번 주 글 안 씀 — 관찰만

**2주차 — 후기 3연발 + 유료 오픈 — 7/29(수)~8/3(월)**
- 7/29(수)~7/31(금): 후기·비포/애프터 하루 1개씩 3연발
- 8/3(월): 유료 오픈 공지 (정가 30만 + 이유 불문 환불) 스레드 + 디스콰이엇
- 오픈카톡: 팁글 형태로 첫 진입 (오퍼 아님)

**3~4주차 — 반복 + 집중 — 8/3(월)~8/14(금)**

- 8/7(금) 중간점검: 문의 0인 채널은 끊고 나머지에 2배 투입
- 오픈카톡에서 반응 오면 그때 오퍼 (방 규칙 안에서)

**측정·판정일**

- **8/14(금) 밤 = 게이트 판정**: 유료 5건 & 환불 ≤1 → 계속 / 미달 → 널 분기

## 직접 영업 (조용한 병행 트랙)

- 스레드·디스콰이엇에서 "예창패 준비 중" "덱 막막" 쓴 사람 검색 → 정중한 답글/DM, 주 5명 한도
- 템플릿: 공감 1줄 + "이런 걸 하고 있다" 1줄 + 링크. 세일즈 문장 금지
- 초기엔 이 트랙에서 결제가 먼저 나올 확률이 높음 (콘텐츠는 쌓이는 데 시간 걸림)

## 측정 (일요일 밤 10분)

주 1회 기록: 채널별 게시 수 / 문의 수 / 결제 수
- 문의 0 채널 → 3주차에 컷
- 문의 있는데 결제 0 → 채널이 아니라 오퍼(가격·문구) 문제로 해석
- 4주 말: 채널 성적표가 게이트 판정 자료에 포함
