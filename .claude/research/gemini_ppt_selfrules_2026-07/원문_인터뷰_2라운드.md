## 라운드 1

### 설계 순서
- 전체 분량·구조 확정 → 5개 대주제(PART) 도출·총 22p 분배 (2p 목차)
- 슬라이드별 핵심 메시지 추출 → 장별 최중요 데이터 1~2개 선별 후 최상단 헤드라인으로 압축 (4p "전망과 실측은 다르다 — 노출 80%, 심층 사용 4%")
- 템플릿 마스터 → 하단 푸터 공통 요소 선배치 (전 페이지 "2026 Peppinch All rights reserved")

### 페이지 레이아웃
- 헤드라인 = 상단 여백 15% 위치·좌측 정렬·최대 2줄 (8p)
- 페이지당 독립 정보 덩어리(Chunk) ≤3 (6p = 2개)
- 단일 핵심 지표 = 좌우/상하 여백 50%+ 비우고 중앙 단독 (8p "85%" 차트)

### 타이포 위계
- 타이틀 = 본문 2.5배(약 40pt+)·Extra Bold (1p·2p)
- Big Number = 타이틀 이상(약 48pt+)·Extra Bold·액센트색 (15p "49%"·"69%")
- 본문·표 = 14~16pt Regular (6p) / 캡션·출처 = 10pt Light·좌하단 (12p)

### 색 운용
- 배경 1 + 텍스트 1 + 액센트 1 = 총 3색 이내 (11p)
- 액센트 적용 페이지당 ≤3곳 (15p)

### 데이터/도해 선택
- 3+ 항목 비교 = 표 (6p 3열·9p 2열) / 시계열 = 선 그래프 (11p 3개년)
- 2시점 비포애프터 = 2단 분할 + 화살표 브릿지 (15p 49%→69%)
- 단일 수치 압도 = 반원 게이지 (8p 85%)

### 페이지 리듬
- PART 전환 = 본문 배제·타이틀만·시각 밀도 10% 이하 (4·6·9·13·17p)
- 데이터 연속 직후 = 텍스트 불릿 요약 페이지로 완급 (17p 후 19·20p)

### 금지
- 미사여구·감정 수식어·산문 서술 금지 — 단문/명사형 종결 (20p)
- 데이터 없는 장식 클립아트·배경 패턴·3D 아이콘 전면 배제 (전 페이지)
- 차트가 보여주는 수치를 본문에 재서술 금지 — 본문은 차트에 없는 외부 맥락만 (15p)

### 재현 명세 (슬라이드당 JSON 4변수)
- slide_layout_type: title/toc/metric_highlight/data_table/summary_list 택1
- header_insight_text: 2줄 이내 결과 해석형 헤드라인
- data_payload: Key-Value 어레이 / footer_references: 출처 문자열 어레이

### 자가지적 (실제 못 지킨 것)
1. 16p — 덩어리 ≤3 붕괴: 상이한 데이터 블록 6개+ 한 페이지에 구겨넣음
2. 21p — 출처 중복: 각 페이지 좌하단 표기했는데 21p에 20개+ 출처 몰아넣기 재발
3. 17p — 산문 침입: 에이전틱 AI 사전풀이형 긴 산문으로 단문 리듬 붕괴
