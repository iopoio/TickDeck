# 발표 덱 설계 규칙

## 설계 순서

1. 청중·발표 시간·결정 과제가 없으면 → 제작 전에 각각 1문장으로 고정한다.
2. 발표 시간이 정해지면 → 총 슬라이드를 `발표 분 ÷ 1.0~1.5`장으로 제한한다.
3. 핵심 결론이 2개 이상이면 → 우선순위 1개를 메인 결론으로 정하고 나머지는 근거로 내린다.
4. 메인 결론이 정해지면 → `상황 → 긴장 → 선택 → 근거 → 행동`의 5막으로 배열한다.
5. 각 페이지를 설계하면 → 제목만 이어 읽어도 전체 논리가 성립하도록 제목을 결론형 문장으로 쓴다.

## 페이지 레이아웃

6. 16:9 화면용이면 → 캔버스를 960×540px로 두고 안전 여백을 좌우 6.25%(60px), 상하 7.4%(40px) 이상 둔다.
7. 정렬 기준이 필요하면 → 12열 그리드와 20px 거터를 사용하고 모든 요소 시작선을 열에 맞춘다.
8. 한 페이지에 요소가 많아지면 → 제목·본문·차트·주석을 포함한 주요 요소를 7개 이하로 줄인다.
9. 정보 블록이 2개 이상이면 → 가장 중요한 블록이 면적의 55~70%를 차지하게 한다.
10. 텍스트와 시각 자료가 함께 있으면 → 4:8, 5:7, 6:6 중 하나의 열 비율로 분리하고 임의 비율을 쓰지 않는다.

## 타이포 위계

11. 표지 제목이면 → 48~60px, 700~800 굵기, 행간 1.05~1.15를 사용한다.
12. 본문 페이지 제목이면 → 30~36px, 700~800 굵기, 최대 2줄로 제한한다.
13. 핵심 수치이면 → 44~72px, 800 굵기로 본문보다 최소 2.5배 크게 쓴다.
14. 본문이면 → 18~22px, 400~600 굵기, 행간 1.4~1.6을 사용하고 한 줄을 34자 이하로 제한한다.
15. 캡션·축·출처이면 → 11~14px를 사용하되 11px 미만은 금지하고 본문 대비 명도 차를 25% 이상 확보한다.

## 색 운용

16. 팔레트를 정하면 → 배경·잉크·주색·강조색의 4색 이내로 제한한다.
17. 색 면적을 배분하면 → 배경 60~70%, 잉크·중립 20~30%, 주색 8~15%, 강조색 3~5%로 둔다.
18. 강조할 항목이 생기면 → 한 페이지에서 강조색을 의미 1개에만 사용한다.
19. 텍스트를 배경 위에 놓으면 → 일반 텍스트 4.5:1, 큰 텍스트 3:1 이상의 대비를 확보한다.
20. 상태나 범주를 색으로 구분하면 → 색 외에 라벨·패턴·위치 중 1개를 함께 사용한다.

## 데이터·도해 선택 기준

21. 정확한 값 비교가 목적이면 → 표를 사용하고 비교 열은 5개 이하로 제한한다.
22. 항목 간 크기 비교가 목적이면 → 0 기준선의 가로 막대차트를 사용하고 항목은 7개 이하로 제한한다.
23. 시간 변화가 목적이면 → 선차트를 사용하고 계열은 3개 이하, 시점은 12개 이하로 제한한다.
24. 전체 대비 비중이 목적이면 → 5개 이하 범주의 100% 누적 막대 또는 도넛을 사용하고 합계 100%를 표시한다.
25. 순서·흐름·관계가 목적이면 → 단계 6개 이하의 화살표·타임라인·2×2 매트릭스 중 가장 단순한 도해를 선택한다.

## 페이지 리듬

26. 연속 3페이지가 같은 구성이면 → 다음 페이지의 레이아웃 축·배경 명도·시각화 유형 중 1개를 바꾼다.
27. 정보 밀도가 높은 페이지가 나오면 → 전후 1페이지 중 하나를 핵심 문장 또는 단일 수치 페이지로 비운다.
28. 섹션이 바뀌면 → 배경색 전환 또는 48px 이상의 섹션 번호로 경계를 만든다.
29. 발표가 8페이지 이상이면 → 3~4페이지마다 현재 위치를 알려 주는 진행 표시를 둔다.
30. 마지막 결론 페이지이면 → 새 근거를 추가하지 않고 결론 1개와 행동 1개만 남긴다.

## 하지 않는 것

31. 문장이 2줄을 넘으면 → 축약하거나 다음 페이지로 분리하고 글자 크기를 줄여 끼워 넣지 않는다.
32. 장식이 판단을 돕지 않으면 → 그라디언트·글로·유리 효과·3D 그림자·장식 아이콘을 제거한다.
33. 같은 크기 카드가 4개 이상 반복되면 → 중요도에 따라 크기를 달리하거나 표·차트로 통합한다.
34. 제목·본문·차트가 모두 중앙 정렬이면 → 핵심 문장 외 정보 블록을 좌측 정렬로 바꾼다.
35. 차트에 범례가 필요하면 → 범례 대신 데이터 근처에 직접 라벨을 붙이고 범례 왕복 시선을 없앤다.

## 재현 명세

36. 덱을 전달하면 → 캔버스·그리드·여백·색상 HEX·폰트·크기·굵기를 파일 안에 명시한다.
37. 반복 요소가 있으면 → 제목 위치·페이지 번호·진행 표시·카드 반경을 공통 토큰으로 정의한다.
38. 차트를 만들면 → 데이터 값·최댓값·스케일·정렬 기준을 코드 또는 주석으로 남긴다.
39. 화면과 인쇄를 함께 쓰면 → 16:9 화면 규격과 `@media print` 페이지 분리 규칙을 함께 제공한다.
40. 최종 파일을 넘기기 전이면 → 960×540 기준 오버플로·11px 미만 글자·누락 페이지·규칙 매핑을 자동 또는 수동 검사한다.
