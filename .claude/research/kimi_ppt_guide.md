# [Kimi 조사 원문] AI로 더 쉽고 멋진 PPT 만드는 실전 프롬프트 & 워크플로우 가이드

## 핵심 원칙: 5가지 프롬프트 법칙
대부분의 사람들이 AI PPT 도구를 자판기처럼 사용 — "피치덱 만들어줘" 입력 후 기대만. 상위 10% 품질은 크리에이티브 브리프 수준의 프롬프트에서 나옴.

- 원칙 1: 콘텐츠보다 청중 먼저 명시. ❌ "Q3 실적 덱" / ✅ "보드 5명(3명 전 운영자, 2명 재무) 대상 12슬라이드 업데이트 — 런웨이 연장과 고객 유지 강조"
- 원칙 2: 구조를 먼저 제약. AI는 과잉 생성. 슬라이드 수(8,12,15), 섹션 제목, 한 슬라이드=한 아이디어 규칙 지정.
- 원칙 3: 정확한 출력 형식 지정. ✅ "슬라이드 4를: 6단어 헤드라인, 20단어 서브헤딩, 8~12단어 불릿 3개, 차트 추천 1개"
- 원칙 4: 숫자가 중요할 때 소스 자료 제공. AI는 그럴듯한 통계를 지어냄. "아래 숫자만 사용: [데이터]. 주어지지 않은 시장 통계는 추가하지 마세요"
- 원칙 5: 중요한 덱은 슬라이드별로 반복 생성. "15슬라이드 생성" vs "슬라이드 7만 구체적으로 생성" — 품질 차이 3배. 전체 워크플로우에서 가장 큰 레버.

## 15개 복사용 프롬프트 템플릿 (요약)
[영업/마케팅] 엔터프라이즈 세일즈 피치 / 제품 런칭 / 마케팅 캠페인 제안
[투자/보드] 시드 피치덱(Guy Kawasaki 10슬라이드) / 시리즈 A / 보드 업데이트(분기)
[내부/기술] 올핸즈 / 엔지니어링 아키텍처 리뷰 / QBR
[전략/분석] 시장 진입 분석 / 경쟁사 분석 / 전략 오프사이트
[교육/사고리더십] 신입 교육 / 컨퍼런스 키노트 / 웨비나
공통: "각 슬라이드: 6단어 헤드라인, 10단어 불릿 3개" 식의 형식 지정 반복.

## 3가지 피해야 할 실패 패턴
- 패턴1: 원라인 프롬프트 → 평균적 제네릭 덱.
- 패턴2: 키친싱크 프롬프트(800단어 비구조화, 상반된 청중/톤, 40개 불릿) → 밀도 높고 초점 없음.
- 해결책: "Audience:", "Structure:", "Source material:", "Tone:", "Output format:" 헤딩으로 정리. 소스 제외 300단어 내외.

## 피치덱 고급 기법
- 기법1 Kawasaki 제약: "정확히 Guy Kawasaki 10슬라이드 구조. 슬라이드 추가 금지."
- 기법2 숫자-우선: 트랙션 지표를 프롬프트 최상단에. "AI가 초기 입력에 더 높은 가중치를 두므로 전체 덱이 숫자 중심."
- 기법3 적대적 투자자 재작성: "톱티어 VC 파트너 관점에서 재작성. 논리가 약한 부분은?"

## 보드 덱 기법
- KPI 테이블 선행 / 리스크 슬라이드 요청 / 운영·전략 분리.

## 기술 프레젠테이션 기법
- 청중 기술 수준 정밀 지정 / 문제-진술-우선 구조(1슬라이드 30초 이해) / 추천 대신 트레이드오프 매트릭스(3옵션x5기준).

## 프롬프트 엔지니어링 10원칙 (모든 모델 공통)
구체성 / 구분자(--- 또는 """) / 생각할 시간(단계별 추론) / 소스 인용(환각 방지) / 전문용어 회피 / 목표 설정 / 시나리오 생성 / 분석 장려 / 시간 프레이밍 / 형식 명확화.
추가: 반복 지시(시작·끝, recency bias) / 출력 프라이밍("\n- "로 끝내기) / Few-shot 1~3개 / 작업 분해 / 대안 경로("못 찾으면 'not found'").
