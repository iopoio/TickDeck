# 시각화 결정 로직 (SoT) — 콘텐츠를 어떤 그림으로

> 신야 2차 흡수. 핵심 출처 = Gene Zelazny "맥킨지, 차트의 기술"(차트 선택의 정설·경영대학원 교재) + 데이터 시각화 실무.
> 원칙: 차트는 예술이 아니라 *메시지 전달 도구*. **데이터가 아니라 메시지(보고 싶은 스토리)가 그림을 정한다.**

## 0. 비주얼을 넣을까 — 추가 게이트 (매번 X · 후추님 명시)
비주얼은 의무가 아니라 *벌어야 한다*. 그 슬라이드에 넣어서 **설득력이나 이해가 실제로 올라갈 때만** 넣는다. 안 오르면(장식) 또는 오히려 헷갈리게 하면 빼고 여백·텍스트로. "매 슬라이드 차트" 금지.
- 이해 ↓ 예: 왜지금(3힘) 슬라이드에 5트렌드 그림 = 혼란 → **제거**. So-What에 서로 다른 단위 5막대 = 무의미 → **제거**.
- 이해 ↑ 예: 격차 = dumbbell · 전·후 변화 = before/after · 추상 이동 = 흐름 도식 → **유지**.
- 게이트 통과 후에만 아래 "어떤 그림"을 고른다.

## 1. 메시지 → 비교 유형 → 차트 (Zelazny)
먼저 메시지가 *어떤 비교*인지 정하고 그에 맞는 차트를 고른다:

| 메시지(비교 유형) | 차트 |
|---|---|
| 구성 (부분/전체) | 파이·누적막대 (조각 2~4개·8+ 금지) |
| 항목 비교·순위 | 막대(가로/세로) |
| 시간 추이 | 선(꺾은선) |
| 도수 분포 | 히스토그램 |
| 상관관계 | 산점도 |
| 흐름·단계 | 플로우·산키·깔때기(funnel) |
| 전·후 변화 | before/after |
| 단일 충격 수치 | 큰 숫자 하나 |

## 2. 차트가 제목(주장)을 증명한다
헤드라인(action title) → 시각화(그걸 증명) → 컨텍스트. 3계층. *제목만 봐도, 차트만 봐도 같은 메시지*가 와야 한다.

## 3. 추상 개념 → 도식·은유
"신뢰의 이동"·"토대가 동시에 움직인다" 같은 추상은 글이 아니라 개념 다이어그램·시각 상징(은유 이미지)으로. (Zelazny 개념 비주얼)

## 4. 위계·여백 (강조/힘빼기)
data-ink 비율(군더더기 제거)·여백 넉넉·헤드라인 크게·색 절제·차트당 3~4줄.

## 5. 흔한 실수
파이 6+ 조각 · 연속 시계열에 막대 · 한 화면에 다 담기.

### B. 수치 → 그래프 (이야기 *방향*이 가른다)
절대값·최초 = **빅넘버** / 과거→현재 = **before-after** / 기준 대비 격차("대비"·"우위") = **점도표·dumbbell**(막대보다 객관적) / 전체 중 비중 = **스택막대**.

> ★ **구성비(부분/전체) = 비례 막대·100%누적·gap_map. dumbbell·shift·before_after 금지.** A%+B%가 합쳐 100 근처(예: 기술 93 : 사람 7)면 두 점 격차 차트(dumbbell/shift)는 *길이가 같은 노드 두 개*라 비율이 안 보인다 — 막대 길이가 곧 수치인 비례 막대(gap_map)를 써야 93이 7보다 약 13배 길게 박힌다. **dumbbell은 같은 척도 위 서로 다른 두 *대상*의 격차일 때만**(예: 소비자 83% vs 임원 38%·가치 인식 74% vs ROI 달성 24%). **before_after는 시간 전·후일 때만**(같은 지표의 과거→현재). 구성비를 before_after로 쓰지 않는다. (2026-06-30 후추님 p13 재발 지적 — 영구 SoT.)

> ★★ **funnel·연속 시각(깔때기·단계 막대)은 동일 코호트·동일 출처일 때만.** 같은 사람들이 단계마다 줄어드는 게 *실측*일 때만 깔때기로 그린다. 표본·출처가 다른 단계를 깔때기로 이으면(예: KPMG 설문 88% → CB 성숙도 54% → Deloitte 운영 11%) 독자가 *같은 코호트의 연속 전환율*로 오독한다 — 실제로는 서로 다른 세 경계 신호다. 이때는 **독립 카드(stat_grid) 3개로 분리하고 각 수치 옆에 표본·출처를 붙인다**. note의 "출처가 달라 절대 비교 아님" 단서를 시각으로 끌어올리는 것. (2026-06-30 후추님 p04 funnel 오독 지적 — 영구 SoT.)

주제마다 표지·색·모서리·배경·타이포를 **새로 추론**한다. 틱덱 기본(에디토리얼·펜톤)은 골격으로 두되 *주제 모티프를 그 위에 얹는다*(배경 패턴·구분선·모서리·포인트색·은유 도형).

|---|---|---|---|---|

### D. 변주 축 — 같은 주제도 매번 다르게
- **흔들 것(안전):** 핵심 은유 선택(노드 vs 회로 vs 레이어 vs 신호)·색 온도·정렬 방식·여백 밀도

### E. 다양성과 일관성 = "문법 고정 · 어휘 가변"
레이아웃(어휘)은 페이지마다·주제마다 다르게. 그리드·타이포·색비율(문법)은 절대 고정. → 다양하되 한 덱 안에서 일관. **designer는 매 페이지 A의 신호를 읽어 어휘를 고르고, 매 덱 C로 주제 양식을 새로 짠다.**

### F. 핵심 질문 → 시각 어휘 (MiniMax 흡수 — 페이지·주제가 *무엇을 묻나*)
A(동사 신호)와 함께 쓰는 보완 렌즈. 그 페이지가 던지는 질문이 어휘를 가른다:
| 핵심 질문 | 시각 어휘 |
|---|---|
| 무엇이 변하나 | 화살표·시간축·before/after |
| 어떻게 작동하나 | 다이어그램·레이어·노드 |
| 무엇을 해야 하나 | 체크리스트·단계·번호 |
| 어디에 있나(현황) | 지도·매트릭스·분포 |
| 왜 중요한가 | 빅넘버·대비·강조 |

### G. 수치 결정 트리 (MiniMax)
혼자 말하나 / 비교 필요? → 비교축(시간=before-after·라인 / 대상=가로막대·표 / 구성=누적·도넛 / 분포=점도표) → 변화 크기가 메시지면 빅넘버+보조차트 → 맥락 필요하면 차트+콜아웃, 아니면 숫자만.

1. **카테고리 묶음 + 선언형 트렌드 제목 [구성/스토리 — 즉시 적용]** — 트렌드가 6+개로 많으면 단일 선형 아크 대신 **도메인 카테고리(기업·산업·금융 등)로 묶고**, 각 트렌드 제목은 선언형 주장(action title) 한 문장. 카테고리명은 본문 슬라이드 eyebrow를 **강조 칩**(배경색 칩)으로. 제목만 죽 읽어도 카테고리별로 스토리가 흐른다. (단일 3막 아크 vs 카테고리 묶음 — 트렌드 수·청중에 따라 designer가 택)
2. **강조 박스 주석 (accent-box) [focal 강화]** — 차트에서 핵심 1~3개 항목을 *회색 처리 외에/대신* **액센트 윤곽 박스로 묶어** 시선을 박는다(CB p10: 상위 3 KPI를 퍼플 박스). 그레이아웃(전원 회색+1액센트)과 함께 쓰는 더 강한 focal. 현 막대 차트의 highlight 색칠을 **윤곽 박스로 확장**하면 즉시 가능. [현 렌더 부분 지원 — 색칠은 됨, 윤곽 박스는 렌더 소폭 확장]
3. **미니라벨 + 히어로 비주얼 [구성 — 즉시 적용]** — 차트 옆 설명을 *문단*으로 길게 쓰지 말고, 왼쪽에 **작은 라벨(무엇을 보여주나) + 설문 질문(italic)** 만 두고 차트를 화면 대부분으로 크게. 좌텍스트+우비주얼의 정제형: 텍스트는 미니라벨, 비주얼이 히어로.
4. **보이스 카드 (정성 증거) [렌더 확장 후보]** — 실무자 인용을 보여줄 땐 큰 라운드 카드 2장 대조(좌/우) + 출처(직책·회사 규모) + **핵심 구절만 마커 하이라이트**. 설문·인터뷰의 '목소리'를 한 장으로. (현재 quote-card 렌더 미지원 → 쓰려면 렌더 확장.)
5. **기업 스포트라이트 + 마켓맵 [렌더 확장 후보 — CB Insights 특기]** — "누가 만드나"를 보여줄 땐 포지셔닝 매트릭스(2축)에 기업 로고 배치 + **한 곳을 액센트로 스포트라이트(원/하이라이트)** + 옆에 딥다이브 카드(투자단계·금액·핵심 한 줄). 비상장·스타트업 신호(CB Insights 데이터)를 시각화하는 가장 강한 형식. (현재 미지원 → 렌더 확장 시.)
6. **단일 강한 액센트 [디자인 게이트]** — CB는 브랜드색 하나를 과감히(간지 풀블리드·강조 박스·막대 2톤). 우리 톤다운 기조와 어디까지 과감할지는 후추님 디자인 게이트. 권고로만.

> 흡수 우선순위: 1·3은 designer가 지금 바로 적용(구성·구도). 2는 렌더 소폭 확장. 4·5는 렌더 확장 후보(별도 task — 정성 증거·기업 신호가 많은 리포트에 큰 값). 6은 게이트.
