# 시각화 결정 로직 (SoT) — 콘텐츠를 어떤 그림으로

> 신야 2차 흡수. 핵심 출처 = Gene Zelazny "맥킨지, 차트의 기술"(차트 선택의 정설·경영대학원 교재) + 데이터 시각화 실무.
> 원칙: 차트는 예술이 아니라 *메시지 전달 도구*. **데이터가 아니라 메시지(보고 싶은 스토리)가 그림을 정한다.**

## 0. 비주얼을 넣을까 — 추가 게이트 (매번 X · 후추님 명시)
비주얼은 의무가 아니라 *벌어야 한다*. 그 슬라이드에 넣어서 **설득력이나 이해가 실제로 올라갈 때만** 넣는다. 안 오르면(장식) 또는 오히려 헷갈리게 하면 빼고 여백·텍스트로. "매 슬라이드 차트" 금지.
- 이해 ↓ 예: 왜지금(3힘) 슬라이드에 5트렌드 그림 = 혼란 → **제거**. So-What에 서로 다른 단위 5막대 = 무의미 → **제거**.
- 이해 ↑ 예: 격차 = dumbbell · 전·후 변화 = before/after · 추상 이동 = 흐름 도식 → **유지**.
- 게이트 통과 후에만 아래 "어떤 그림"을 고른다.

## 1. 메시지 → 비교 유형 → 차트 (Zelazny)
먼저 메시지가 *어떤 비교*인지 정하고 그에 맞는 차트를 고른다:

| 메시지(비교 유형) | 차트 |
|---|---|
| 구성 (부분/전체) | 파이·누적막대 (조각 2~4개·8+ 금지) |
| 항목 비교·순위 | 막대(가로/세로) |
| 시간 추이 | 선(꺾은선) |
| 도수 분포 | 히스토그램 |
| 상관관계 | 산점도 |
| 흐름·단계 | 플로우·산키·깔때기(funnel) |
| 전·후 변화 | before/after |
| 단일 충격 수치 | 큰 숫자 하나 |

## 2. 차트가 제목(주장)을 증명한다
헤드라인(action title) → 시각화(그걸 증명) → 컨텍스트. 3계층. *제목만 봐도, 차트만 봐도 같은 메시지*가 와야 한다.

## 3. 추상 개념 → 도식·은유
"신뢰의 이동"·"토대가 동시에 움직인다" 같은 추상은 글이 아니라 개념 다이어그램·시각 상징(은유 이미지)으로. (Zelazny 개념 비주얼)

## 4. 위계·여백 (강조/힘빼기)
data-ink 비율(군더더기 제거)·여백 넉넉·헤드라인 크게·색 절제·차트당 3~4줄.

## 5. 흔한 실수
파이 6+ 조각 · 연속 시계열에 막대 · 한 화면에 다 담기.

## 우리 덱 적용 (placeholder → 실제 비주얼 후보)
- 검색 클릭률 15%→8%·인용 1% = **before/after 막대**(전·후 변화)
- 영상 디지털 60% 돌파 = **임계선 넘는 선/누적**(구성+추이)
- AI 예산 15.3% vs 확장 준비 30% = **막대 대비**(항목)
- 신뢰 격차 소비자 83% vs 임원 38%(45%p) = **dumbbell/막대 대비**
- 광고비 전망 $979B~$1,390B = **range/dot plot**(분산)
- "토대 동시 이동"(추상) = **5 토대 화살표 개념도**(은유)
- "신뢰 이동"(추상) = **paid → 가까운 출처 흐름 도식**
