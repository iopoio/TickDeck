# 덱 팔레트 (SoT)

> 원칙(`feedback_deck_palette_pantone`): 톤다운 기본 · 파랑 일변도 X · 네온/원색 X · 세련됨은 타이포+여백+구성으로.
> **후추님 선호: 전체적으로 다크보다 라이트.** 배경은 흰색/오프화이트 기본.
> 색은 장식이 아니라 *의미 코딩* — 상단 라인·번호·강조에만, 배경은 흰색 유지.
> **이 파일은 고정 정답이 아니라 *자라는 팔레트 라이브러리*다.** 한 세트로 단정하지 말고, 덱을 만들면서 잘 맞은 조합·새 축색·새 테마를 계속 더해 확장한다.

---

## 현재 기본 (시작점 · 고정 아님) — 펜톤 톤다운(라이트) + 트렌드(축)별 의미색

2026 마케팅 트렌드 보고서용. codex 주제-적응 리뷰 + 중국 AI(GLM) awwwards 미니멀 베이스를 합친 것. *지금의 1순위일 뿐*, 덱마다 내용·컨셉에 맞춰 조정·확장한다.

- **배경:** `#FFFFFF` / 오프화이트 `#F7F8FA`
- **잉크(본문):** `#1F2733` (차분한 다크 슬레이트) · **muted:** `#6B7384`
- **라인:** `rgba(31,39,51,.12)`
- **트렌드(축)별 보조색** (제목 상단 라인·번호·강조):
  | 축 | 색 | 톤 |
  |---|---|---|
  | T1 발견·구매 | `#8A6F3D` | 뮤트 골드 |
  | T2 신뢰·진정성 | `#A8664F` | 톤다운 러스트 |
  | T3 AI 정산 | `#5A6F92` | 슬레이트 블루 |
  | T4 데이터·규제 | `#6D856D` | 뮤트 세이지 |
  | T5 관계·개인화 | `#7A5F73` | 뮤트 플럼 |
- **의미 코딩:** 위험·손실 강조 = 러스트(`#A8664F`/짙게 `#74422F`) · 긍정·도입 = 블루(`#5A6F92`). 같은 차트라도 의미 다르면 색 다르게.

## 참고 소스 (모음)

### ★ 드리블 인기 프레젠테이션 트렌드 (2026-07-02 · 인기순 상위 15샷 시각 분석)
> 소스: `dribbble.com/search/presentation` (인기순). **갱신 방법**: 직접 fetch는 AWS WAF에 막힘 → `curl -s "https://r.jina.ai/https://dribbble.com/search/presentation"`으로 목록 확보 → `cdn.dribbble.com/userupload/...` 이미지를 `?resize=760x570` 붙여 받아 눈으로 분석. **분기 1회 재수집 권장**(트렌드 소스는 썩는다).

**컬러 — awwwards 미니멀(무채+1포인트)과의 델타 = "한 색을 더 과감하게":**
- **모노브랜드 램프**가 지배적: 덱 전체 = 브랜드색 1 + 동일 색상의 틴트 3~4단. 무채 베이스가 아니라 *브랜드색이 베이스*.
- **컬러 블록 리듬**: 덱 중간에 배경 전체를 accent로 채운 풀블리드 장(전환·펀치라인·감사)을 4~6장마다 박음 — 다크 북엔드의 컬러 버전.
- **동일계열 그라디언트 귀환**: 오렌지→레드, 바이올렛 글로우, 라디얼 블루. 단 한 색상 family 안에서만(무지개 금지 동일).
- **웜 뉴트럴 캔버스**: 순백 대신 아이보리/웜그레이(`#F4F1EA`류) + 오프블랙(`#141414`).
- 관측 팔레트 세트(자주 보인 조합):
  | 세트 | 베이스 | 액센트 | 보조 |
  |---|---|---|---|
  | 딥그린×라임 (agri·프로덕티비티) | 아이보리 `#F4F3EE` | 딥그린 `#1E4033` | 라임 `#A6C34C`·세이지 |
  | 딥네이비 모노 (핀테크) | 화이트 | 네이비 `#1B2A6B` | 네이비 틴트램프만 |
  | 바이올렛 (AI·SaaS) | 쿨화이트 | 바이올렛 `#8B5CF6` | 라벤더 틴트·다크와 병용 |
  | 오렌지레드 그라디언트 (커뮤니티·미션) | 오프블랙+화이트 | `#FF4D00→#E63B12` | 웜아이보리 |
  | 크림+파스텔 벤토 (피치덱) | 크림 | 오프블랙 타이포 | 파스텔 핑크·옐로·라임 카드 |
- **다크 덱 부활**: 오프블랙/딥그린/딥네이비 본문 + 네온 포인트(시안·바이올렛) — 단 우리 기본은 라이트(후추님 게이트), 다크는 명시 요청 시.
- ⚠️ 긴장: 후추님 "톤다운" 기조와 트렌드의 "과감한 1색"이 충돌 — 절충 = *본문은 톤다운 유지, 컬러 블록 전환장에서만 과감*. 채택 폭은 후추님 디자인 게이트.

**렌더 반영**: `forest`(딥그린×라임·아이보리)·`violet`(바이올렛×라벤더) 테마를 render_deck.py PALETTES에 추가(7/2). 타이포·레이아웃 델타는 visualization.md "드리블 흡수" 항목.

## 적용 규칙
1. 배경은 흰/오프화이트 (라이트). 다크 배경은 후추님 명시 시에만.
2. 색은 상단 라인·번호·강조·차트에만. 본문 텍스트는 잉크.
3. 한 덱에 원색·네온 0. 톤다운 안에서만.
4. 색이 의미를 나르게 (축·위험/긍정). 의미 없는 색칠 금지.
5. 변경·신규 팔레트는 이 파일에 추가. 고정하지 말고 *확장*한다.

## 확장 후보·이력

> 덱을 만들면서 잘 맞은 조합·새 축색·새 테마를 여기 누적. 형식: 날짜 — 덱/주제 — 쓴 팔레트 — 잘된 점/조정.

- **2026-06-29 — 2026 마케팅 트렌드 덱 — 펜톤 톤다운 라이트 + 트렌드별 의미색**(T1 골드 `#8A6F3D`·T2 러스트 `#A8664F`·T3 슬레이트블루 `#5A6F92`·T4 세이지 `#6D856D`·T5 플럼 `#7A5F73`).
  - 잘됨: 라이트·세련됨 · 축별 색이 *의미*로 읽힘 · 고스트 페이지번호 · 흰 배경에 색 절제 OK.
  - 조정: 과밀 슬라이드(T1)에서 하단 각주가 본문과 겹침(렌더 spacing 문제) → 각주는 본문 아래로 흐르게 + 과밀 슬라이드는 분리/압축.
