# 격식 실무체 참조 (formal-voice · 2026-07-23 신설)

> 용도 = **제안서·공모전·외부 제출 덱의 표면 문구** 전용 어휘·문체 참조. 블로그·SNS 개인 말투는 `Think/outputs/marketing/_foundation/voice_profile.md`가 정본 — 두 레지스터 혼용 금지.
> 근거 = 후추님 아카이브 실납품·소장 제안서 텍스트 실추출(1차): 롯데푸드 홈페이지 제안(넥스트컬쳐 2021)·현대차 신차 설명회 운영 제안(GMS 2019)·환전지갑 하나멤버스(eWIDEPLUS 2018) + HWA 복구본 8종 열람(미스미·대출왕 등). 구조 문법(거버닝 메시지·표 장인)은 `author-style.md`가 정본 — 본 파일은 **어휘·종결·문형만**.
> 우선순위: `writing-standard.md`(금지어·수치 규율)와 충돌 시 writing-standard 우선.

## 1. 이원 종결 구조 (핵심)

한 페이지 안에서 종결이 두 층으로 갈린다:

- **리드/거버닝 1문장 = "~합니다" 경어 서술형** — 페이지의 결론을 먼저 말한다.
  - "쉽고 간편한 환전지갑 서비스를 구축하는 것을 제안의 목표로 합니다"
  - "안전을 최우선으로 하여 체험자의 만족을 극대화합니다"
  - "적합한 세팅 및 도열을 진행합니다"
- **불릿·표·라벨 = 명사형 종결(개조식)** — 서술어를 한자어 명사로 닫는다.
  - "반응형 웹 도입" · "전문인력 투입" · "개발 업무 시행착오 최소화" · "컨텐츠 볼륨 강화"
  - 상태 서술은 음/함 종결: "내용은 많으나 직관적이지 않고 복잡함" · "모바일 대응이 되지 않아 사용성이 좋지 않음"
- 조건·유보 각주는 "~함/~됨" 문어체: "추후 협의를 통해 조정 가능함" · "장소 섭외가 가능한 일정에 맞춰 변경되었으며"

## 2. 어휘 서랍 (실측 빈출)

| 갈래 | 어휘 |
|---|---|
| 압축 동사(명사형) | 구축·구현·수립·투입·도입·확보·강화·증대·제고·최소화·극대화·명세화·세분화·간소화·활성화·고도화 |
| 접미 캐논 | ~방안(수행/관리/이행/해결) · ~체계(협업/의사소통) · ~전략 · ~계획 · ~현황 · ~실적 · ~범위 |
| 수단 구문 | "~을 통한/통해" ("협의를 통해 조정 가능함" · "컨텐츠 형식을 통한") |
| 병렬 | "및" ("제안배경 및 목적" · "품질보증 및 위험관리방안") — 와/과보다 및 |
| 판정 형용 | 차별화된 · 체계적인 · 최적의 · 책임감 있는 · 안정적인 |

## 3. RFP 응답 목차 캐논 (관용 순서)

제안 개요(배경·목적→범위→추진 전략→기대효과) → 수행 방안 → 관리 방안(일정·조직·보안·품질·산출물) → 지원 방안(교육·유지보수) → 제안업체 현황 → 견적. 발주처가 이 순서로 채점하므로 임의 재배열하지 않는다.

## 4. 주의 (따라하지 않을 것)

- 원문 오탈자는 관습이 아니다: "재고"(→제고)·"통회조회"(→통화조회) 류는 교정해서 쓴다.
- 이 문체는 **읽는 사람이 발주사·심사위원일 때만**. 펩핀치 블로그·X에 이 레지스터가 새면 AI투/공문서투로 읽힌다 (역방향 오염 금지).
- 개조식이라도 수치·근거 규율(writing-standard C6)은 그대로 — 격식이 검증을 대체하지 않는다.
