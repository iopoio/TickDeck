## 1. 브랜드 헌정 — 덱은 클라이언트의 옷을 입는다 [재량]
제안·납품 덱의 팔레트·로고·모티프는 **제안사가 아니라 받는 쪽(클라이언트) CI**다. 아우디 덱=아우디 링·레드·산세, 롯데 덱=롯데 레드·블랙. 러닝 헤더에 프로젝트명을 상시 표기해 "이 문서는 당신 것"이라는 신호를 매 장 반복.
→ v4 적용: theme/palette를 수신자 브랜드로 잡는다(peppinch 테마가 이 원리의 사례). 간지·표지 모티프도 클라이언트 도메인에서 추론.

## 2. 거버닝 메시지 — 제목 아래 지배 문장 한 줄 [엔진]
거의 모든 본문 페이지가 `제목(명사구) → 거버닝 메시지(서술형 한 문장·핵심어만 강조색) → 본문` 3층. 예: "교육 운영의 **효율성**과 행사 **비용의 절감**" / "QR코드를 활용한 **온라인 교육 만족도 조사** 진행".
- 제목 = 짧은 명사구, 거버닝 = "~합니다/~한다" 서술형으로 페이지의 결론을 먼저 말한다.
- 강조는 **문장 전체가 아니라 핵심어 1~2개만** 액센트색.
→ v4 대응: `headline` 블록 + `==키워드==` 색전환(7/2 흡수)이 정확히 이 문법. designer는 본문 페이지마다 거버닝 한 줄을 기본으로 둔다.

## 3. 표 장인 — 비교·평가는 표로, 판정은 색으로 [확장·일부 엔진]
후추님 덱의 주력 무기는 차트보다 **판정이 인코딩된 표**다:
- **전수 비교 히트맵 표** (아우디 교육장 분석 16곳): 후보 전부 나열 × 평가축(위치·일정·비용…) 셀을 명도 막대로 채우고, **선택한 행만 액센트색**. "다 검토했고, 그래서 이것"이 한 장에 박힌다. → 백로그 Phase 2 `heatmap_matrix`의 실물 원형. [확장]
- **비용/스펙 대칭 비교표** (장소 A vs B, 전경 사진 + 항목행 + 합계행 진하게): 2안 비교의 표준형. [확장 — 비교 매트릭스 표]
- **마지막 열 = 시사점 컬럼** (롯데 유사업종 분석: 비고 열만 레드): 데이터 열은 중립, 판정 열만 색. [재량 — matrix/표 설계 시]
- **합계 행/열 강조** (차량 운영 계획: 합계 셀 레드): 수치 표는 반드시 합계로 닫는다. [재량]

## 4. 옵션 제시 문법 — 항상 복수 안 + 판단 근거 [재량·page-planner]
"1안/2안" · "옵션 1 파라다이스 / 옵션 2 파크로쉬" · "4조 운영(안)/3조 운영(안)". 단일 답을 던지지 않고 **복수 안 + 각 안의 장단점(회색 박스) + 권고**를 세트로 준다. 발주자에게 결정권을 주되 비교 기준을 깔아준다.
→ 제안·의사결정 장르 덱에서 action/제언 장의 기본 문법으로 쓸 것 (단정적 권고 원칙과 양립: 안은 복수, 권고는 단정).

## 5. 간지 = 무드 전환 + 하위 목차 프리뷰 [엔진 — 7/2 렌더 반영]
간지가 단순 챕터 마커가 아니라 **풀블리드 무드 비주얼 + 섹션 번호 + "이 파트에서 볼 것" 불릿 리스트**. 청중이 매 파트 시작에서 지도를 다시 받는다.
→ v4: divider에 `bullets/list` 블록을 주면 하위 목차 프리뷰로 렌더된다(divider-items).

## 6. 로테이션/편성 매트릭스 — 운영 제안의 시그니처 [확장]
그룹×시간 그리드에서 셀 명도·화살표로 로테이션을 보여주는 표(아우디 p25·p26: 3그룹 90분 로테이션, Test drive 셀만 틴트). 스케줄이 아니라 *운영 설계 능력*의 증거로 쓰인다. → 렌더 확장 후보(스케줄 그리드).

## 7. 증거는 사진 그리드, 실행력은 실물로 [확장 — 이미지 파이프라인(B단계) 이후]
포트폴리오·시설·F&B = 헤더 바 라벨 + 사진 모자이크. "잘한다"를 글이 아니라 수행 현장 사진으로 증명. 데이터/본문 슬라이드에는 사진을 안 쓰고(격 유지), 증거·시설·무드 장에만.

## 8. 작은 결정에도 게이지 [엔진]
Welcome gift 옵션마다 가격/실용성 막대, 시승 코스 체크포인트 체크박스, 드라이브 모드 레이더. 정성 판단도 눈금으로 보여준다. → v4 gap_map(짧은 축 비교)·metric 델타로 대응 가능.
