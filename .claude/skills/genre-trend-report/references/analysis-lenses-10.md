# Trend Report Analysis Lenses

Source: `tickdeck_harness/knowledge/content/00_SYNTHESIS_콘텐츠방법론.md` PART B.

Use 2~4 lenses per trend report. The goal is richer original analysis, not checklist completion.

## B1. Follow The Friction
Real trends create friction with incumbents, regulation, labor, privacy, or consumer behavior.

Run method:
- Collect recent lawsuits, strikes, boycotts, regulation, sandbox filings, and public resistance.
- Locate the highest-friction area.
- Treat friction as a signal of structural importance, not only as a risk.

## B2. Talent x Capital Gap
Media hype and durable commitment often diverge.

Run method:
- Compare a media hype index with smart money and expert talent movement.
- Hype greater than capital suggests bubble risk.
- Capital greater than hype suggests hidden alpha.

## B3. Negative Space
What disappears can reveal the future.

Run method:
- Collect failed, withdrawn, paused, or abandoned initiatives from the last two years.
- Find common failure causes.
- Translate the absence into a structural limit or reversal pattern.

## B4. Inversion
Search against the hypothesis first.

Run method:
- Write the draft hypothesis.
- Search for "not A" evidence before confirming evidence.
- Place credible rebuttals beside the main claim.

## B5. Counterfactual Slot
Every major chapter needs a failure path.

Run method:
- Ask: if this trend fails or stalls by 2026, what is the decisive reason?
- Add a short counterfactual note to each major chapter.

## B6. Inter-Language Lag
Global and local reports often move at different speeds.

Run method:
- Compare English primary sources with Korean, Japanese, or Chinese-language reports where safe and allowed.
- Measure tone or emphasis gaps.
- If variance is large, create a regional variance signal.

## B7. Adversarial Self Review
Use three critical personas.

Run method:
- Senior executive: weakest evidence.
- Competitor analyst: thesis reversal.
- Academic reviewer: method weakness.
- If two personas flag the same issue, rewrite that section.

## B8. TTA Backcast / Historical Analogue
Do not match old adoption curves mechanically.

Run method:
- Estimate current adoption velocity from investment, patents, and hiring.
- Compare velocity to a past analogue.
- Adjust time-to-adoption dynamically.

## B9. Trigger Point
A trend report should support decisions.

Run method:
- For each trend, define: when metric X reaches value Y, role Z should start action A.
- Prefer concrete owner, metric, threshold, and timing.

## B10. Tombstone Section
Optimism needs failed analogues.

Run method:
- Identify similar trends or companies that failed in the last two years.
- Extract the failure mechanism.
- Use it to bound claims and sharpen scenarios.
