## 변경 파일
`.claude/skills/deck-harness/scripts/render_deck.py` 1개 파일, 31줄 추가·7줄 삭제 (`git diff --stat`).

- `_render_source_appendix_page`(760행 부근): 섹션("제공하신 자료" seed / "추가 조사" research) 내부에서 `len(publisher+title)` 짧은순 정렬. 8행 초과 시 `main` 요소에 `appendix-2col` 클래스 부여.
- CSS(4442행 부근, 기존 `.appendix-row` 스타일 옆): `.appendix-2col .appendix-list { display:block; columns:2; column-gap:40px; }` — CSS multi-column(네이티브) 사용. grid-auto-flow 대신 선택한 이유: 행 수를 미리 계산해 `grid-template-rows`를 주입할 필요 없이, 소스 순서를 그대로 좌열 상→하 채운 뒤 우열로 자연 흐름시켜 준다(1줄로 끝남).
- **실측 중 발견한 선행 결함 2건도 같이 고침** (범위 내 root-cause라 별도 파일 안 늘고 여기서 처리):
  1. `.appendix-list`가 `display:flex`라서 `columns` 속성이 애초에 무효(스펙상 flex 컨테이너에 multicol 미적용) — `display:block`으로 되돌려야 실제 2열이 됨. 이거 안 고치면 2단 클래스가 붙어도 시각적으로는 그대로 1단.
  2. 기존 `.appendix-row{white-space:nowrap}` + `.appendix-title{text-overflow:ellipsis}` — 긴 출처(다중 출처 병기·영문 논문명)가 **행 수와 무관하게 조용히 잘려** 있었다(감사 대상인데 잘림 = 사고). nowrap/ellipsis 전면 제거, `overflow-wrap:anywhere`로 교체 — 길면 줄바꿈, 자르지 않음. `.appendix-pub`도 `flex:none`(축소 불가)이라 34자짜리 퍼블리셔명이 칼럼 폭을 밀어 가로 초과(FIT_HOVERFLOW)를 내던 것도 `flex:0 1 auto; min-width:0`으로 같이 고침.
