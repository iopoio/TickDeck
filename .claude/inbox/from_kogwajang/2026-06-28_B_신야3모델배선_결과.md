## 실호출 결과

`dig.py`는 미생성 상태라 쿼리 1개 실호출을 실행하지 못했습니다.

모델 ID를 추측하지 않기 위해 OpenRouter `/models`에서 GLM/Qwen/Kimi `:online` 지원 ID를 먼저 확인하려 했지만, 로컬 네트워크 DNS 에러가 2회 동일하게 재현됐습니다.

### 호출 1

```bash
python3 - <<'PY'
import json, urllib.request
url='https://openrouter.ai/api/v1/models'
try:
    with urllib.request.urlopen(url, timeout=20) as r:
        data=json.load(r)
    names=[]
    for m in data.get('data', []):
        mid=m.get('id','')
        low=mid.lower()
        if any(k in low for k in ('glm','qwen','kimi','moonshot')):
            names.append(mid)
    for mid in names[:120]:
        print(mid)
    print('COUNT', len(names))
except Exception as e:
    print('ERROR', type(e).__name__, str(e))
    raise SystemExit(1)
PY
```

결과:

```text
ERROR URLError <urlopen error [Errno 8] nodename nor servname provided, or not known>
```
