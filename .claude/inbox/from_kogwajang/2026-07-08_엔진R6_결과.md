## 작업별 결과

### ① render_deck.py — 텔레메트리 스니펫 삽입
- `render_deck()` 반환부에서 `_render_telemetry(deck_spec, meta)` 호출 → 결과가 빈 문자열이면 `</body>` 직전에 아무것도 안 붙음(바이트 불변), 있으면 `</body>` 직전에 삽입.
- 발동 조건: `deck_spec.meta.telemetry.ga_id` 있을 때만. `meta` 자체가 없거나 `telemetry` 키가 없으면 즉시 `""` 반환.
- `deck_id` 우선순위: `telemetry.deck_id` > `meta.run_id` > `deck_spec.run_id`(top-level) > `"unknown"`. (설계 문서 "meta의 run_id 또는 telemetry.deck_id 우선"을 반영 — 실제 deck_spec 샘플 확인 결과 run_id는 top-level에 있는 경우가 많아 폴백 체인에 포함.)
- gtag 로더(async script + dataLayer init) + 인라인 IIFE 스니펫(바닐라 JS, 외부 의존 0).
- 페이지 컨테이너 셀렉터 = `section.slide` — cover/outro/body/source_appendix 전 레이아웃이 공통으로 이 클래스+`data-page-id`를 쓰는 것을 코드에서 확인 후 사용.
- `deck_page`: IntersectionObserver(threshold 0.5)로 페이지별 누적 가시 시간(ms) 추적. `document.hidden`이 되면 누적 정지, 다시 보이면(그리고 여전히 교차 중이면) 재개. 페이지가 뷰포트를 벗어날 때 버킷 분류(3s/10s/30s/60s+) 후 3초 미만은 미전송, 이상이면 `gtag('event','deck_page', {deck_id, page_no, dwell_bucket})` 전송, 누적치 리셋.
- `deck_source_click`: `a[href^="http"]` 클릭 시 `deck_source_click` 전송, `url` 파라미터는 `new URL(url).hostname`로 도메인만.
- `deck_read_end`: `pagehide`에서 전 페이지 flush 후 `deck_read_end`를 `transport_type: 'beacon'`으로 전송(`max_page`/`total_pages`).
- ga_id/deck_id는 `json.dumps()`로 JS 문자열 리터럴 이스케이프(수기 이스케이프 대신 stdlib 재사용).
