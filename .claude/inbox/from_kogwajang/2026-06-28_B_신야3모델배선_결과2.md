## 모델 교체법

구현 가능 상태가 되면 `dig.py` 상단에 아래처럼 두는 방식이 가장 단순합니다.

```python
DEFAULT_DIG_MODELS = [
    "z-ai/glm-5.2:online",
    "qwen/qwen3.7-plus:online",
    "moonshotai/kimi-k2.7-code:online",
]
```

교체는 두 방법 중 하나:

1. `sinya/.env`에 `DIG_MODELS=z-ai/glm-5.2:online,qwen/qwen3.7-plus:online,moonshotai/kimi-k2.7-code:online` 한 줄 추가
2. `dig.py` 상단 `DEFAULT_DIG_MODELS`만 수정

권장 우선순위는 `.env DIG_MODELS` > 파일 상단 상수입니다. 모델 실험 때 코드 수정 없이 교체할 수 있습니다.
