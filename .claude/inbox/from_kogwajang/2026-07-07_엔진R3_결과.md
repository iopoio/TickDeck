## 작업별 결과

### ① 파생 metric 계약
- `metric_registry` 검증 추가:
  - `derivation`: `cagr | delta_pct | delta_abs | multiple | share`
  - `status: "derived"`
  - `derived_from[]`: 실재 metric 2개 이상 참조
  - derived metric `source_ids` 비움 강제
  - `derived_from` 순환 금지
- C6 source allowlist 자동 상속을 direct `source_ids`에서 `derived_from` 재귀 원천까지 확장.
- renderer는 파생값 계산 없음. registry의 `value/unit`만 포맷.
- verifier protocol 주석을 설계 문서 §1a에 기록.

### ② `viz.annotations[]` 렌더러
- 허용 chart 3종: `multi_line`, `rising_columns`, `quarterly_bars`.
- 구현 kind 4종:
  - `callout`: derived metric 참조, ellipse/box
  - `endpoint_value`: series metric 값 굵게 표시
  - `trend_arrow`: 순수 시각 화살표
  - `event_band`: from_key/to_key 축 좌표 기반 세로 밴드 + raw number 금지 라벨
- 고정 픽셀 anchor 입력(`x`, `y`, `left`, `top` 등) 계약에서 금지.
- `event_band from_key/to_key`가 series label을 참조하는지 검증.
- `capture_deck.sh` / `qa_log.py`에 `FIT_ANNOTATION_OVERLAP` 게이트 추가.

### ③ `toc_progress`
- `deck_spec.meta.section_nav`: `chips | dots | toc`.
- 기본 off.
- renderer가 divider 섹션 경계에서 자동 생성.
- 표시 텍스트는 `section_label`/`part_label` 재사용. `section_nav_label` 같은 designer 자유 텍스트는 렌더하지 않음.

### ④ `metric_commentary`
- `layout: "metric_commentary"` enum 추가.
- row 1~2개 계약:
  - `heading_metric_id`
  - `headline_metric_id`는 `delta_pct` 파생 metric
  - bullet label은 `YoY`/`QoQ`
  - chart는 `quarterly_bars`
- renderer는 row shell만 만들고, 내부 차트는 기존 `quarterly_bars` renderer 재사용.
