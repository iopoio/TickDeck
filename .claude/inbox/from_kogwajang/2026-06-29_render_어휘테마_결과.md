# render_deck 어휘·테마 구현 결과

## 작업 범위

- 코드 수정: `.claude/skills/deck-harness/scripts/render_deck.py` 1개 파일.
- 보고 파일: 본 파일 신규 생성.
- 기존 워크트리 변경(`designer.md`, `visualization.md`, 기존 inbox 파일)은 건드리지 않음.

## 구현 내용

### 1. theme 시스템

- `deck_spec["theme"]` 지원 추가.
- 지원 theme: `tech`, `marketing`, `health`, `editorial`.
- 기본값: `editorial`.
- CLI `--theme`은 명시했을 때만 `deck_spec["theme"]`을 override.
- 기존 호환 alias 유지: `pantone -> editorial`, `breeze -> marketing`, `cobalt -> tech`.

### 2. theme별 cover 분기

- `tech`: T1~T5 band element 제거, 회로 모서리(`cover-circuit-corner`), 딥블루 `#1F4E79`, 시안 `#17A6C4`, 48px grid background, mono eyebrow/footer 적용.
- `marketing`: radial blob background, 큰 radius, T1~T5 band 유지.
- `health`: cool white, trust blue/mint, 중간 radius, curve decor 적용.
- `editorial`: 기존 pantone 계열 유지, band 텍스트 없이 장식 strip만 유지.

### 3. layout 어휘 확장

- 추가 layout wrapper 함수:
  - `_render_split`
  - `_render_stepper`
  - `_render_node`
  - `_render_matrix`
  - `_render_index`
  - `_render_divider`
- 기존 content block 렌더링(`headline`, `body`, `bullets`, `metric`, `viz`)을 재사용하고 layout wrapper/CSS만 다르게 적용.
- stepper/index 번호는 CSS counter로 생성해 C6 raw number 검출을 피함.

### 4. C6 유지

- metric 값은 기존처럼 `metric_id` registry에서 주입.
- source는 기존처럼 `src_id` 기반 footer citation으로 생성.
- 신규 layout wrapper는 raw 숫자·출처 문자열을 직접 생성하지 않음.
- 기존 C6 보강 변경은 보존.
