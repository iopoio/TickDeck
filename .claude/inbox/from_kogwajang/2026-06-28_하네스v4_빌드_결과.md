## 구현된 5대 계약

- C1: 명제 DAG 고아 노드와 route bucket 검사
- C2: 사용자용 제목/본문의 검증 메타데이터 표현 스캔
- C3: trend genre Insight의 `from_state`·`to_state`·`mechanism` 필수 검사
- C4: Insight별 `evidence_ids` 2개 이상 + `source_overlap_score` 검사
- C5: designer가 page-plan 이후 실행되는지, Loop B가 공간/밀도/잘림 사유인지 검사

## 미정·막힌 부분

- PRD에 `source_overlap_score` 실패 임계값이 숫자로 정해져 있지 않음. 현재 test 코드 운영 기본값은 `0.85`로 둠.
- PRD에 실제 런타임 모델 ID가 없음. agent frontmatter `model`은 PRD §5 표기(`opus`, `가벼운+코드`, `코드+가벼운`, `opus(general-purpose)`)를 그대로 넣음.
- PRD에 `_workspace/` run id 포맷과 기본 render target(HTML/PDF/PPTX 중 기본값)이 없음. 스킬 문서에는 `<run_id>`와 `render_target` 필드로 열어둠.
- 세션 시작 fact-check 스크립트 `.claude/scripts/yangnyeon_factcheck.py`, `.claude/scripts/tracker_factcheck.py`는 이 프로젝트에 없어 실행 실패함. 하네스 계약 test는 별도로 통과.
- Gemini CLI 교차 리뷰는 시도했으나 90초 이상 출력이 없어 중단함(exit 130). 외부 교차 리뷰는 미완료.
