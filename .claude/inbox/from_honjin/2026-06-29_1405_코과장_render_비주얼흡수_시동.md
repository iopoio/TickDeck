## 1. 배경
v4 하네스(`.claude/skills/deck-harness/`)는 머리(에이전트 추론)·규율(C6 날조차단·4층 검토) 다 됐는데 **렌더러가 비주얼을 못 그린다**: designer가 deck_spec에 viz_intent(dumbbell·before/after·점도표·흐름도)를 자연어로 적었으나 `render_deck.py`가 텍스트·metric 카드만 그려 deck_v4.html의 `<svg>` = 0.
일회용 `render_distilled_deck.py`(deck_v3)는 SVG 8종을 그렸지만 (a) 수치가 코드에 하드코딩 = C6 위반 (b) "검색 클릭률" 등 마케팅 전용 문자열 매칭 = 범용 X 이라 **그대로 못 옮긴다**. 모양만 일반화해 가져온다.

## 2. 목표

## 4. viz 블록 계약 (본부 설계 초안 — 기존 블록 패턴에 맞춰 조정 OK)
content 블록에 `viz` 타입 추가:
```json
{ "type": "viz", "chart": "before_after|dumbbell|flow|big_number|gap_map|shift",
  "title": "<짧은 제목·수치 금지>",
  "series": [ {"label": "<라벨·수치 금지>", "metric_id": "m_067", "role": "baseline|highlight"} ],
  "note": "<선택·수치 금지>" }
```
- **수치·단위·출처 = metric_id로만** (render_deck이 registry에서 꺼내 SVG 텍스트에 주입). title/label/note에 숫자 직접 쓰기 금지 = C6.
- 차트 6종 ← deck_v3 8함수 일반화 매핑:
  - `before_after` ← `_visual_search_ctr`·`_visual_measurement_adoption` (막대 2개: baseline 회색 / highlight 강조)
  - `dumbbell` ← `_visual_privacy_gap`·`_visual_ai_readiness` (두 점 + 격차선)
  - `flow` ← `_visual_trust_flow` (A→B 화살표)
  - `big_number` ← `_visual_korea_drop` (빅넘버 + 방향 화살표)
  - `gap_map` ← `_visual_gap_map` (여러 행 미니 비교)
  - `shift` ← `_visual_foundation_shift` (노드 이동 개념도)
- 계승 규칙: 비교군 회색 `#E5E7EB`·주장만 트렌드색·범례 없이 직접 라벨·0 기준축·외부 라이브러리/이미지 0(inline SVG만).
