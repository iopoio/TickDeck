## 2. 생성 파이프라인 (`autoAgentProgress.store` 상태머신 그대로)
```
starting-draft (개요 생성)
 → 테마 후보 N개 추천 (themeCandidateIds)
 → creating-slides (슬라이드별 병렬 생성 · progressPercent = 완료/요청수)
 → completed → 편집 캔버스 + 챗 리파인 (우측 Chat/Design)
```
- 추적 상태: `draftId`·`selectedThemeId`·`requestedSlideCount`·`completedSlideIds`·`progressPercent`.
- **우리 대비**: 우리 파이프라인(②틀+스토리 → ②-2 critic 8게이트 → ③출처1:1 → ③-2 일관성 리파인)이 **더 깊다.** snapdeck엔 critic·출처 1:1·재분류 단계 없음(범용 소비자용). 흡수할 파이프라인 우위 없음 — 우리가 앞.
- 차용 가치 1개: **슬라이드별 병렬 생성 + 진행률** (우리는 채굴만 병렬·작성은 순차).

## 3. 출력·내보내기 모델
- **PDF · Image(.png) · PowerPoint(.pptx)** 3종. **편집 가능 PPTX = 유료 후크** (무료=워터마크 PDF/PNG).
- "편집가능" 라벨은 표시됨 · **fidelity 미검증**(유료·돈 안 냄). 캔버스가 Fabric.js라 PNG 래스터 경로 보유 → 복잡 레이아웃은 폰트 치환·위치 틀어짐 흔함(감안).
- **우리 카운터**: 편집 네이티브 PPTX(텍스트=텍스트·차트=살아있는 차트)는 **우리 pptx 스킬·python-pptx가 이미 기본 제공.** 저쪽 유료 기능 = 우리 기본기.

## 4. 두 디자인 언어 (규율만 흡수 · 스킨 복제금지)
완성본 2종이 서로 다른 레지스터 = **레지스터 선택이 제품 기능**임을 보여줌.

**(가) 볼드 포스터형** — 디자인 트렌드 보고서
- 풀블리드 단색 브랜드 배경 + 초대형 한글 헤드라인(display 스케일·3줄) + 코너 장식 모티프. 슬라이드당 텍스트 적음·임팩트 큼.
- 본문: 라이트 배경 + 단일 강조색 · 3스텝 가로 플로우(화살표) · 4사분면 마인드맵(중앙 노드) · 좌리스트+우막대차트 · 번호 전략 카드.
- **= 저밀도 고임팩트 레지스터.** 트렌드·전략 제언·브랜드 임팩트 덱용.

**(나) 밀도 컨설팅형** — 마케팅 트렌드 보고서
- 좌측 사이드 타이틀+요약 + 우측 다단 섹션(표·색코딩 지표·상관계수·로드맵 STAGE) · 전 장 푸터(섹션+페이지+워터마크).
- **= 우리 17골격과 수렴.** 독립 제품이 같은 구조에 도달 → 우리 라이브러리 강한 신호 재확인(신규 흡수 아님).

→ **흡수 결론**: 우리 라이브러리는 컨설팅-밀도형에 치우침. **볼드-포스터형을 "저밀도 레지스터 프리셋"으로 추가**(같은 primitives·타입스케일↑·항목 수↓·풀블리드 강조 1색·코너 모티프). 레이아웃 신규가 아니라 **밀도/타입스케일 프리셋**. 상세 = `DECK_STRUCTURE_LIBRARY.md` 레지스터 절.
