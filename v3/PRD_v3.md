# TickDeck v3 PRD — 조사를 시각 양식 덱으로 만드는 재사용 반자동 시스템

> 2026-06-18 작성. v3 1차 실패(텍스트 fallback·envato 양식 0·1회성) 후 근본 재정의.
> 검수 게이트: 본부 작성 → codex + 제미나이 검수 → **다 OK 나면 진행**(후추님 결재).

## 0. 한 줄 정의
낯선 분야도 조사 데이터를 받아, **내용별로 적합한 시각 양식 화면에 배치·정리**해서 설득 덱을 (반)자동 생성하는 **재사용 시스템**.

## 1. 왜 (문제)
- 낯선 분야 이해 → 근거 종합 → 설득 자료 = 후추님 통증이자 강점.
- 기존 도구(Gamma 등) = 그럴듯한 합성·출처 약함.
- **v3 1차 실패** = 조사는 됐으나 덱이 텍스트로 fallback, envato 양식 0개 활용, 1회성 어댑터.

## 2. 이번 PRD가 못 박는 4가지 (실패 반복 차단)
1. **시각 양식 = 1급 시민** — 양식을 HTML/CSS/SVG 컴포넌트로 프로그램화. 텍스트 fallback이 **원천 불가능**.
2. **큐레이션 = 심장**(후추님 통찰) — 자료 받은 뒤 *"내용별로 어떤 화면(양식)에 넣을지 고민하며 정리"* = 인간 덱 방식. **단순 dict 매칭 아님.**
3. **재사용** — 1회성 ❌. 어떤 주제(반도체·부동산·뭐든) 넣어도 도는 영구 시스템.
4. **반자동** — 시스템이 큐레이션·렌더하고, 사람은 검수·조정만.

## 3. 사용자·성공 기준
- 사용자 = 후추님(customer zero). 낯선 분야 설득 자료.
- 성공 = 주제 1개 넣으면 **시각 양식이 풍부한** 덱 초안이 나오고, 사람 검수가 최소.

## 4. 파이프라인
```
[주제] → ① 축1 수집 (중국AI·신야 격리 · 자료+수치+출처)
       → ② 큐레이션 (내용별 "어느 화면·어떤 양식" 배치·정리 · 인간 방식)
       → ③ 양식 컴포넌트 렌더 (시각)
       → ④ 덱 출력 (HTML·PDF·PPTX)
       → 사람 검수·조정
```

## 5. 양식 컴포넌트 라이브러리 (재사용·시각·1급)
11유형을 **HTML/CSS/SVG 컴포넌트 + 데이터 슬롯**으로: 빅퍼센트 · 도넛게이지 · 바차트 · 퍼널 · 카드그리드(N열) · 타임라인 · 매트릭스2x2 · 비교(VS) · 대시보드 · 지도+데이터 · 프로세스. **한 번 만들면 모든 덱이 재사용.** (envato 카탈로그 = 디자인 참고)

## 6. 큐레이션 엔진 (심장 · 반자동 · 후추님 통찰)
- **입력** = 축1 자료(내용 조각·수치·논리·출처).
- **처리** = 각 내용 조각의 **성격 판별**(수치 비중 / 단계 / 비교 / 추세 / 요약…) → **적합 양식 화면 선택 + 배치 + 순서**(도입→요약→설명→비교→전망 스토리). = 인간이 "이 내용은 도넛, 저건 타임라인"으로 고민하는 것.
- **반자동** = 애매하면 후보 2~3개 추천·사람 선택.
- ⚠️ 단순 dict 아님 — **내용의 의미·맥락을 보고 큐레이션.**

## 7. 자산 (살림) vs 재정의
- **살림**: 축1 딥리서치(조사·수치 corpus 대조·용어·검증됨) · envato 양식 카탈로그(11유형 디자인 참고).
- **재정의**: 어댑터(텍스트 매핑) · deck_harness 텍스트 레이아웃 전제.

## 8. 비기능
- **보안**: 중국 모델 호출은 신야 격리·TickDeck는 자료만 소비(verify_boundary).
- **진실**: 수치 corpus 대조·출처 명시(축1 자산) — 큐레이션·렌더에도 출처 유지.
- **비용**: 조사 1회 ~$0.02(OpenRouter 실측 SoT)·렌더 0(로컬).

## 8.5 Phase 0 — 구현 계약 (검수 보강 · codex+제미나이 6/18 · 없으면 같은 실패 재발)
검수 결과 = "방향 OK·보강 필요". 구현 전 아래를 **계약(test·스키마)으로 확정**한다 (선언 X):
1. **fallback 금지 acceptance test** — 렌더러는 "시각 컴포넌트 없으면 실패"(텍스트 fallback 금지). 테스트로 강제 = 계약.
2. **envato 수준 visual 기준** — 각 컴포넌트가 차트·게이지를 실제로 그리는지 기준·시각 검증.
3. **큐레이션 스키마** — 내용 조각→양식 선택 입출력 JSON 스키마 + 선정 가이드 logic (예: 수치 1개·70%+ → 빅퍼센트 / 3항목 수평 → 카드그리드 / 과거-미래 → 타임라인 / '하지만·대조' → 비교).
4. **source_map 계약** — 슬라이드·수치마다 출처 추적 유지 (진실 안전장치).
5. **단계별 품질 게이트** — 각 Phase 산출 검증 기준.
6. **기본값 시각 컨테이너** — 양식 애매 시 디자인된 카드그리드로 (텍스트 fallback 절대 X · 제미나이).

## 9. 구현 단계 (codex · 그룹별 · 품질)
1. **양식 컴포넌트 라이브러리** — 우선 핵심 4(빅퍼센트·도넛게이지·바차트·카드그리드) → 11유형 확장.
2. **큐레이션 엔진** — 내용 성격 판별 → 양식 매칭·배치·반자동.
3. **렌더 통합** — 컴포넌트 → 덱(HTML/PDF).
4. **E2E** — 마케팅 트렌드 재생성(이번엔 시각 양식 풍부).
