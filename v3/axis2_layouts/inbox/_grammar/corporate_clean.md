## 1. 타이포 위계

- **제목**: 8/9가 산세리프. 예외 1건(3번)만 세리프("Infographic Section"). 손글씨 스크립트 제목은 2건(9번 전면, 5번 없음—9번만 스크립트 주력, 8번 일부 세로회전). 즉 "깨끗한 산세리프 굵은 제목"이 지배적.
- **2톤 강조 제목 관용구**: 제목 안에서 일부 단어만 색/굵기를 바꿔 강조하는 패턴이 반복. 방식 2종:
  - 색 전환형 — "Marketing **Plan**"(1: 검정+블루), "Product **Positioning**"(1), "Take Control Of Ur **Business!**"(2 볼드흑+퍼플), "Market **research**"(1) → 4건.
  - 닷/브랜드형 — 브랜드명 뒤 마침표 + 액센트색: "SCAIVE."(5), "scaive."(5 소문자변형), "Heart." "Fun." "Services."(8) → 2건(5,8).
- **부제/라벨**: 전 아이템 공통으로 아주 작은 올캡 산세리프 라벨(자간 넓힘)을 제목 위/아래에 붙임 — "CLEANING SERVICE"(6,7), "BUSINESS CORPORATE"(5), "PROJECT PORTFOLIO 01"(9), "HOME LIGHTING"(9). (7/9)
- **본문**: 전부 얇은 회색 산세리프 소문자. 행간 넉넉, 라이트~레귤러 웨이트. 제목(볼드/색)과 본문(얇은 회색)의 웨이트 대비가 이 패밀리의 핵심 위계 장치.
- **크기 관계**: 제목 >> 본문 강한 점프. 빅넘버(1.4m / 3,490,000 / 312K)는 제목보다도 크게, 별도 위계로 독립.

## 2. 그리드·컴포지션

- **여백 철학**: 흰(또는 단색) 여백을 넉넉히 남기는 "숨쉬는" 레이아웃. 요소를 가장자리까지 꽉 채우지 않음. (커버 예외: 컬러 블리드형 커버는 별개)
- **제목 앵커**: 좌상단 또는 상단 중앙. 본문 슬라이드 제목은 대부분 좌상단 정렬 + 바로 아래 짧은 액센트 밑줄(언더바) — 1,2,3에서 반복. 중앙 정렬 제목은 3(세리프)만.
- **분할 비율**: 좌/우 2분할(텍스트 : 사진 또는 텍스트 : 컬러패널)이 지배적. 5·6·7은 화면 절반을 단색(차콜/네이비)으로 채우고 반대편에 텍스트.
- **배치 리듬**: 2×2, 3열, 4아이콘 가로배열 등 균등 그리드. 아이콘+제목+한줄설명 카드가 반복 유닛.
- **표지 vs 본문 vs 간지 구조 차이**:
  - 표지 = 로고 + 대형 2톤 제목 + 작은 URL/태그라인. 사진 히어로형(2,4,6) 또는 순백 타이포형(3,8,9).
  - 간지 = 화면 절반 컬러 블리드 + 대형 제목(1의 "unique selling positioning", 5의 컬러 분할).
  - 본문 = 좌상단 제목 + 언더바 고정, 하단에 콘텐츠 그리드.
- **개별 버릇**: 아웃라인 대형 페이지번호를 모서리에 배치(9만), 브라우저 크롬 UI 헤더바를 전 슬라이드 상단에(3만), 세로 90° 회전 제목(8만).

## 3. 차트·데이터 화법

- **빅넘버 우선**: 차트보다 "큰 숫자 + 짧은 라벨" 카드가 이 패밀리의 주력 데이터 화법. 1.4m·5.8M·312K·3,490,000·+634/-287·80%/20% 등 거의 모든 아이템에 등장. (7/9)
- **차트 종류**: 도넛/링게이지(1), 세그먼트 파이(3), 라인 그래프(1), 피라미드(1), 지도 코로플레스(7). 막대는 얇은 진행바(progress bar)형이 주 — 굵은 컬럼 차트는 드묾.
- **막대/선 스타일**: 얇고 각진(라운드 없음~약한 라운드) 진행바, 회색 트랙 + 액센트색 채움. 게이지 링은 얇은 스트로크.
- **수치 표기**: 퍼센트/약어(k, M) 병기. 숫자는 볼드 + 액센트색, 라벨은 얇은 회색.
- **아이콘**: 얇은 라인(아웃라인) 아이콘이 압도적(1,3,8). 원/헥사곤/사각 배지 안에 넣는 경우 많음(1 헥사곤, 6 원형 배지). 채운(솔리드) 아이콘은 4,6 일부.

## 4. 장식 어휘

- **도형**: 원·사각·헥사곤 배지가 아이콘 컨테이너로 반복. 1은 헥사곤 특화, 6은 라운드 사각 카드.
- **선**: 짧은 액센트 언더바(제목 아래), 얇은 구분선, 타임라인 점선/도트 라인(5,9).
- **사진 처리**: 3종 공존 — (a) 직사각 프레임 그대로, (b) 원형/타원 마스크(4,6), (c) 컬러 패널 위 반쯤 겹침. 블리드(가장자리까지 꽉 채움)는 컬러 패널에만, 사진은 보통 프레임 안.
- **배경 패턴**: 대부분 무지 흰/단색. 유기체 블롭(4), 큰 곡선 아크(6,7), 워터마크형 옅은 로고(1) 는 개별 버릇.

## 5. 컬러 운용

- **구조**: 바탕(흰 또는 단색 1개) + 잉크(진회색/검정 텍스트) + **액센트 1개** 가 표준 골격. (9/9 모두 액센트 1개가 주력)
- **액센트 수**: 대부분 **1개 주액센트**. 보조 색을 더한 경우:
  - 1번: 블루(주) + 그린(보조) → 2개
  - 4번: 블루 + 옐로 → 2개(동등)
  - 7번: 네이비 베이스 + 레드(맵) / 라임(소셜) → 문맥별 교체
  - 나머지 6건(2 퍼플, 3 무채색, 5 골드, 6 라임, 8 오렌지, 9 더스티블루)은 **단일 액센트**.
- **액센트 색상표**: 블루(1,4)·퍼플(2)·무채색(3)·블루+옐로(4)·골드/머스타드(5)·라임옐로(6,7)·레드(7)·오렌지(8)·더스티블루(9). → "한 개의 선명한 액센트를 흰 여백 위에 절제해서 쓴다"가 공통.
- **다크 변형**: 5(차콜)·7(네이비)처럼 어두운 바탕에 같은 액센트를 반전 적용하는 슬라이드가 섞임. 라이트 기본, 다크는 간지/강조용.

## 7. TickDeck 엔진 시사점

기존 editorial(기본)·editorial_serif·data_mono와 대비:
- **editorial 계열이 "비대칭 그리드 + 큰 세리프 에디토리얼"이라면, corporate_clean은 "대칭 균등 그리드 + 산세리프 + 넉넉한 흰 여백"** 으로 정반대 축. 좌상단 제목+짧은 액센트 언더바를 고정 규칙으로 두면 이 패밀리 정체성이 바로 선다.
- **액센트 토큰을 정확히 1개로 강제**(현 엔진 빅넘버 강조색 토큰 재사용 가능)하되, 라이트 기본 + 다크 간지에서 동일 액센트 반전만 허용 — 색을 여러 개 뿌리는 순간 이 패밀리 아님.
- **데이터 화법을 차트가 아니라 "빅넘버 카드" 우선으로** 재배치. data_mono가 표/차트 밀도형이라면 이쪽은 큰 숫자 1~4개 + 얇은 진행바가 기본. 각진(비라운드) 얇은 게이지/진행바 스타일 추가 필요.
- **아이콘 컨테이너(원/헥사곤/라운드사각 배지 안 라인아이콘)** 를 컴포넌트로 넣어야 editorial의 "무아이콘 활자중심"과 구분됨.
