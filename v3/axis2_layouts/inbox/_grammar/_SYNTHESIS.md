## 제안 우선순위 (후추님 결재 대상)

1. **dark_premium 전면 다크 시스템** — 판매 다양성 임팩트 최대(라이트 3벌 대비 축 자체가 다름). 무독 리스크 3종(순백 본문 눈부심·저채도 차트 묻힘·액센트칩 글자 뒤집힘)은 토큰 설계로 선제 차단 — 이미 같은 클래스 버그(navy-on-navy) 전례·수정 경험 있음.
2. **minimal_typo(B형) 시스템** — 구현 비용 최소(장식이 없어서 CSS 오버라이드 소형), 인상 차별화는 큼.
3. **editorial_serif 보강** — 콘덴스드 산세 헤드 변형 + 러닝헤드 프레임 + 어스톤 액센트 슬롯 (기존 시스템의 변주 폭 확대 — "몇 벌이면 판매 가능" 셈법에서 0.5벌 가치).
4. **data_mono 보강** — KPI 델타 카드 블록 + 다계열 라인/바 렌더러 (차트 어휘 확장은 전 시스템 공용 이득).
5. creative_bold 조각 흡수는 1~4 뒤 여유 시.

## 산정

1~2번이 들어가면 시각 시스템 = 라이트 카드형(기본 8테마) / 세리프 매거진 / 모노 데이터 / **미니멀 타이포** / **전면 다크** = 5벌. "레이아웃이 다 같다"는 G5 판정에 대한 답이 되는지 후추님 실물 판정 필요 — 각 시스템 파일럿은 기존 실전 덱(creator_serif 또는 tech_v3) 재렌더로 저비용 검증 가능.
