# Axis 2 — Layout Library

축2는 설득 자료에 맞는 레이아웃 패턴을 모으는 영역이다.

## 들어온 것

`envato/`는 Think의 `sandbox/deck_layouts/envato/`를 원본 보존 복사한 것이다.

- item 폴더: 37개
- 전체 파일: 154개
- 포함: `envato_collect.py`, `_queue.txt`, 각 item별 preview 이미지, `layouts.md`

## 주의

- Envato 미리보기 이미지는 양식 학습·분류 참고용이다.
- 재배포나 상업 사용 자산으로 취급하지 않는다.
- 기존 `layouts.md`와 미리보기 결과물은 삭제하거나 재분류하지 않았다.
