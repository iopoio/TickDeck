# 디자인 레퍼런스 수집 규칙 (코덱스·제미나이 핸드오버용)

> 2026-07-03 후추님 방향 전환: 디자인 시스템 다양화는 클차장이 한두 레퍼런스 감으로 빚는 게 아니라,
> **수십 개 템플릿을 스타일 패밀리별로 모아 공통 문법을 추출**해서 엔진 시스템으로 만든다.
> 이 문서 = 수집 봇(코덱스/제미나이)이 따를 규칙. 수집 후 클차장이 클러스터링→문법 추출→엔진 반영.

## 저장 구조 (아이템 1개 = 폴더 1개)

```
v3/axis2_layouts/inbox/<source>_<슬러그>/
  00.jpg          ← 프리뷰 슬라이드 이미지 (순서대로 00, 01, 02…)
  01.jpg
  ...
  meta.txt        ← 아래 필수 필드
```

`meta.txt` 필수 필드 (한 줄 하나·빈 값 금지):
```
url: <상품 페이지 원본 URL>
name: <템플릿 이름>
source: creativemarket | envato | etsy | ui8 | 기타(적기)
style_family: <아래 6개 중 정확히 1개>
sub_tags: <자유 태그, 쉼표 구분 — 예: 헥사곤아이콘, 포토블록, 언더라인제목>
mosaic: yes | no   ← 슬라이드 개별 이미지가 아니라 모자이크 썸네일 1장뿐이면 yes
collected: YYYY-MM-DD
```

## 스타일 패밀리 (수집 쿼터의 축)

| family | 특징 예시 |
|---|---|
| `corporate_clean` | 흰 바탕·블루/네이비 액센트·아이콘 칩·정갈한 그리드 (예: GoldenPixelStudio Marketing Plan) |
| `editorial_magazine` | 세리프 혼용·큰 여백·풀블리드 사진·잡지 조판 |
| `minimal_typo` | 타이포 자체가 주인공·장식 최소·1~2색 |
| `data_dashboard` | 차트 밀도 높음·KPI 카드·계기판/그리드 감성 |
| `creative_bold` | 강렬한 색·비대칭·도형 오브제·그라디언트 |
| `dark_premium` | 다크 바탕·금속/골드/네온 액센트·럭셔리 톤 |

**쿼터: 총 40~60개, 패밀리별 최소 8개.** 한쪽 패밀리만 쌓이면 중단하고 부족한 패밀리를 채운다.

## 아이템 자격 (하나라도 어기면 수집하지 않는다)

1. **16:9 프레젠테이션 템플릿**만 (소셜 포스트·이력서·브로슈어 X)
2. **프리뷰에서 본문 슬라이드가 6장 이상 보일 것** — 표지 1장만 예쁜 건 탈락. 차트·리스트·타임라인·비교 같은 *일하는 슬라이드*가 보여야 문법 추출이 됨
3. 이미지 폭 **최소 1000px** (텍스트 위계가 판독돼야 함). 워터마크가 본문을 가리면 탈락
4. **같은 제작자(스튜디오) 최대 3개** — 한 스튜디오의 버릇이 패밀리 공통 문법으로 오염되는 것 방지
5. 기존 수집분과 중복 금지 — `v3/axis2_layouts/envato/` 폴더명과 `_queue.txt`의 URL을 먼저 확인

## 저작권 가드레일

- 상품 페이지에 공개된 **프리뷰/스크린샷 이미지만** 저장한다. 유료 원본 파일(pptx/key) 다운로드·크랙 시도 금지
- 용도 = 시각 문법 학습 참고 (복제가 아니라 "공통 관례" 추출). meta.txt의 url이 출처 기록

## 실전 PDF 리포트 (2026-07-06 신설 — 후추님 "PDF 최우선" 지시)

템플릿 마켓은 "팔려고 만든 덱", 진짜 문법은 컨설팅사·투자사 **실전 PDF**에 있다. **수집 우선순위 1순위.**

- 도구: `python3 pdf_intake.py <PDF_URL> <슬러그> <family>` → inbox 아이템 자동 생성 (다운로드→페이지별 JPG 1200px→meta 스텁). 생성 후 meta.txt의 name·sub_tags 실측 태깅 의무
- 폴더 접두사 `pdf_`. 원본 `source.pdf` 동봉 (JPG는 분석용, PDF가 정본)
- 자격 완화: 실전 리포트는 **4:3·변형 가로판도 OK** (BOND=4:3). 세로 A4 리포트는 editorial 문법용으로만 선별 수집
- 게이트(이메일월·Drive 보기전용·로그인) = **우회 금지.** 공개 직링크가 있는 것만. 막히면 미러·다른 발행물로
- 검증된 소스 (직링크 다운로드 확인됨):
  - BOND Capital (bondcap.com/report/pdf/) — 2026-07-06 수집 완료
  - 삼정KPMG (assets.kpmg.com .../kr/pdf/) — 이슈모니터·Business Focus·CES 프리뷰. 2026-07-06 수집 완료
- 후보 소스 (직링크 미확인 — 수집 시 확인): McKinsey·BCG·Bain·Deloitte Insights 발행물, a16z·Activate Consulting 연례 덱, 네이버 증권 리서치(증권사 산업분석 PDF 직링크), 상장사 IR 덱
- 막힌 것: Coatue EMW 덱 = Drive 보기 전용 (다운로드 차단) — 공식 공개 미러 찾기 전까지 보류

## 수집 팁 (creativemarket 기준)

- 상품 페이지 직접 curl은 Cloudflare에 막힘 — 프리뷰 이미지 CDN(`tint.creativemarket.com/...width:1200...`)은 직링크 다운로드 가능. 페이지에서 이미지 URL을 추출한 뒤 curl로 받는다
- envato elements는 기존 수집기(`v3/axis2_layouts/envato/envato_collect.py`) 참고 가능

## 완료 보고 양식 (제대리 조사 룰 준수)

1. `ls v3/axis2_layouts/inbox/ | wc -l` raw 출력 첨부 (보고 개수와 검산 일치 의무)
2. 패밀리별 집계표 (family × 개수)
3. 탈락시킨 후보와 사유 3~5건 샘플 (자격 기준이 실제로 작동했다는 증거)
4. 확인 안 된 것은 "확인 안 됨"으로 — 추측 금지

## 수집 후 (클차장 몫 — 봇은 여기까지 안 함)

클러스터 검토 → 패밀리별 공통 문법 시트(타이포 위계·그리드·차트 화법·장식 어휘) → 엔진 시스템 후보 도출 → 후추님 승인 → render_deck.py 시스템 추가. 기존 "엔바토 흡수 라운드"와 달리 **레버 단위가 아니라 패밀리 단위**로 흡수한다.

## 패턴화 flow (2026-07-04 후추님 — "그대로 따라하지 말고 규칙과 flow를 만들자")

레퍼런스가 들어올 때마다 도는 상시 사이클. **스타일 복제 직행 금지** — 반드시 패턴 분해를 거친다.

1. **인테이크**: 후추님이 URL/스샷을 던짐 → `inbox/<source>_<슬러그>/`에 저장 (위 규칙 그대로. 소량이면 클차장이 직접, 대량이면 코덱스/제미나이 핸드오버)
2. **패턴 추출**: analyst 에이전트가 새 수집분을 실측으로 보고 **패턴 단위로 분해** → `PATTERN_LIBRARY.md`와 대조해 기존 패턴이면 관찰수 갱신, 새 패턴이면 ⬜(백로그)로 등재 제안 → 클차장 병합
3. **엔진 반영**: 라이브러리 ⬜ 항목을 관찰수·판매 임팩트 순으로 라운드 처리. 구현 원칙 = **시스템 무관 부품**(색·서체는 각 시스템 토큰에 위임) — 특정 레퍼런스의 스타일을 통째로 새 테마로 만들지 않는다
4. **선택·적용**: designer가 덱 제작 시 라이브러리에서 내용에 맞는 패턴을 고른다 (선택 규칙 = `.claude/agents/designer.md`) — 여기가 "패턴들 중 하나 골라서 적용"이 실행되는 지점
