# Onboarding Process Flow — 레이아웃 1차 분류

## 학습 가치 있는 레이아웃 (deck_harness 후보)

| 유형 | 출처 슬라이드 | 패턴 요약 | deck 매칭 룰 |
|---|---|---|---|
| 원형 노드 순환 프로세스 | 여러 슬라이드 | 01~04 원 노드 순환 + 중앙 아이콘 | 프로세스/순환 |
| 기어 메타포 | 내지 | 톱니바퀴 + 단계 수치(70/80/90%) | 메타포 프로세스 |
| 좌텍스트 + 우 사진 | 여러 슬라이드 | 좌 큰 제목/우 인물 사진 + 빅넘버 | 설명 |
| 무한대 루프 흐름 | 내지 | ∞ 형태 경로로 단계 연결 | 순환/흐름 |

## 비고
- 온보딩 흐름. 순환·무한루프 패턴이 deck에 없던 유형.
