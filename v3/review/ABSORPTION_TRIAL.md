## B. 비판가 패스(critic) — ✅ 실증 완료

살아있는 마케팅 덱에 DNA 8게이트 루브릭으로 1회 호출 → **구체·실행가능 약점 6건** 적출:
논점이탈(p4.5·p6·p10) · 출처샐러드(p9) · 단위충돌(p15·기존 반복버그) · 현상나열 헤드라인(p14) · 무딘 착지(p19).
무오류 아님(p6은 DNA 원칙1로 변호 가능) → **"정답"이 아니라 "검토할 판단점"을 정확히 집음 = 가치.**

**채택 권고:**
- (A) 자동 차수 = FLOW `②blueprint → ②-2 critic → ③page_specs` 한 단계 신설. critic은 page_specs까지 받아 ③ 직후에도 1회 가능.
- (B) 인세션 차수 = 클차장이 손원고 쓴 뒤 `run_critic_pass.py` 1회 돌려 자가 교정 (이미 가용).
- 루브릭 = DNA 자동화 게이트 G1~G8 (본 critic 시스템 프롬프트 = 그 이식본).

## A. Few-shot 골드예시 — 적용 상태 (현 덱의 critic-클린 페이지에서 추출)

> ②③ 작가 프롬프트는 현재 **규칙 나열만.** 아래 모범 page 객체를 in-context 예시로 동봉 → 포맷·톤·BLUF·출처규율을 규칙보다 빠르게 학습. (A) 시스템 프롬프트 말미 `## 모범 예시` 블록에 그대로 삽입.
> 선정 기준 = critic '이상 없음' + content_kind 다양성(관계/카드/단계) + 출처 1:1 + so-what 있음.

**예시 1 — concept_relation (before→after, p11):** 헤드라인이 주장("볼륨→확신"), takeaways가 결론먼저, 출처 1:1(HubSpot).
**예시 2 — growth_drivers (대비 2카드, p13):** 기본값 vs 차별값 대비 + footnote로 용어(개인화의 역설) + 수치 출처 분리(Deloitte 43%).
**예시 3 — funnel_steps (4단계 상승, p18):** 단계마다 동사 액션 + "루프를 닫음" so-what 착지.

(실제 JSON은 page_specs p11/p13/p18 그대로 — 별도 복제 안 함, 추출 출처만 명기.)

**채택 권고:** 즉시 win(임팩트 상·난이도 하). 단 골드예시는 **critic 통과 페이지로만** 구성(오염 예시 = 오염 학습).

## C. 프롬프트 역학 — 적용 상태 ((A) 래퍼용 템플릿)

> Gemini 검수: primacy(시작 가중)·recency(시작+끝 반복으로 lost-in-the-middle 완화) = 사실. (A) `anthropic_call_wrapper` 경유 작가 호출에 적용.

```
[시스템] = 구조 라이브러리 §1·§2 법칙 + ## 모범 예시(A) + ## 절대규칙(JSON only)
[유저 프롬프트 골격]
  ## 과제(한 줄, 맨 위)         ← primacy
  --- (구분자)
  ## 입력: report.final + blueprint
  --- (구분자)
  ## 출력 스키마(JSON)
  ## 핵심 규칙 재확인(3줄, 맨 끝)  ← recency: "JSON만 / 출처 1:1 / so-what 착지"
  출력 프라이밍: 응답을 `{` 로 시작하도록 유도(assistant turn 프리필 or "JSON: {")
```

**채택 권고:** (A) 구현 시 기본 적용(난이도 하). (B) 인세션엔 불필요(클차장이 직접 작성).

## D. 일관성 보존형 페이지 리파인 — 적용 상태 (Kimi 원칙5 ↺ Gemini 경고 절충)

> Kimi "슬라이드별 반복생성=3배"는 **과장**(Gemini)이고 무차별 N+1 재생성은 **지배메시지 일관성 파괴 리스크.** → 독립 재생성 X. 아래 형태로만 흡수.

**규칙:** 전체 단일호출 초안 → critic(B)이 '치명도 상' 짚은 페이지**만** 선별 → 그 페이지를 **governing_thought를 재주입한 채** 1:1 보강(다른 페이지·아크 불변). 사실상 현 "멀티모델 리뷰 + autofix"를 코드 게이트로 형식화한 것.

- 보강 입력 = {governing_thought, 해당 page, critic 지적, 인접 page 2개(맥락)}.
- 금지 = 전 페이지 일괄 재생성 · 새 주장 신설 · 아크 변경.

**채택 권고:** 중×중. B 도입의 자연 후속(critic→선별보강 짝). B 없이는 무의미.
