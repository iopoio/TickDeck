## 1. 흡수 규율 (수렴 8 + 개별 시그니처)

**수렴 8 (위 표) — 토큰화 대상:**
1. **한 색 N단계 규율.** primary 1색 + 그 색의 tint/shade 4단계로 헤드/강조/보조/차트계열 전부. 강조색 사용 카운트 ≤2/슬라이드. **무지개 금지.**
2. **라이트/다크 매핑.** `cover/divider/closing=dark`, `body/data/compare=light` 자동.
3. **킥커+헤드 2필드 헤드 컴포넌트.** 작은 강조색 킥커(맥락) 위 + 거대 Bold 타이틀(2줄). 강조는 웨이트믹스(색·크기 변경 X).
4. **안 채우는 레이아웃.** 텍스트는 상단 60%/좌측에 몰고 하단·우측은 비우거나 풀블리드 비주얼. "여백=고급".
5. **borderless 데이터잉크.** 격자선·축눈금 제거, 막대 위 직접 라벨, 빅넘버는 body 3~5× + 강조색 + 2줄 회색 설명.
6. **모듈러 타입스케일(큰 점프).** caption .75 / body 1 / 카드·소제목 1.15 / 리드·H2 1.5 / H1 2.4 / 섹션헤드 4.5 / divider 거대 7~8×. 산세 1종, 위계는 크기·웨이트·색으로만.
7. **단일 산세리프.** (※ DNA와 긴장 — §2 결정)
8. **시리즈 고정 템플릿.** N개 병렬 섹션은 한 스켈레톤 반복(예: 좌=진단/우=처방). 일관성 > 페이지별 신상.

**개별 시그니처(옵션·긴 덱용):**
- **의미색은 색면이 아니라 ● 도트로** (Trending): green=기회/red=경고를 글머리 점으로만 → 인포그래픽 유치함 회피.
- **다크 패널 = 검정이 아니라 primary-dark** (Trending): 인용·CTA·차트제목탭을 #000 아닌 primary 최진shade → 한 color family 통일.
- **섹션 divider 전용 패턴** (Trending stacked-offset 이미지 / Deloitte 풀블리드 다크): divider만 독점 → 전환 신호 강함. 본문은 절대 안 씀.
- **count-driven 그리드** (Deloitte): 아이템 수가 단 수를 정함(3→3단·5→5단). 균등폭·아이콘 상단.
- **beveled-notch 카드** (Trending): 카드 모서리 45° 노치 → 평범 사각에 디테일.

## 2. DNA 대조 (검증 / 정밀화 / 긴장)

**✅ 검증됨 (3덱이 DNA를 독립 입증):** 단일 강조색 · 라이트/다크 · 거대숫자 콜아웃 · 혼합웨이트 헤드라인 · 비대칭 좌텍스트/우비주얼 · 타이포 스케일 통일 · 권위토큰(출처줄) · 시리즈 일관성. → DNA가 옳은 방향.

**🔧 정밀화 (DNA의 정성 규칙에 구체 수치/장치 보강):**
- "단일 강조색" → **명도 N단계 램프**로 비강조 데이터 위계 인코딩(구체).
- "타이포 통일" → **구체 비율**(0.75~8× 모듈러) 부여.
- 헤드라인 → **킥커+헤드 2필드** 구조(신규).
- 차트 → **borderless·직접라벨** 프리셋(신규).
- 의미색 **● 도트**, 다크패널 **primary-dark**, **count-grid**, **노치카드** (신규 장치).

**✔ 긴장 2개 — 후추님 결정(2026-06-24):**
- **(가) 서체 = 산세리프 + ★시스템 안전 폰트.** 발표자료(.pptx)는 타 기기 실행 가능성 높아 폰트 portability 필수 → **맑은 고딕 1순위**(PPT 기본 한글), **나눔고딕 2순위**. Pretendard는 개인 선호이나 우선순위 X(타 기기 미설치 위험). DNA의 세리프 제목 규칙은 이 portability 규칙에 밀림. SoT = `deck-font-safety` 메모리.
- **(나) 강조색 = 톤다운 베이스 + 비비드 강조 1점.** 베이스·데이터는 무채에 가깝게 절제, 강조색만 순채도 1점(≤2/슬라이드). = MezzoMedia/Trending 세련도의 출처. DNA '톤다운'은 베이스에, 강조 1점은 순채도 허용.

## 3. ★ 한글 타이포 규율 (MezzoMedia — 우리 한국어 덱 직접 적용)

- **줄바꿈 = 의미(절) 단위 수동 분절.** 소개문단 각 줄이 완결된 절로 끝남(어절 중간 절단 금지). = 한글 가독 핵심 + AI 티 제거.
- **헤드라인 자간 -2~3%**(한글 Bold 빽빽함 방지) / 영문 대문자 라벨은 자간 +(고급감).
- **본문 행간 1.6~1.7**(한글 받침·복잡자 숨통).
- 한글 단위어 그대로("1,075**억 달러**" — 숫자 크게/단위 작게), 천단위 콤마, 가운뎃점(〮)으로 병렬.
→ 엔진: `ko` 전용 트래킹/리딩 토큰 + 카피 생성 시 "줄당 완결절" 강제.
