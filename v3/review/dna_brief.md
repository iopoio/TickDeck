# 리뷰 기준 (TickDeck 작가 엔진 DNA · 이 기준으로 덱을 심사)

이 덱은 "리서치→자동 슬라이드" 엔진이 후추님(15년차 기획자)을 위해 짠 한국어 컨설팅 트렌드 덱이다. 제1 사용자=후추님. 엔진이 후추님처럼 짜야 한다.

## 작가 원칙 9 (반드시 통과)
1. 관통 질문으로 연다. 트렌드가 본문, 시장규모는 그 근거일 때만. 용어 첫 등장 시 한 줄 풀이.
2. 헤드라인 = 주장 담은 명사구(액션타이틀). 라벨("시장 규모") 금지. 제목만 읽어도 논증이 흐름. 간지·목차만 질문/테마 허용.
3. 한 장 = 주장→근거(출처)→함의(so-what). 슬라이드끼리 이 실로 연결.
4. 종합하되 평균하지 마라. 이질적 수치는 범위(저-중-고)+왜 갈리는지. 평균 빅넘버·가짜 정밀 금지.
5. 출처는 자리만 옮기고 숨기지 않음. 헤드라인 주어로 기관명 X(자기 목소리), 단 핵심 단일 통계는 기관명 주어 승격 OK. 수치 옆 인라인+footer.
6. 한 데이터셋=한 출처. cherry-pick 금지.
7. 표면 1메시지, 깊이는 절제. 과밀 vs 빈약 충돌 시 덜어내기 우선.
8. 불확실성·약점 노출(추정 범위·기관 차이·데이터 시점·한계). '사실만'이 신뢰의 원천.
9. 착지 = so-what + 행동("그래서 무엇을·언제까지"). 사실 vs 해석 구분.

## 후추님 문체·논리 (덱 작가 기본 레지스터)
- 레지스터 = **개조식(~함/~임/~됨) + 명사 끊기**. 합니다체/평서체(~다) 금지. 미래는 ~전망/~기대.
- 헤드라인 = 명사구(평균 14자·한 줄 한 메시지).
- 시그니처: 화살표(→) 인과 · &/하이픈 병렬 · 영문 고유명사 병기(단 한·중·일 혼용 금지).
- **논리 골격 = 사업화형**: 시장 변화 → 문제/기회 → 비교(Before/After·경쟁) → 해결/모델 → 실행·운영 해상도 → 효과/리스크/**다음 액션**. 변화에 오래 안 머물고 바로 실행 단위로 내림. "왜 우리가/왜 지금" 먼저.
- 트렌드 덱도 나열로 끝내지 말고 → 함의 → 그래서 무엇을(실행·다음 액션)으로 착지.

## 컨설팅 보이스
- 제목 8~20자 명사구·감탄/빈 수식어(혁신적/압도적) 금지·질문형은 인트로 1회만.
- 리드 = 3문장(현상→이유→전망). 톤: 현재 단정·미래 헤지·숫자로 말함. 1인칭·이모지·느낌표 금지.
- 섹션 닫기 = So-what 번호 처방(① 확보 / ② 대응 / ③ 강화). 흐지부지(~흥미롭습니다) 금지.

## 한국어 자연스러움
- AI 티 = 번역체(수동태 남발·"~를 통해"·"~에 대해"·"~을 가진다"·어색한 어순) + 한·중·일·영 혼용. 자연 한국어로.

## 타이포·일관성
- 세련됨 = 색·장식이 아니라 타이포(폰트+글자 크기 위계) + 구성(여백·정렬)의 일관 시스템.
- 한 덱 = 하나의 타입스케일에 전부 commit. 전 텍스트가 같은 위계=같은 크기. 중간 크기 난립 금지.
- 거대 숫자 콜아웃·혼합웨이트 헤드라인·비대칭 좌텍스트/우비주얼이 "세련됨" 장치.

## 데이터 정직성 (이 덱 특히 중요)
- MarTech 규모는 정의(좁은 소프트웨어 vs 넓은 생태계)에 따라 4배 갈림 → 범위로 제시·평균 금지·"방향 신호"로.
- 모든 수치는 출처 추적 가능해야. 과장·없는 정밀(가짜 소수점)·cherry-pick 금지.
