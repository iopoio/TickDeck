## ★ 새 델타 — 흡수 대상 (키미/현 DNA 너머)

### A. 색·팔레트 실행 규칙
- **60-30-10** (qwen·minimax): 중립 배경 60 / 보조 30 / 액센트 10. 액센트는 정말 중요한 곳만.
- **색 의미 사전 1장 고정 → 전 슬라이드 일관** (전원): 빨강=위험/감소 · 초록=성장 · 회색=비교군/과거. 의미 흔들리면 청중이 데이터를 의심.
- **적록 동시 사용 회피(색약 8%) + 대비 WCAG 4.5:1** (전원): 노랑글씨+흰배경 금지. `#0F172A`/`#F8FAFC`가 검정/순백보다 부드럽고 안전.
- **한 슬라이드 = 액센트 1개** (minimax·kimi): 강조점 2개면 강조점이 없는 것.

### B. 타이포 실행
- **크기 점프 ≥1.5배** (qwen·minimax·kimi): 24→28 실패, 24→36 성공. 인접 크기는 위계가 안 읽힘. → 우리 "전 텍스트 스케일 통일" 규칙에 *점프 간격 수치* 보강.
- **폰트 ≤2개** (전원): 헤딩 1 · 본문 1(또는 같은 폰트 굵기 차이만).
- **좌측 정렬 기본, 중앙정렬 회피** (qwen): 중앙정렬은 시선 분산.

### C. 데이터 시각화 (우리 차트 모듈 H·I·J·K·L에 직접 입힐 규율)
- **그레이아웃 강조** (전원 = 가장 강한 신호): 비교군 전부 회색 `#E5E7EB`, 주장하는 데이터 1개만 브랜드색. 전체를 컬러로 칠하면 아무것도 안 보임.
- **차트 직접 주석 = 차트의 BLUF** (qwen·minimax): 차트 옆 텍스트박스 X → 핵심 데이터 포인트에 화살표+한 줄 직접.
- **직접 라벨 > 범례** (minimax): 선 옆에 라벨을 두어 눈 왕복 제거.
- **파이차트 회피(3+ 항목)** (전원): 가로막대·도넛·100% 누적막대로 대체.
- **Y축 0 시작 · 이중축·3D 금지** (전원): 축 truncation = 거짓말. G5/G6의 차트판.

### D. 레이아웃·여백
- **focal point 1개** (qwen·minimax): 큰 도형 / 진한 색 / 큰 글씨 중 하나만.
- **Z-패턴 4지점** (minimax): 좌상 헤드라인 → 우상 시각 → 좌하 보조 → 우하 CTA.
- **여백은 콘텐츠** (전원): 화면 40%만 차도 OK, 80% 채우면 싸 보임. → 우리 여백 그리드 규율 강화.

### E. 스토리 무브 (델타)
- **헤드라인 5단계 강화 공식** (minimax): 사실 → 비교 → 인과 → 행동 → 감정. 3단계 이상이면 강한 슬라이드.
- **PASA** (glm): Problem → Agitation → Solution → Action. 회사소개·역사를 첫 장에 두지 말 것.
- **바이트앤스위치 색** (qwen): 문제/경쟁 설명 = 어둡게·회색 → 솔루션/미래 = 순백+브랜드색 터뜨림 → 청중이 물리적 해방감을 착각. 우리 "사업화형 Before/After"의 시각 장치로.
- **로고 수프 → 숫자 1줄** (minimax): 고객사 로고 20개 X → "52개사 도입" 1줄이 더 강함.
- **CTA로 닫기** (전원): "감사합니다" X → "다음 단계 = 이 링크/일정/결정사항". 우리 G7(사업화형 착지) 보강.

### F. QA 기법 (파이프라인 게이트 추가 후보)
- **스쿼트 테스트** (qwen): 눈 가늘게 뜨고 흐리게 봐서 시선·명암 대비 점검. 핵심과 잡음이 섞여 보이면 실패. (시각 QA 한 줄짜리 강력 도구.)
- **Q&A 5문항 고스트 슬라이드** (qwen·minimax): 예상 반박 5개를 답 슬라이드로 만들어 부록에 무장.
- **시간 = 슬라이드 수 × 2분** (minimax·kimi): 30분 발표 = 15장.

## ⚠️ 우리 것과 충돌 — 무지성 수용 금지
- 4모델 전원 "스크린=산세리프(Pretendard/Noto)" 권고. 그러나 우리 = **에디토리얼 세리프(Hahmlet) + 개조식 = 의도된 타이포 차별화.** 우리 덱은 투사 발표용이 아니라 "읽는 PDF/리포트 덱"이라 세리프 가독성 문제 적음. → 산세리프 권고는 *투사 발표 덱*에만 적용, 우리 기본은 유지 (후추님 디자인 게이트).
- 본문 24pt 하한 = 투사 기준. 읽는 덱은 더 작아도 됨.
- 10-20-30·슬라이드 수 가이드 = 발표용. 우리 컨설팅/리포트 덱과 결 다름 → 골격만 참고.
