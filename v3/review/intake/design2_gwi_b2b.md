## PDF 1 — GWI "Connecting the Dots 2026"

**디자인 한 줄 요약**: 흑/백/마젠타 3색 극단 미니멀. "선(pill bar)+점(dot)"이라는 단일 그래픽 모티프를 타이틀·디바이더·차트 전반에 일관 적용한 **모티프-주도 시스템**. 라이트(연보라 틴트) 본문 ↔ 풀블랙 디바이더 교차.

### NEW 패턴 (흡수가치)

**1. 모티프-드리븐 타이포 빌드 — 글자를 "선+점"으로 조립 (커버)** · 흡수가치 **중**
- 레이아웃 맵: 거대 헤드라인의 글자(C, o, d, o)를 둥근 pill-bar와 원형 dot로 치환·조립. 마젠타 dot가 'o' 자리를 차지. 배경 흑, 글자 백+마젠타.
- "connecting the dots"라는 메시지를 형태로 시각화 = concept-as-form. 우리 엔진엔 글자 조립은 무리지만, **"키워드 1개를 그래픽 도형으로 치환"** 아이디어는 커버 변형으로 차용 가능(낮은 우선).

**2. 라운드 pill "number chip" + 점 부착 디바이더** · 흡수가치 **상**
- 레이아웃 맵: 섹션 디바이더(흑 배경) 좌상단 = 흰 pill 탭 안에 마젠타 섹션번호("05"), 탭 끝에 마젠타 lozenge/dot 부착. 아래 거대 헤드라인은 **마젠타+백 혼색·bold 강조어 혼용**. 화면 곳곳에 pill-bar와 dot를 떠다니는 장식으로 흩뿌림.
- 우리 "킥커+거대헤드"의 진화형: 킥커를 **숫자 chip(알약형 배경 도형)** 으로 격상 + 단색 floating 도형으로 여백 채우기. 단일강조색 1개로 구현 가능 → **바로 흡수 권장**.

**3. 히트맵 매트릭스 표 (heatmap cell table)** · 흡수가치 **상** ★최우선
- 레이아웃 맵(p14): 좌측 본문 컬럼 / 우측 2열×5행 매트릭스. **셀 배경색 = 단일색 채도램프로 값을 인코딩**, 숫자는 셀 안에 흰 텍스트. 행 라벨 = 리커트 척도(1-Always impulsive → 5-Always planned). 열 헤더에 ▼ 삼각 포인터 글리프, 데이터 출처 표시용 원형 "%" chip.
- 우리가 가진 "단일강조색+명도램프"를 **표 셀에 적용**한 형태 = 신규 차트타입. Gemini가 만든 수치 매트릭스를 색농도 셀로 렌더 → 정보밀도 높은 슬라이드 1장. **엔진에 신규 모듈로 추가 권장.**

**4. 덤벨/도트플롯 비교 차트 (dumbbell dot-plot + delta column)** · 흡수가치 **상**
- 레이아웃 맵(p21): 행마다 2개 시리즈를 점으로(Gen Z=마젠타 dot, All=흑 dot) 같은 가로축에 찍고, 각 점 옆에 수치 직접라벨. **맨 오른쪽에 "% difference" 델타 컬럼**(+20%, -4%)을 별도 정렬. borderless·정렬됨·범례는 색점.
- before/after는 가졌지만 "두 그룹 동시 비교 + 차이값 컬럼"은 신규. 2-시리즈 비교 데이터에 강력. **신규 차트 변형으로 흡수 권장.**

**5. 라디얼 게이지 / 링-스탯 리스트 (radial progress ring stack)** · 흡수가치 **중**
- 레이아웃 맵(p25): 우측 패널에 원형 progress ring(마젠타 호 + 연핑크 트랙) 세로 스택, 중앙에 거대 %, 옆에 한 줄 설명. 좌측은 본문. 패널 제목은 2색 처리("True fans:" 마젠타 / 부제 흑).
- 우리 "거대숫자 콜아웃"의 시각화 변형 = 숫자에 원형 게이지를 입힘. 4개 stat 리스트에 적합. **콜아웃 모듈의 옵션 렌더로 흡수 가능.**

**6. 인용 템플릿 — 거대 따옴표 + 2색 브랜드 워드마크 + 원형 아바타** · 흡수가치 **중**
- 레이아웃 맵(p5·8·17): 좌 60% 거대 인용문 + 좌상단 **거대 마젠타 따옴표 글리프**를 비주얼 앵커로. 우측 레일 = "Ask our customers" 킥커 + **2색 브랜드 워드마크**(bold흑 + 컬러: "Accenture Song", reddit 로고) + **마젠타 백플레이트 원형 아바타** + 직책.
- 인용/증언 슬라이드 표준 템플릿. 거대 따옴표를 색 도형처럼 쓰는 게 포인트. **인용 슬라이드 타입으로 흡수 권장.**

**7. 그라데이션 배경 클로징 + sparkle 글리프 + UI 목업 카드** · 흡수가치 **하**
- 레이아웃 맵(p37): 부드러운 연보라 그라데이션 배경, 큰 다크 헤드, 마젠타 버튼, 떠다니는 챗/UI 목업 카드 + 마젠타 4점 sparkle(✦) 글리프.
- 그라데이션 면 + sparkle 장식은 트렌디하나 우리 "단색면" 기조와 충돌. 클로징 1장 변형으로만 참고.

### 비주얼 장치 / 타이포·색
- **floating 도형 장식**: pill-bar + dot를 본문 없는 여백에 흩뿌려 흑 배경의 공허 방지(디바이더·p29). 단색 1개로 가능 → 흡수 쉬움.
- **인라인 컬러 강조어**: 본문 문장 중 핵심 구절을 마젠타로(p25 "World Cup hub"). 우리 강조색 텍스트 적용과 동일 계열(이미 보유, 참고만).
- **데이터 origin "%" 원형 chip**: 차트마다 단위/출처를 작은 원형 배지로(p14·33). 차트 메타 표기 장치로 차용 가능.
- 사진 사용: 라이프스타일 스톡사진을 본문 우측 풀블리드로(p3). 우리 엔진은 사진 소스 없음 → 비적용.

### 판정 — GWI
**흡수할 게 많다.** 차트 3종(히트맵매트릭스·덤벨도트플롯·라디얼게이지)이 모두 우리 "단일강조색+명도램프" 자산을 **신규 차트타입으로 확장**하는 직접 후보. number-chip 디바이더·인용 템플릿도 즉시 흡수 가능. 단색 1개로 전부 구현되어 우리 엔진 제약과 궁합 최상.

## PDF 2 — Collective Measures "2026 Trends B2B"

**디자인 한 줄 요약**: 네이비 베이스 + **섹션별 컬러코딩(coral/blue/amber)** 4색 시스템. 라운디드-그로테스크 헤드 + 청키 chevron "상승 트렌드선" 코너 그래픽이 커버↔클로징을 북엔드. 섹션마다 강조색이 바뀌는 wayfinding이 핵심.

### NEW 패턴 (흡수가치)

**1. 섹션별 컬러코딩 + 컬러 동기화 목차 (color-coded section system)** · 흡수가치 **상** ★최우선
- 레이아웃 맵(p4 목차): 3컬럼, 각 항목 = **솔리드 컬러 정사각 블록 안 숫자**(1=coral·2=blue·3=amber), 그 아래 헤드라인의 **마지막 강조구절을 자기 번호색과 동일색으로**("competitive edge"=coral, "entertain"=blue, "everything"=amber).
- 섹션 진입 시 그 색이 헤드 숫자·강조어·breadcrumb·footer chip에 일관 반복 = 독자 길찾기. **우리는 단일강조색 1개 → "섹션마다 강조색 슬롯을 교체"하는 멀티색 변형으로 확장 가능.** 멀티-챕터 덱에 강력. 흡수 권장.

**2. 러닝 섹션 breadcrumb (top-corner italic colored header)** · 흡수가치 **상**
- 레이아웃 맵(p6·12): 우상단에 현재 섹션명을 **이탤릭·섹션색**으로 작게 표기("Strong brand presence delivers a competitive edge"). + footer에 섹션 태그 chip("B2B" amber chip).
- 긴 덱에서 "지금 어느 섹션" 상시 표시 = 방향감. 공통셸에 **코너 breadcrumb 슬롯** 추가로 흡수. 단색으로도 동작.

**3. 풀블리드 솔리드 컬러 플러드 디바이더 (full-color flood + 거대 카테고리 라벨)** · 흡수가치 **중**
- 레이아웃 맵(p2): 화면 전체를 saffron 단색으로 채우고 좌측 거대 "B2B" 라벨 + 얇은 수직 룰 + 우측 헤드라인 statement(이탤릭 강조절). 섹션마다 다른 색 플러드.
- 우리 라이트/다크는 가졌지만 "**강조색 자체를 풀블리드 배경으로**"는 신규. 디바이더 강도 최대치. 섹션색과 연동 시 강력. 흡수 권장.

**4. 컬러 정사각 number-block enumeration** · 흡수가치 **상**
- 레이아웃 맵(p4·8): 숫자를 **솔리드 컬러 사각 블록**에 흰/흑 숫자로 박아 리스트/스텝 마커로. (GWI의 pill-chip과 형태만 다른 동일 발상 — 사각 vs 알약.)
- 모듈러 리스트의 번호 마커를 색면 블록으로 격상. 즉시 흡수 가능.

**5. 좌측 세로 풀블리드 사진 + 우측 스탯리스트 분할** · 흡수가치 **중**
- 레이아웃 맵(p3): 좌 1/3 = 세로 풀블리드 사진(얇은 강조색 엣지), 우 2/3 네이비에 거대% + 강조어 포함 단락 스택.
- 50:50은 가졌지만 "1/3 세로사진 + 2/3 스탯리스트" 비율 변형. 사진 소스 있을 때만. 참고.

**6. 케이스-스터디 카드 스택 (스크린샷 2장 세로 적층)** · 흡수가치 **하**
- 레이아웃 맵(p8): 우측에 광고/사이트 예시 스크린샷 2장을 깔끔한 카드로 세로 적층. 좌측 거대숫자 섹션라벨.
- 예시 이미지 갤러리. 이미지 의존 → 우리 비적용.

### 비주얼 장치 / 타이포·색
- **chevron/zigzag "상승 트렌드선" 코너 그래픽**(p1·14): 청키한 nested chevron 리본(cream+coral+blue 평행 스트로크)을 코너에 앵커. 커버=우하단, 클로징=우상단 미러로 북엔드. 브랜드 시그니처 도형. 우리도 **"단색 기하 코너 모티프 1개"로 커버/클로징 묶기** 차용 가능.
- **인버티드 콜아웃 카드**(p6): 네이비 본문 위에 cream 단색 카드를 우측 엣지로 bleed. 강조 박스 = 명도 반전 카드. 흡수 쉬움.
- **이탤릭 강조어 + 색 강조**: 헤드라인 마지막 절을 이탤릭+섹션색으로(p2·4·8). 강조 이중화(기울임+색).
- **CTA 버튼 + 커서 글리프**(p14): coral 버튼에 hand-cursor 아이콘 → "클릭 가능" 시각 암시. 클로징 CTA 장치.
- 타이포: 라운디드 그로테스크(둥근 단말) 헤드 1패밀리로 친근·B2B톤 완화.

### 판정 — B2B
**흡수할 게 중상.** 핵심은 **"섹션별 컬러코딩 시스템"**(목차·breadcrumb·플러드·번호블록·강조어가 한 색으로 묶임) — 우리 단일강조색 엔진을 **멀티-챕터 컬러 슬롯**으로 확장하는 명확한 청사진. 코너 chevron 북엔드·인버티드 카드·number-block도 단색으로 즉시 흡수 가능. 사진·케이스카드는 소스 의존이라 보류.
