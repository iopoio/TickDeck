# PART A — 디자인 분해

## 1. 전체 시스템 (그리드·여백·리듬·라이트/다크)

**라이트/다크 이원 구조 — 색이 곧 정보 위계의 1차 신호:**
- **다크(어두운 적흑 그라데이션)** = 표지·인덱스·섹션 간지·클로징. 즉 "챕터 경계 = 어둠". 독자에게 "여기서 큰 단위가 바뀐다"를 색면으로 통보.
- **라이트(순백 #FFFFFF 배경)** = 모든 본문/데이터/비교 페이지. 정보 밀도 높은 페이지는 100% 화이트 → 잉크(검정·빨강)만으로 위계 구성.
- 이 이원 리듬이 31p 전체에 일정하게 반복 → 독자가 "지금 챕터 안 어디쯤"인지 색으로 감지(rhythm by theme).

**그리드 (라이트 본문 기준, p4·p24·p28 관찰):**
- 좌우 동일 마진 추정 ~5–6% (≈ 1440px 폭에서 좌우 70–80px). 상단 마진 넉넉(~7–9%).
- 헤드라인은 좌상단 고정 **앵커**. 본문 소개문단 그 아래 좌측 정렬 블록.
- 페이지 하단 절반~2/3는 **비주얼 존**(차트·카드·표). 즉 "상단=언어, 하단=시각" 수직 2분할이 기본 골격.
- 멀티칼럼: 데이터 2개 → 좌/우 50:50 (p4 막대+도넛). 카드 → 4열(p20) 또는 2열(p12). 표 → 좌/우 대칭(p28 비교).

**화이트스페이스:**
- 본문 페이지 화이트스페이스 비율 매우 높음(체감 40%+). 차트 주변에 의도적 공백 → 빅넘버/빨강 데이터가 숨쉴 공간 확보.
- 텍스트 블록은 절대 폭 꽉 채우지 않음 — 소개문단도 우측에 여백 남김(가독 행폭 제한).

**페이지 리듬(반복 패턴):**
`다크 간지 → 라이트 본문(소개) → 라이트 데이터 → 라이트 프로세스/카드 → 라이트 비교 → (다음)다크 간지`. 챕터 4개(AI/Discovery/OTT/DOOH)가 동일 리듬 반복.

**색의 규율 (핵심):**
- **빨강 = "여기 봐"의 단일 토큰.** 한 차트에 빨강은 보통 한 막대(p4 2028년 1,075억)·한 슬라이스(p4 32%)뿐. DOOH 막대(p24)에선 "DOOH 매출" 한 계열만 빨강 → 나머지 전체 검정.
- **검정→그레이 단계 = 데이터 중요도 그라데이션.** 채도 없이 명도만으로 1·2·3순위 표현(도넛: 빨강32 → 검정43 → 진그레이21 → 연그레이3).
- **톤:** 본문은 **고대비 모노크롬+단일 비비드 레드**. 톤다운 아님 — 채도 빠진 흑백 위에 순수 채도 레드 1점 → 명료·단호한 인상. 다크 페이지만 그라데이션으로 무드(분위기).
- 브랜드 인용 색(NAVER 그린·kakao 옐로)은 "그 브랜드를 가리킬 때만" → 데이터색이 아니라 **로고색 인용**. [브랜드전용·복제금지]

**위계(상대 스케일, 라이트 본문 기준):**

| H2 서브헤드 | "마케팅 산업 내 AI 활용 증가" | ~16–18pt (0.6×) | Bold | 잉크블랙 |

- 위계 비율: H1 : H2 : Body ≈ **2.4 : 1.4 : 1**. 점프가 큼 → 헤드라인이 압도적으로 시선 선점.
- **헤드라인 처리:** 좌상단 고정 + 그 위에 작은 **빨강 액센트 바(■ 짧은 굵은 가로 막대, ~40×6px)**를 헤드라인 윗줄에 배치 → "섹션 마커" 역할(p4·p24·p28 공통). 간지 다크 페이지는 헤드라인 **중앙 정렬+영문 대문자**(AI MARKETING / OTT), 위에 작은 라벨 "MARKETING TREND 1".

**숫자/통계 스타일링(★):**
- 빅넘버는 **Bold, 단위는 작게**("1,075**억 달러**" — 숫자 크게/단위 작게). 막대 위 라벨로 직접 표기(축눈금 의존 X).
- 강조 수치만 **빨강+Bold**(도넛 중앙 "32%", DOOH 비율 "36%").
- 천단위 콤마 사용(1,075). 한국식 단위 혼용("억/조 달러" — 한글 단위어 그대로).

**★한글 타이포 처리(관찰):**
- **헤드라인 자간(트래킹) 살짝 좁힘**(-2~-3% 추정) → 한글 Bold가 빽빽해 보이지 않게. 단 영문 대문자 간지(OTT)는 자간 **넓힘**(레터스페이싱 +로 고급감).
- **줄바꿈은 의미 단위로 수동 분절** — 소개문단이 3줄일 때 각 줄이 완결된 절(節)로 끝남(어절 중간에서 안 끊음). 한글 가독 핵심 규율.
- **행간(leading) 넉넉**(본문 ~1.6~1.7배) → 한글 받침·복잡 글자 숨통.
- 영문/숫자가 한글과 섞일 때 동일 베이스라인 정렬, 영문은 약간 작은 시각보정 없이 그대로(폰트 자체 한글최적).
- 한글 약물(〮 가운뎃점)로 병렬 항목 구분("대화〮음악〮효과음").

## 5. 데이터 비주얼 스타일

- **세로 막대(p4):** 축선 최소(눈금선 거의 없음), 막대 위 **직접 값 라벨**, 마지막(미래/핵심) 막대만 **빨강**, 나머지 검정. 미래값에 "(E)" 표기.
- **도넛(p4):** 4슬라이스, 채도는 빨강 1개만, 나머지 흑→회 명도단계. **중앙에 핵심 수치 빨강 빅넘버**("32% 완벽히 도입"). 우측에 순위 리스트(1·2·3위) 가는 구분선으로.
- **콤보 차트(p24):** 검정 막대(전체) + 내부 빨강 세그먼트(DOOH 부분) + 위에 검정 꺾은선(증감율%) + 빨강 텍스트로 비중% 강조. 한 차트에 "절대값·구성비·성장률" 3정보를 색으로 분리.
- **빅넘버 처리:** 숫자 Bold 대형 / 단위·라벨 작게 / 핵심만 빨강. 차트 제목은 가운데 위, 출처는 그 바로 아래 작은 회색.
- 전반적으로 **격자선·박스테두리 제거**(borderless), 데이터잉크 비율 높임.

## 6. ★ 훔칠 규율 (재사용 가능 — 우리 덱 엔진 흡수용)

1. **단일 강조색 규율(THE 빨강 1점):** 한 슬라이드/차트에 강조색은 "가장 중요한 단 하나"에만. 나머지는 흑→회 명도단계로. → 엔진: `accent` 토큰 1개 + `ink/gray-700/gray-400` 명도 램프로 데이터 중요도 인코딩. 강조색 사용 카운트 ≤2 규칙.
2. **테마=챕터경계 규율:** 다크(간지/표지/클로징) vs 라이트(본문) 이원. 챕터 전환을 색면으로 통보. → 엔진: `slideType`에 `divider/cover/closing=dark`, `body/data/compare=light` 자동 매핑.
3. **좌상단 헤드라인 + 빨강 액센트 바 규율:** 본문 페이지는 "■ 짧은 강조바 → H1 → H2 → Body 3줄"의 좌상단 앵커 블록 고정. → 엔진: 본문 마스터에 `accent-bar(40×6) + h1 + h2 + body` 고정 슬롯.
4. **상단언어/하단시각 2분할 규율:** 페이지 상단=텍스트 블록, 하단 2/3=차트/카드/표. → 엔진: 본문 레이아웃 기본을 수직 2존(text-zone / visual-zone)으로.
5. **borderless 데이터잉크 규율:** 차트 격자선·테두리 제거, 막대 위 직접 라벨, 축눈금 최소. → 엔진: chart preset = no-gridline, direct-label, axis-min.
6. **타입스케일 큰 점프 규율:** H1:H2:Body ≈ 2.4:1.4:1로 위계 점프를 크게(미지근한 1.2배 금지). → 엔진: type scale 토큰을 보수적 1.2가 아닌 1.5~1.7 비율로.
