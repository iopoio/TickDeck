## ① WPP Media Trends UK 2026

**디자인 한 줄 요약:** 네온 그라데이션 + "오비탈 리본(궤도 띠)" 모션 그래픽을 시그니처로 박은 다크/라이트 교차 에디토리얼 — 챕터마다 거대 번호·꽉 찬 헤드라인이 표지처럼 도배되는 고채도 브랜드 덱.

### 레이아웃 맵(샘플 페이지)
- **표지/챕터표지(p1·p7·p14·p34):** 화면 우상단~좌하단을 가로지르는 **궤도 리본 2~3가닥**(네온 그린·블루·바이올렛)이 거대 타이포 위/아래를 감음. 거대 챕터번호("01"·"02") 우상단 워터마크급 배치 + 헤드라인이 baseline 그리드 무시하고 **2색·2크기로 한 단어씩 끊겨** 쌓임("INTERFACES / REIMAGINED").
- **본문 2단(p10·p18·p22·p46):** 좌측 킥커 pill("AREA TO WATCH") + 본문 2단 그리드. 우측에 **고채도 풀블리드 사진 카드**(라운드 코너) 또는 거대 통계 콜아웃 카드.
- **통계 콜아웃(p10):** "58%" 같은 거대숫자를 **반투명 다크 카드 + 라운드 코너**에 얹고 본문과 분리 — (우리 거대숫자 콜아웃의 *카드화* 변형).
- **다이어그램(p40·p50) "Brand Considerations":** 라이트 배경에 **둥근 사각 노드 4~6개를 ㄱ자/지그재그 커넥터 라인으로 잇는 플로우**. 각 노드 = 볼드 제목 + 2~3줄. 노드 꼭짓점에 **마름모(diamond) 조인트 마커**. → 수렴도식과 다른 **"순차 연결형 권고 다이어그램"**.

### NEW 패턴 (흡수가치)
1. **오비탈 리본 / 궤도 띠 모션 그래픽** *(흡수가치: 중)*
   화면을 대각으로 가로지르는 2~3가닥 그라데이션 곡선 띠 = 브랜드 시그니처 전환장치. 표지·챕터표지·divider 전반에 반복돼 **단일 그래픽 모티프로 덱 전체를 묶음**. TickDeck엔 SVG 베지어 1~2가닥 + 강조색 그라데이션으로 cover/divider 한정 옵션화 가능. (남용 시 산만 → 표지·divider만.)

2. **거대 챕터번호 워터마크 + 단어 분절 헤드라인** *(흡수가치: 중)*
   "01"·"INTERFACES/REIMAGINED"처럼 **번호를 헤드라인 뒤 거대 고스트로 깔고**, 헤드라인을 단어 단위로 줄바꿈해 2색/2크기로 쌓는 표지 아키타입. 우리 킥커+거대헤드라인의 **"넘버드 섹션 표지" 전용 변형**. (한글은 어절 단위 끊기로 이식 — p14 처럼.)

3. **노드-커넥터 권고 다이어그램(diamond 조인트)** *(흡수가치: 상)*
   "다음에 뭘 해야 하나"형 권고/액션을 **4~6 라운드 노드 + 꺾인 커넥터 + 마름모 조인트**로 잇는 도식. 우리 수렴도식(여러 입력→1결론)과 **방향이 반대**(1주제→여러 액션 분기). 결론/액션 슬라이드용 신규 아키타입으로 가치 높음. → `diagram_type: branched_actions` 후보.

4. **반투명 다크 카드 위 거대숫자** *(흡수가치: 중)*
   거대 통계를 본문에 박지 않고 **라운드 코너 반투명 패널**에 얹어 사진/그라데이션 위에 떠 있게. 우리 거대숫자 콜아웃에 **카드 컨테이너 + glass 톤** 옵션 추가하면 사진 배경 슬라이드에서 가독 확보.

5. **고채도 듀오톤 사진 카드** *(흡수가치: 하)*
   사진을 라운드 코너 + 강조색 오버레이로 통일. 우리 단일강조색 시스템과 충돌 적음. 톤 통일 장치로만 참고.

## ② Deloitte Digital Media Trends 2026

**디자인 한 줄 요약:** 디자인된 "덱"이 아니라 **웹 아티클을 PDF로 뽑은 롱폼 리포트** — 본문은 세리프 1단, 디자인 자산은 회색 패널 안의 절제된 차트 블록뿐. 시각적으로 가져올 건 **차트 처리 규약** 하나로 수렴.

### 레이아웃 맵
- **표지/본문(p1·p2·p3):** 좌상단 Deloitte Insights 로고 → 굵은 검정 룰 바 → **블랙 슬랩-세리프 거대 타이틀** → 회색 메타라인(Article · 11-min read · 날짜). 본문은 **세리프 1단**(폭 좁은 measure). 디자인 의도가 거의 없는 에디토리얼.
- **메트릭 박스(p2):** 본문 상단에 **얇은 라운드 보더 박스 + 불릿 통계 리스트**("6 hours – …", "90% – …"). 숫자를 문장 앞에 두는 **"수치-대시-설명" 불릿** 포맷.
- **차트 블록(p4·p5·p6):** 본문 흐름 안에 **연회색 풀폭 패널**을 끼우고: ① "Figure N"(이탤릭 라벨) → ② **볼드 슬랩 제목** → ③ 이탤릭 부제("Percentage of fans who agree…") → ④ 차트. 캡션 위계가 항상 3단 고정.

### NEW 패턴 (흡수가치)
1. **회색 패널 "Figure 블록" 규약** *(흡수가치: 상)*
   차트를 본문 톤과 분리하려고 **연회색 배경 패널 안에 [Figure N 라벨 → 볼드 제목 → 이탤릭 부제 → 차트] 4요소를 항상 같은 위계로** 박는 규약. TickDeck 차트 슬라이드의 **표준 캡션/컨테이너 스펙**으로 직수입 가치 높음(현재 우리 차트는 직접라벨만 있고 *figure-block 캡션 위계*는 없음). → chart slide에 `figure_label · title · subtitle` 3슬롯 + panel bg 토큰.

2. **미러형(분기형) 막대 차트 + 중앙 라벨 스파인** *(흡수가치: 상)*
   p4 Figure 2: **좌우 두 개의 가로 막대 세트를 거울처럼 마주보게** 두고, 카테고리명(Generation Z·Millennials…)을 **정중앙 라벨 컬럼**에 한 번만 둠. 두 지표를 **한 행에서 직접 비교**시키는 강력한 비교 도식. 우리 before/after와 다른 **"동일 그룹 × 두 질문" 양면 비교** 아키타입. → `chart_type: diverging_mirror` 후보. (각 막대 끝/안에 값 직접라벨은 우리 패턴과 일치 → 그대로 합쳐짐.)

3. **값-인-바 + 짧은 축 스파인** *(흡수가치: 중)*
   막대 안/끝에 % 직접 라벨, **0축만 짧은 검정 수직선으로 그리고 격자·축선 전부 제거**. 우리 borderless 차트의 한 단계 더 미니멀한 변형 — "축은 0선 1px만" 규칙으로 흡수 가능.

4. **"수치-대시-설명" 불릿 통계 박스** *(흡수가치: 중)*
   "90% – US households that…"처럼 **수치를 불릿 맨 앞에 고정**하고 대시로 설명을 잇는 메트릭 리스트. 거대숫자 콜아웃까지 안 가는 **다중 통계 요약 슬라이드**용 경량 포맷. 라운드 보더 박스에 6~8개 묶기.
