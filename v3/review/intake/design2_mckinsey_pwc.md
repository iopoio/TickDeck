## A. McKinsey — State of Marketing Europe 2026 (50p)

**한 줄 요약:** 절제된 네이비-단색 에디토리얼 리포트 — "Exhibit 넘버 + 액션타이틀(완전한 문장형 차트 제목) + borderless 차트" 3단 규약이 전 차트를 지배하고, 본문은 세리프 헤드/2단 텍스트의 책-같은 조판. 우리 차트 스택과 겹치는 부분 많음(직접라벨·단색·다크대시보드). 단, **조판·exhibit 규약·정보그래픽 다양성**에서 차별 패턴 다수.

### NEW 패턴 (우리에 없는 것)

| # | 패턴 | 레이아웃 맵 | 흡수가치 |
|---|------|-----------|---------|
| A1 | **Exhibit 규약: 넘버 + 액션타이틀** | 차트 위에 「Exhibit N」(작은 라벨) → **완전한 주장 문장**을 차트 제목으로(예: "Surveyed marketers aim to increase investment…") → 차트. 우리의 킥커+헤드라인과 다름: 여기선 *차트마다* 넘버링·문장형 takeaway 제목 규약화. (p31, p21) | **상** — 데이터 슬라이드 제목을 "명사구"가 아니라 "검증된 주장 문장"으로. 우리 엔진이 차트 슬라이드에 takeaway-as-title 규칙 추가 가치 큼 |
| A2 | **Bar-on-track (0–100 회색 트랙 위 채움바)** | 각 수평바 뒤에 전체 100% 회색 트랙을 깔고, 그 위에 네이비 채움바 + 바 안 값라벨. 우측 끝에 「100」 축 눈금 1개만. (p31, p21) | **중** — 우리 borderless 바와 다른 변형. "share-of-100"을 트랙 대비로 즉시 읽힘. 막대 차트 변형으로 추가 가치 |
| A3 | **델타 주석 (bar 사이 변화량 콜아웃)** | 두 바를 비교할 때 한쪽 바 끝~트랙 사이 빈공간에 「−27 percentage points」를 점선 가이드와 함께 박아넣음. (p21) | **상** — before/after는 있으나 *변화량 자체를 차트 위에 직접 주석*하는 장치는 신규. 비교 차트에 델타 라벨러 추가 |
| A4 | **Facts & Figures 다크 대시보드 1p** | 단일 다크 페이지에 이질적 차트 4종 혼합 배치: ①비례 원(버블) 클러스터 ②거대 72% 콜아웃 ③아이소타입(사람 픽토그램 격자) ④스택 가로바. 좌상단 알림-pill(원형 i 아이콘 + takeaway 1문장). (p13) | **상** — "한 페이지 = 한 차트" 관성을 깨는 **혼합 통계 대시보드 레이아웃**. 우리에 없는 멀티-위젯 1페이지 아키타입 |
| A5 | **비례 원(버블) 클러스터** | 국가별 시장규모를 면적-비례 원으로, 유기적으로 군집 배치. 각 원에 값+국가명+성장% 직접라벨. 지도형 배열(영국/독일 위치 암시). (p13) | **중** — 카테고리별 크기 비교용. 우리 차트군에 없음. 단 자동생성 난이도 중상 |

| A8 | **우측 사이드바 inset 박스** | 2단 본문 옆/안에 틴트 박스로 "Case example/방법론" aside를 본문과 분리해 띄움. (p24) | **중** — 곁텍스트(aside) 모듈. 본문에 보조정보 레이어 1개 추가 |

| A10 | **풀블리드 에디토리얼 일러스트(브리더)** | 한 페이지 전체를 브랜드 블루 한정팔레트 플랫-벡터 일러스트로 채움(요트/태양 글로우 그라데). 챕터 사이 호흡용 아트 페이지. (p1 표지, p40) | **중** — 우리에 사진/일러스트 브리더 슬라이드 없음. 단 일러스트 자동조달이 난점(스톡/생성 필요) |
| A11 | **기여자 좌-레일 리스트 (원형 헤드샷)** | 저자/기여자를 원형 헤드샷 + 이름·역할 짧은 단락으로 좌측 리스트 정렬. 인트로 하단엔 서명처럼 작은 원형 헤드샷을 한 줄로. (p4, p6) | **하** — 자동 URL 덱엔 기여자 데이터가 거의 없음. 흡수가치 낮음 |

**SOE 판정:** **흡수할 게 많음(상).** 다만 핵심은 *차트 종류*가 아니라 **규약·조판 레이어** — ①Exhibit 액션타이틀 규칙(A1) ②델타 주석(A3) ③혼합 통계 대시보드 1p(A4) ④본문 인라인 스탯/aside(A7·A8) ⑤산세/세리프 페어링(A9). 이 5개가 우리 엔진을 "차트 나열"에서 "컨설팅 리포트"로 끌어올리는 지렛대.

## B. PwC — AI 시대의 마케팅 (17p, 한국어)

**한 줄 요약:** 화이트 베이스 + **단일 오렌지 강조(주황/버건디)** + 각진 PwC 스워시 + 본문 산세리프의 깔끔한 컨설팅 덱. 차트는 적지만 **반복되는 시그니처 템플릿 2종**(좌-레일 타이틀블록 + 상승형 3컬럼 비교 + 멀티플라이어 브래킷 / 거대 멀티플라이어 콜아웃)이 강력. 우리와 색 운용은 유사하나 **차트-제목 좌레일화·브래킷 델타·매트릭스·피라미드** 등 차별 패턴 있음.

### NEW 패턴 (우리에 없는 것)

| # | 패턴 | 레이아웃 맵 | 흡수가치 |
|---|------|-----------|---------|
| B1 | **상승형 컬럼 + 멀티플라이어 브래킷** | 좌→우로 점점 높아지는 3~4개 컬럼, **맨 끝 컬럼만 솔리드 오렌지(목적지 강조)** 나머진 회색/아웃라인. 컬럼 위로 아치형 브래킷 커넥터가 첫↔끝을 잇고 가운데에 「+79%」「5.5배」델타. 컬럼 안 값라벨 + 아래 카테고리 캡션. (p5, p7) | **상** — PwC 시그니처. before/after를 *누적 상승 서사*로 바꾸고 브래킷이 총변화를 한 눈에. 우리 수렴도식과 다른 "점증 + 총합 콜아웃" 아키타입. 재현 쉽고 임팩트 큼 |
| B2 | **좌-레일 차트 타이틀 블록** | 차트 좌측에 별도 칼럼으로 「제목 + 기간(2019~2024) + 출처 캡션」을 세로 정렬, 차트 본체는 우측. 한 페이지에 이 유닛을 2개 세로 적층(미니-exhibit 2개). (p5, p7) | **상** — 제목을 차트 위가 아니라 *좌측 레일에 메타블록으로* 묶는 배치. 페이지당 차트 2개 적층을 깔끔하게. 우리 차트 슬라이드 밀도/메타표기에 직접 적용 가능 |
| B3 | **거대 멀티플라이어 콜아웃을 차트요소로** | 「3배」를 초대형 오렌지 디스플레이 숫자로 렌더해 *비교 차트의 한 칸처럼* 사용(좌측 거대숫자 vs 우측 컬럼들). 숫자 자체가 비주얼 오브젝트. (p7) | **중** — 우리 거대숫자 콜아웃을 *차트 내부 비교 항목*으로 격하/통합한 변형. "N배" 배수 강조 패턴 |
| B4 | **비교 매트릭스 테이블** | 좌-레일 라벨열(행 질문) + 2개 비교 컬럼(선도기업/대다수기업). **컬럼 헤더 셀 색 구분(오렌지틴트 vs 그레이틴트)** + 행 교차음영. 정식 스타일 테이블. (p9) | **상** — 우리에 *제대로 스타일된 비교표*가 없음. A vs B 다항목 비교에 필수. 헤더 색구분 + zebra 행으로 가독 |
| B5 | **피라미드 계층 다이어그램 + 우측 커넥터** | 3단 적층 피라미드, 단별 색 농도 램프(연→중간→솔리드 오렌지), 각 단에서 우측으로 리더라인 뻗어 설명 라벨. (p9) | **상** — 계층/우선순위 구조도. 우리 수렴도식과 다른 **위계 피라미드** 아키타입. 3~4단 자동화 쉽고 범용 |
| B6 | **2x2 거대숫자 그리드** | 본문 아래 4개 오렌지 디스플레이 스탯(20~50% / 70~90% / 3~10배 / 10~30%)을 2열 그리드, 각 아래 작은 캡션. 좌-레일 타이틀블록 동반. (p11) | **중** — 우리 거대숫자 콜아웃의 *그리드 멀티-스탯* 변형(1개 아닌 4개 동시). 범위값(20~50%) 표기 포함 |
| B7 | **시나리오 A/B 카드 + 방향 트라이앵글** | 하단에 좌우 2장 카드(시나리오1 그레이 / 시나리오2 오렌지틴트), 각 헤더바 + 아이콘 + 3-메트릭 미니행(예산/비용/mROI)에 ▲▼ 상승·하락 트라이앵글 글리프. (p13) | **중** — 카드형 A/B 비교 + 방향성 지표. 옵션/시나리오 대비 슬라이드에 유용 |
| B8 | **각진 스워시 + 사진 오버랩 (표지)** | 표지 하단 사진 위로 PwC 오렌지/버건디 각진 도형이 겹쳐 들어와 브랜드 마크처럼 사진을 자름. (p1) | **중** — 브랜드 셰이프로 사진을 마스킹/오버랩하는 표지 장치. 우리 표지에 "강조색 기하 오버레이" 추가 가치 |
| B9 | **풀폭 사진 밴드 (섹션 클로저)** | 텍스트 섹션 하단에 edge-to-edge 가로 사진 스트립을 깔아 섹션을 닫음. (p15) | **중** — 사진을 *띠(band)*로 쓰는 배치. 텍스트 단조 페이지의 하단 앵커. (B 이미지 단계 참고: 풀폭 밴드 / 표지 오버랩 / 콘텐츠 무사진 — 사진은 표지·섹션경계에만, 데이터/본문엔 안 씀) |
| B10 | **그라데이션 메시 백커버** | 마지막 페이지 전체를 핑크→오렌지→피치 소프트 그라데 메시로 채우고 로고+디스클레이머만. (p17) | **하** — 닫는 페이지 무드. 단색램프 우리 시스템에 다색 그라데는 톤 이탈 위험. 흡수가치 낮음 |

**PwC 판정:** **흡수할 게 많음(상).** 색·강조 운용은 우리와 거의 동일해 새로울 게 적지만, **구조 다이어그램/표 계열이 강점**: ①상승컬럼+브래킷(B1) ②좌-레일 차트 타이틀블록(B2) ③비교 매트릭스 테이블(B4) ④피라미드(B5). 이 4개가 "텍스트→차트" 자동덱이 *구조를 그림으로* 보여주는 능력을 크게 키움. 사진은 **표지 오버랩 + 섹션 풀폭밴드**에만 쓰고 데이터 영역엔 안 쓰는 절제 규칙도 차용 가치.

## 종합 우선순위 (흡수 추천 Top)

**상-상 (즉시 검토):**
1. **Exhibit 액션타이틀 규약** (A1) — 차트 슬라이드 제목 = 검증된 주장 문장.
2. **좌-레일 차트 타이틀블록 + 페이지당 2차트 적층** (B2) — 차트 메타/밀도 표준.
3. **상승컬럼 + 브래킷 델타** (B1) + **bar 간 델타 주석** (A3) — 변화량을 차트 위에 직접.
4. **비교 매트릭스 테이블** (B4) + **피라미드 계층도** (B5) — 우리에 없는 구조 위젯 2종.
5. **혼합 통계 대시보드 1p** (A4) — "1페이지 1차트" 깨는 멀티위젯 레이아웃.

**중 (여력 시):** 본문 인라인 스탯/aside(A7·A8) · 산세/세리프 페어링(A9) · 2x2 거대숫자 그리드(B6) · 시나리오 A/B 카드(B7) · 표지 셰이프 오버랩(B8) · 풀폭 사진밴드(B9) · 비례버블(A5)·아이소타입(A6).
