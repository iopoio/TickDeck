## A. 2026_Social_Trends_Report (Ogilvy SocialLab)

**디자인 한 줄 요약:** 풀블리드 "오로라/메시 그래디언트" + 매크로 인물 사진을 색으로 녹여 합성한 무드 표지, 그 위에 세리프×산세리프 혼합 거대 헤드라인 — 전 페이지 좌(어두운 무드)·우(밝은 크림) 비대칭 2-존 셸로 통일된 매거진형 트렌드 리포트.

### NEW 패턴 (흡수가치 順)

**1. 챕터별 색-코딩 수직 그래디언트 바 (좌측 레일) — 흡수가치 [상]**
- 각 "Trend 001~005" 본문 좌측 가장자리에 가느다란 세로 막대. 챕터마다 **그래디언트 hue가 통째로 바뀜** (001=무지개, 002=오렌지, 003=서멀레드, 004=그린, 005=레드마젠타).
- 레이아웃 맵: `[세로 그래디언트 바 8~12px][아이콘+불릿 본문 칼럼][여백]` — 페이지 번호도 같은 챕터색.
- 흡수: 우리 "단일강조색"을 **섹션 단위로 회전**시키는 변형. 엔진에 `section_accent_ramp[]` 추가 → 챕터 인덱스로 hue 시프트. 색 1개 유지 철학과 충돌 안 함(명도램프를 hue램프로 1축 확장). 구현 쉬움(도형 1개+그래디언트 fill).

**2. "비대칭 2-존 셸" (다크무드 1/3 + 크림 2/3) — 흡수가치 [상]**
- 우리 50:50과 다름. 좌측 ~33%는 풀블리드 그래디언트/사진 무드존(소스·메타·작은 캡션), 우측 ~67%는 크림 배경 콘텐츠존. 전 페이지 동일 비율 고정 → 강한 리듬.
- 레이아웃 맵: `[33% 이미지/그래디언트 + 흰 텍스트][67% 크림 + 본문]`.
- 흡수: 50:50 외에 **33:67 "무드/콘텐츠" 프리셋** 1종 추가. 좌존은 자동 추출 그래디언트, 우존은 텍스트. 5장 연속 같은 비율 = "리포트 같은" 인상의 핵심.

**3. "In Action" 콜라주/스캐터 보드 (회전 사진카드 + 커넥터선 + 테이프형 캡션) — 흡수가치 [중]**
- 사례 페이지: 사진 카드 5~7장을 약간씩 회전시켜 흩뿌리고, 가는 **디딩(leader) 라인**으로 캡션 라벨에 연결. 무드보드/핀보드 느낌.
- 레이아웃 맵: 자유 배치 그리드 + L자 커넥터 + 작은 번호 캡션블록.
- 흡수: 자동화 난이도 중상(겹침·회전 충돌 회피 로직 필요). 우선순위 중 — "사례 모음" 슬라이드 타입으로 별도 도입 검토. 회전각만 ±2~4° 살짝.

**4. 세리프×산세리프 단어 단위 혼합 헤드라인 — 흡수가치 [중]**
- 한 헤드라인 안에서 강조 단어만 산세리프 굵게, 나머지는 세리프("Social **with** Substance"). 두 패밀리를 줄이 아니라 **단어 레벨**로 섞음.
- 흡수: 우리 "2패밀리(고정/가변)"의 적용 단위를 단어로 내림. 강조 토큰에 `font_family_swap` 옵션. 표지·결론 등 임팩트 슬라이드 한정 권장(본문 남발 금지).

**5. 닫힘(결론) "스퀘클 갤러리 행" — 흡수가치 [중]**
- 결론 페이지 하단에 둥근사각(squircle) 이미지 5칸 가로 배열, 각 칸은 챕터색 그래디언트 1장 → 5개 트렌드를 색-썸네일로 회수.
- 흡수: 결론에서 챕터색 바(패턴1)와 짝 맞춰 "색=챕터" 인덱스를 시각 요약. 단순 도형 행이라 구현 쉬움. before/after처럼 "회수형 클로저" 모듈로.

**6. 상단 트렌드 스테퍼(탭) 내비 — 흡수가치 [중하]**
- 모든 본문 상단에 회색 트렌드 탭 5개가 가로로 늘어서고 현재 챕터만 하이라이트(웹 스텝퍼처럼). 진행 위치 표시.
- 흡수: 멀티-섹션 덱의 "지금 어디" 표시. 우리 공통셸 헤더에 `progress_tabs` 옵션. PDF에선 살짝 과하지만 긴 리포트엔 유효.

**7. 그래디언트 "필 배지"(둥근 알약 라벨) — 흡수가치 [하]**
- 좌측 무드존에 "Real Form" 등 외곽선 그래디언트 알약 라벨 + 작은 통계 미니불릿. 부드러운 라벨 장치.
- 흡수: 소소한 토큰. 기존 킥커를 알약형으로 변주 가능한 정도.

**비주얼/타이포 특이처리:**
- 매크로 인물사진(눈·손)을 그래디언트와 멀티플라이로 **녹여** 무드존 배경화 — 사진을 "이미지"가 아닌 "색면"으로 사용.
- 숫자 통계는 굵은 막대 옆 거대숫자 + 출처 초소형 — (우리 거대숫자 보유, 단 **출처 micro-link를 항상 붙이는 규율**은 차용 가치 [중]).
- 3-칼럼 레퍼런스 부록: 번호 매긴 출처를 3열로 빽빽이 → "근거 있는 리포트" 시그널. 부록 템플릿으로 [중하].

## B. WGSN — TT26 (Top Trends 2026)

**디자인 한 줄 요약:** 트렌드 1개 = 1스프레드, 풀블리드 에디토리얼 인물/제품 사진 한 장에서 **지배색을 추출해 반대편 텍스트 패널 전체를 그 색으로 도배**하는 모노크롬 색-월드 방식. 다크 슬래브 셸 + 모노스페이스 캡션의 절제된 패션-매거진 문법.

### NEW 패턴 (흡수가치 順)

**1. 사진→색 추출 "모노크롬 색-월드" 스프레드 — 흡수가치 [상]**
- 트렌드별로 텍스트 패널 전체 배경을 **그 트렌드 히어로 사진의 지배색 1색**으로 채움 (Unserious=마젠타, PDRN=네이비, Gold=올리브골드, Cult of Cute=퍼플). 사진과 패널이 한 색가족 → 강한 일체감, 페이지마다 완전히 다른 인상인데 시스템은 동일.
- 레이아웃 맵: `[지배색 솔리드 패널 50%: 헤드+서브+2칼럼본문][풀블리드 사진 50%]`.
- 흡수: **사진/주제 키컬러를 자동 추출 → 슬라이드 배경 솔리드로** (우리 단일강조색을 "이미지에서 뽑은 색"으로 동적 결정). B의 핵심 흡수 대상. 우리 명도램프와 결합하면 "추출색+자동 명도단계" 가능.

**2. 좌우 교번 풀블리드 50:50 (사진존 좌↔우 스왑) — 흡수가치 [상]**
- 우리 50:50 보유하지만, **사진을 풀블리드로 한 면 전체** 채우고 매 스프레드 좌/우를 번갈아 스왑 → 책장 넘김 리듬. 텍스트존은 항상 솔리드 색.
- 흡수: 50:50 프리셋에 `image_side: alternate` 플래그. 연속 슬라이드에서 자동 교번 → 단조로움 제거. 구현 쉬움(side 토글).

**3. 사진 가장자리 회전 카테고리 라벨 (vertical rotated tag) — 흡수가치 [중]**
- 사진의 우측 가장자리에 90° 회전한 작은 라벨("FASHION·BEAUTY·INTERIORS"+페이지번호). 책등(spine)처럼 분류 색인.
- 흡수: 슬라이드 측면에 세로 회전 메타라벨 토큰. 카테고리/페이지 표기를 본문 침범 없이. [중] — 깔끔한 색인 장치.

**4. 상단 "카테고리 탭바 + 우측 도메인" 미니멀 셸 — 흡수가치 [중]**
- 최상단 다크 바: 좌측 `TOP TRENDS 2026` + 가운데 분류 태그(MACRO TREND/INSIGHT/FASHION) + 우측 `WGSN.COM`. 매우 절제된 러닝헤드.
- 흡수: 우리 공통셸 헤더에 **3분할 러닝헤드(브랜드·섹션태그·URL)** 변형. 가운데 태그가 페이지마다 바뀌며 분류 → 멀티주제 덱에 유효. [중].

**5. 헤드라인 아래 색-세그먼트 구분선 — 흡수가치 [중하]**
- 헤드라인과 서브카피 사이에 짧은 단색/그래디언트 가로 막대 1개(텍스트 폭의 30~50%만). 굵은 헤드를 본문에서 끊는 라이트한 디바이더.
- 흡수: 풀폭 룰 대신 **부분폭 색막대 디바이더** 토큰. 기존 헤드/본문 사이 호흡. 구현 trivial. [중하].

**6. L자 크롭-브래킷(코너 등록마크) 프레임 — 흡수가치 [하]**
- Guardian Design 페이지: 사진에 L자 모서리 마크 + 옅은 그리드 가이드선을 겹쳐 "촬영 컨택트시트/뷰파인더" 느낌.
- 흡수: 특정 무드(테크·디자인) 슬라이드 한정 장식. 범용성 낮아 [하].

**7. 모노스페이스 캡션/메타 타입 — 흡수가치 [하]**
- 러닝헤드·페이지번호·각주를 모노스페이스로 → 산세리프 본문과 대비되는 "데이터/기술" 텍스처. About 페이지의 세그먼트 그래디언트 미니바와 짝.
- 흡수: 메타 텍스트 전용 모노 패밀리 1종 추가 옵션. 톤 좁아 [하].

**이미지 사용 방식 (B 이미지 단계 참고):**
- **단계 0: 이미지 = 주인공.** 한 스프레드 한 장, 풀블리드, 크롭 과감(인물 얼굴·손 클로즈업). 사진이 콘텐츠의 절반 면적을 단독 점유.
- **단계 1: 색 추출 종속.** 텍스트 패널 색을 사진에서 뽑아 종속 → 사진이 색 시스템의 소스.
- **단계 2: 사진=색면 (A와 공통).** Social은 사진을 그래디언트에 녹여 배경 텍스처화; WGSN은 사진을 솔리드 색으로 환원해 반대편에 반영. 둘 다 "사진을 색으로 번역"하는 같은 사상.
- → 우리 엔진 이미지 파이프라인 권고: **(1) 이미지에서 지배색 추출 → 슬라이드 accent/배경 자동 결정 (2) 사진은 풀블리드 한 면 또는 squircle 갤러리, 작게 흩지 말 것 (3) 좌우 교번.**

## 종합 판정 — 흡수할 게 많나/적나

**판정: 많다 (특히 "색의 동적 결정" 축에서 큰 흡수가치).**

두 리포트의 공통 발견 = **"색을 고정값이 아니라 콘텐츠(챕터/사진)에서 생성"**. 우리는 단일강조색+명도램프를 갖췄지만 *그 색이 어디서 오는가*는 정적임. 두 리포트는 (A) 챕터 인덱스로 hue 회전, (B) 히어로 이미지에서 색 추출 — 둘 다 우리 "단색 철학"을 깨지 않고 **색 결정 로직만 동적화**한다. 이게 최대 흡수 포인트.

**즉시 흡수 권장 (상, 4개):**
- 챕터별 색-코딩 그래디언트 바 (A-1) — `section_accent_ramp[]`
- 비대칭 33:67 무드/콘텐츠 셸 프리셋 (A-2)
- 사진→지배색 추출 → 배경/accent 자동 (B-1)
- 풀블리드 50:50 좌우 교번 (B-2) — `image_side: alternate`

**검토 흡수 (중, 6개):** In-Action 콜라주보드(A-3), 단어단위 세리프×산세리프(A-4), 스퀘클 갤러리 클로저(A-5), 회전 측면 카테고리 라벨(B-3), 3분할 러닝헤드(B-4), 부분폭 색막대 디바이더(B-5).

**보류 (하):** 트렌드 스테퍼·필배지·L자 브래킷·모노스페이스 메타 — 톤/범용성 제약.

**우리와 겹쳐 재보고 안 한 것:** 둘 다 50:50·킥커+거대헤드·거대숫자·라이트/다크는 보유분과 동일하여 제외. 차별점은 위 NEW 목록에 한정.
