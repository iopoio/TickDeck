## 1. Havas Red — New Lens on Brand Experience 2026
**판형:** A4 세로 / **디자인 한 줄:** 검정 기반 다크 에디토리얼 + 마젠타 단색 강조 + 풀블리드 사진 디바이더의 "잡지형 트렌드북". 우리 다크 모드와 유사하나 *사진·컬러 패널 운용*이 차별적.

### NEW 패턴 (흡수가치)
1. **컬러 통패널 "BY THE NUMBERS" 사이드바 [상]**
   - 레이아웃 맵: 본문(좌 60%) ‖ 마젠타 풀채움 세로 패널(우 40%). 패널 안은 거대숫자 2×2 그리드(80% / 56% / 50% / 23%)에 각 한 줄 캡션. 본문과 통계가 같은 줄에서 병주(竝走).
   - 우리 "거대숫자 콜아웃"과 다른 점: 단발 숫자가 아니라 **단색 통패널에 통계를 군집(cluster)** → 본문 옆 "데이터 위성" 모듈. 흡수가치 상.
2. **사진 띠 헤더(photo-band header) + 컬러 탭 라벨 [중]**
   - 페이지 상단에 얇은 가로 사진 스트립(콘서트·축제 군중), 그 위에 마젠타 작은 탭("PAY TO PLAY"). 섹션 정체성을 사진 한 줄로 압축.
   - 흡수가치 중: 우리 셸 헤더에 "사진 1줄 + 컬러 탭" 변형 추가 여지.
3. **사진-필 다크 콜아웃 박스(범주형 헤더 리스트) [중상]**
   - 어두운 사진을 채운 박스 안에 마젠타 소제목 4개("EXCLUSIVITY / QUALITY / COMMUNITY / CULTURAL CURRENCY") 각 1줄 설명. 리스트를 *카드가 아닌 단일 사진 박스 위 컬러 텍스트*로 처리.
   - 흡수가치 중상: 4항목 리스트의 "사진 위 컬러 헤더" 대안.
4. **풀블리드 사진 섹션 디바이더 + 거대 숫자 워터마크 [중]**
   - 챕터 표지가 인물 사진 풀블리드 + 정중앙 초대형 숫자("1","2") + 그 아래 가는 대문자 타이틀. 우리 divider보다 *사진 주도·숫자 워터마크형*.
5. **2색 매트릭스(Internal/Deeper) 셀 [중]**
   - "THE INTERNAL ADVANTAGE / DEEPER CONNECTION" 2칼럼 + 각 굵은 소제목. 단순하지만 *상보 개념 2분할*의 가벼운 버전.

**판정:** 흡수할 게 **중간**. 핵심은 #1(컬러 통패널 군집 통계)·#3(사진박스+컬러헤더 리스트). 사진 의존이 커 우리(텍스트→PPTX) 엔진엔 #1만 즉시 이식 가능.

## 2. KPMG — Global Tech Report 2026 (global-tech-report.pdf)
**판형:** 16:9 가로(1920×1080) / **디자인 한 줄:** 코발트블루 브랜드월 + 네온라인 3D 프레이밍 + 상단 영구 내비탭의 "프리미엄 컨설팅 16:9 덱". 우리와 결이 가장 가까운(=벤치마크) 레퍼런스.

### NEW 패턴 (흡수가치)
1. **상단 영구 섹션 내비게이션 바 [상]**
   - 모든 콘텐츠 페이지 최상단에 섹션 탭 7개 가로 나열, 현재 섹션만 진하게(브레드크럼). 좌상단 페이지번호·우상단 ‹⌂›·⌃ 미니 컨트롤.
   - 흡수가치 상: 멀티섹션 덱에서 "지금 어디" 표시. **우리 셸에 영구 내비탭 슬롯** 추가 = 긴 덱 항법성↑. 즉시 이식 가능(텍스트 기반).
2. **헤드라인 내 색전환 강조(two-tone headline) [상]**
   - 한 헤드라인 안에서 일부 단어만 시안/틸로 색을 바꿈("Realizing value from **tech investment**", "Building **adaptive strategies**"). 우리 킥커+헤드라인과 다른 *헤드라인 내부 키워드 컬러링*.
   - 흡수가치 상: 강조색 1개를 헤드라인 단어 단위로 주입 → 카피라이터가 키워드만 태깅. 간단·강력.
3. **우측 레일 하이라이트 박스(big-%-stat 앵커) [상]**
   - 본문 우측에 박스: "Findings indicate..." 짧은 리드 + 초대형 %(69%/65%/55%) 하단 앵커. 본문과 분리된 "강조 위성 박스".
   - 흡수가치 상: 우리 모듈에 "본문+사이드 강조박스(거대%)" 50:50 변형.
4. **3칼럼 본문 + 가로 스택바 도표 분리 [중상]**
   - 좌측 3단 조판 본문 + 우측 가로 막대(직접 라벨). 정보밀도 높은 컨설팅형 1페이지. 우리 borderless차트와 호환되나 *3칼럼 본문 동반*이 신선.
5. **오버사이즈 인용부호 풀쿼트 + %앵커 [중상]**
   - 거대 `"` 글리프 + 인용문 + 우하단 큰 %(55%) 결합. 인용을 *데이터로 닫는* 처리.
   - 흡수가치 중상: 우리 인용 모듈에 "%로 마감" 변형.
6. **시네마틱 디바이더(인물+에너지필드 합성) [중]**
   - 섹션 표지가 일관된 네온-포털 모티프(인물이 빛의 소용돌이/유리큐브 안). 브랜드 일관성 모범. 단 AI생성 사진 의존 → 우리 즉시이식엔 부적합(컬러필드 추상으로 대체 가능).

**판정:** 흡수할 게 **많다**. #1(영구 내비탭)·#2(헤드라인 내 색전환)·#3(우레일 강조박스)·#5(인용 %마감) 4개가 전부 *텍스트 기반·즉시 이식*. 우리 엔진과 가장 궁합 좋음 → **최우선 벤치 대상**.

## 3. AMA — Future Trends in Marketing 2026 (92p)
**판형:** Letter 세로 / **디자인 한 줄:** 세이지/민트 틴티드 그라운드 + 오렌지/멀티컬러 강조 + 네트워크그래프 모티프의 "에디토리얼 리서치 매거진". 라이트/다크가 아닌 *제3의 틴티드 뉴트럴*이 특이.

### NEW 패턴 (흡수가치)
1. **틴티드 스탯 카드 그리드 (아이콘+거대숫자+캡션) [상]**
   - 레이아웃 맵: 본문 아래 옅은 민트 카드들을 2-up/3-up 그리드. 각 카드 = 의미아이콘(잎/달러/사람) + 거대% + 1줄 캡션 + 인라인 출처링크. 범위값 표기("37%-54%","58%-62%")도 한 칸.
   - 우리 "거대숫자 콜아웃"과 다른 점: 숫자가 **아이콘 동반·카드 그리드로 군집**되어 "통계 보드" 모듈화. 흡수가치 상 — 다항 통계를 한 페이지에 정렬하는 우리 약점 보완.
2. **수직 지그재그 넘버드 프로세스 타임라인 [상]**
   - 8단계를 좌우 교대 배치한 원(01~08), 곡선 화살표로 연결, 각 원이 *카테고리 팔레트의 서로 다른 색*. (p88 "Panel Process")
   - 흡수가치 상: 순차 프로세스/방법론을 우리 "수렴도식"과 별개의 *지그재그 스텝 다이어그램*으로. 텍스트→도식 이식 쉬움.
3. **3분절 컬러 탭 섹션 헤더 [상]**
   - `[Spotlight]│제목│Industry: 분야` 형태의 가로 탭 헤더. 좌측은 컬러 솔리드 탭, 중앙은 강조색 굵은 제목, 우측은 옅은 메타. 한 줄로 분류·제목·메타 3정보.
   - 흡수가치 상: 우리 킥커를 *3분절 탭*으로 확장 = 카테고리/메타 동시 표기. 즉시 이식.
4. **아바타-스탯 융합 디바이스 [중]**
   - 일러스트 인물 원형 아바타에 %를 겹쳐 한 덩어리로("61%" + 인물머리). 인구통계 통계의 인격화.
   - 흡수가치 중: 사진/일러 의존 → 아이콘 버전으로 약화 이식 가능.
5. **풀블리드 케이스 카드 + 코너 탭 라벨 [중]**
   - 사례 사진을 풀폭 카드로, 좌상단에 컬러 코너탭("Spotlight"). p52/p60.
   - 흡수가치 중: #3과 결합해 "사례 블록" 표준화 여지.
6. **네트워크 그래프 / 노드 성좌 모티프 [중하]**
   - 표지·반원 블리드에 점-선 네트워크 그래프를 장식 모티프로 반복. "연결성" 은유의 비주얼 시그니처.
   - 흡수가치 중하: 장식 텍스처로 generative SVG 1개 만들면 재사용. 콘텐츠 종속 X라 가볍게 차용.
7. **인라인 하이퍼링크 출처(밑줄+컬러) [중하]**
   - 본문 중 출처를 밑줄+강조색 인라인 링크로 처리(각주 X). 신뢰도·밀도 동시 확보.
   - 흡수가치 중하: 우리 본문 모듈에 "인라인 출처 스타일" 토큰.

**판정:** 흡수할 게 **많다(패턴 다양성 최다)**. 90p 분량답게 모듈 어휘가 풍부. 우선순위 #1(틴티드 스탯카드 그리드)·#2(지그재그 프로세스)·#3(3분절 탭 헤더)는 *텍스트 기반·즉시 이식·우리 약점(다항통계/순차/메타라벨) 직격*.
