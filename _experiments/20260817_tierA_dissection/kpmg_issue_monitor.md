## 렌즈 B. 페이지 문법

- 관찰(p5·13·19·26·28 공통): 본문 페이지 고정 그리드 = 상단 헤더줄("Issue Monitor | January 2022" + 모서리 남색 사각형 페이지 번호), 좌측 약 28% 인용 레일, 우측 약 72% 본문 열. 홀짝 페이지에서 번호·헤더가 좌우 대칭으로 뒤집힌다. → 규칙: 본문은 "인용 레일 + 본문 열" 2열 그리드를 고정하고, 요소는 자기 열 밖으로 절대 나가지 않는다.
- 관찰: 좌측 레일에는 큰따옴표 장식 + 파란색 3~6줄 인용문 하나만 놓인다(p5 "한국의 고령화 속도는 OECD 38개국 중 2위…"). 페이지 요지의 압축문이다. → 규칙: 한 장 = 한 메시지. 페이지 요지를 40자 내외 인용문으로 좌측 레일에 반드시 1개 추출한다.
- 관찰: 세로 배치 비율(p5) = 섹션 제목 약 8% / 소제목+본문 텍스트 약 50% / 차트 밴드 약 35% / 하단 로고·저작권 푸터 약 7%. 텍스트가 위, 차트가 아래로 층이 분리되어 겹칠 여지가 없다. → 규칙: 텍스트 상단·시각물 하단의 수평 밴드 분리를 기본형으로 하고, 차트는 자기 밴드 안에서만 산다.
- 관찰: 제목 위계 3단 = 남색 대형 섹션 제목(결론 아닌 주제어) → 파란 볼드 소제목(결론문·질문문: "활발한 경제활동 참여가 경제력 확대를 유도" p7, "…어떠한 변화를 맞이하고 있는가" p8) → 검정 본문. 결론은 소제목이 담당한다. → 규칙: 대제목 = 주제어, 소제목 = 결론 문장으로 역할을 나눈다.
- 관찰: 본문은 양쪽 정렬, 문단 4~5개(20~25줄), 줄간격 넉넉(약 1.5배), 문단 사이 빈 줄 1개. 본문 안 강조는 볼드 최소 + 색 강조(빨강·파랑)는 페이지당 몇 단어뿐(p26 카드 안 "AIP 욕구"·"SOTA 기술 내재화"). → 규칙: 한국어 본문은 줄간격 150% 이상·문단 간 공백 확보, 색 강조는 페이지당 5단어 이내로 제한한다.
- 관찰: 한 장 정보량 상한 = 차트 2개 또는 표 1개 또는 카드 4개. p5는 차트 2개+숫자 라벨 약 20개, p26은 카드 4개+중앙 일러스트 1개. 3종류 시각물이 한 장에 섞이는 일이 없다. → 규칙: 한 장에 시각물 유형은 1종, 개수는 2개(카드형은 4개)까지만 담는다.
- 관찰: 차트 제목은 [대괄호 제목] 규격으로 차트 상자 바로 위 좌측 고정, 두 차트가 나란할 때 각자 제목을 가진다(p5·13). 카드 그리드(p26)는 번호 배지 ①~④ + 연한 파랑 배경 + 중앙 일러스트로 4분면 배치. → 규칙: 시각물 제목은 [대괄호] 접두 규격으로 통일하고, 카드는 번호 배지로 순서를 박는다.

## 렌즈 C. 정리 방식

- 관찰: 모든 막대·꺾은선 데이터 포인트에 값을 직접 표기하고(p5 인구 차트 5개 막대 전부 라벨), 축 눈금은 보조로 밀린다. 단위는 축 모서리에 (천 명)·(%)·(세)로 명기. → 규칙: 차트는 전 데이터 포인트 직접 라벨 + 축 모서리 단위 표기를 의무로 한다.
- 관찰: 소수는 1자리로 통일(33.9%·2.50%·83.3세), 천 단위 콤마(17,224), 증감은 "2017년 대비 15.3% 증가"처럼 비교 기준 연도를 반드시 문장에 명시(p13). → 규칙: 소수 1자리·비교 기준 명시 없는 증감 표현 금지.
- 관찰: 출처 규격 = 차트·표 하단 좌측에 "Source: 통계청, 삼정KPMG 경제연구원 재구성" + 필요 시 "Note 1·Note 2" 번호 매김 별도 줄(p5). 가공했으면 "재구성"을 밝힌다. 페이지 하단엔 저작권 고정 문구. → 규칙: Source 좌하단 고정 + 가공 여부(재구성) 표기 + Note 번호 매김.
- 관찰: 표(p11·19)는 열 4~5개, 헤더 행 진한 배경+흰 글자, 첫 열 병합으로 행 그룹화, 셀 안은 불릿 목록 허용, 가는 회색 괘선, 줄무늬 없음, 텍스트 좌측 정렬. → 규칙: 표는 5열 이내·진한 헤더·행 그룹 병합·셀 내 불릿 허용, 줄무늬 배경은 쓰지 않는다.
- 관찰: 색 역할 분담 = 남색(구조·강조 계열)·회색(과거값·보조 계열)·하늘색(2차 계열)·보라(참고 섹션 전용)·오렌지·노랑(요약 인포그래픽 전용). 본문 차트는 사실상 "회색 기본 + 남색 강조" 2색. → 규칙: 차트 팔레트는 회색 바탕 + 강조 1색을 기본으로 하고, 특수 색은 특정 페이지 유형에 전속시킨다.
- 관찰: 텍스트 밀도는 텍스트 페이지(p18·27~28)와 시각물 페이지가 분리되어 있고, 텍스트만 있는 장도 좌측 인용 레일 덕에 벽처럼 보이지 않는다. → 규칙: 텍스트 전용 장을 허용하되 인용 레일 요지문을 필수로 붙인다.

## 이식 가치 높은 규칙 후보 3

1. **좌측 인용 레일 = 한 장 한 메시지 강제 장치** — 페이지 요지를 40자 인용문으로 뽑아 고정 폭 레일에 격리. 요지 추출과 겹침 방지(2열 그리드)를 한 장치로 동시에 해결한다.
2. **결론 선행 요약 1장 + 번호 체계 3중 반복** — 목차 직후 핵심 수치 3개·시사점 ①~④ 한 장을 먼저 내고, 본문·시사점이 같은 번호를 재사용. 덱 전체의 논증 일관성을 구조로 보장한다.
3. **차트 전 포인트 직접 라벨 + Source/Note 좌하단 규격** — 축 읽기 대신 값 라벨 전수 표기, [대괄호] 차트 제목, "재구성" 명시. 자동 생성 차트의 신뢰감을 가장 싸게 올리는 규격이다.
