# 맥킨지 State of AI 2025 조판 해부 (어휘 추출)

페이지 번호 = PDF 순번 기준 (인쇄 번호와 2 차이).

## 렌즈 A. 논리 뼈대

- 관찰: 표지(1) → 결론 선언 페이지(2, 하늘색 밴드 위에 "거의 모든 응답 조직이 AI를 쓰지만 대부분 스케일링 초기" 완결 문장) → Key findings 번호 목록 6개(3) → 서문 에세이(4) → 본문. 결론을 먼저 다 말하고 뒤에서 증명하는 구조.
  → 규칙: 덱 앞 3장 안에 "한 문장 결론 페이지"와 "번호 달린 핵심 발견 목록 페이지"를 고정 배치한다.
- 관찰: 섹션 전환은 별도 표지 페이지가 아니라 본문 페이지 상단의 큰 굵은 결론형 소제목으로 처리(5, 9, 15, 23, 28). 섹션당 본문 3~5장.
  → 규칙: 섹션 구분은 전용 간지 대신 "그 페이지 상단의 큰 결론 제목"으로 하고, 한 섹션은 3~5장으로 제한한다.
- 관찰: 밀도 높은 차트 페이지 3~4장마다 숨쉬는 페이지가 온다 — 파란 대형 인용문 페이지(8, 11, 14, 16, 18, 25, 26) 또는 인물사진+해설 칼럼 페이지(8, 14, 18, 23, 27, 29). 인용문은 본문 수치를 문장으로 풀어 반복한다("Twenty-three percent...").
  → 규칙: 증거 페이지 3~4장마다 핵심 수치 1개를 문장으로 풀어 쓴 대형 인용 페이지를 삽입해 리듬을 만든다.
- 관찰: 마지막은 About the research(30, 조사 방법·n수·기간) → 뒤표지(32). 신뢰 근거를 뒤로 몰아둔다.
  → 규칙: 조사 방법·데이터 출처 요약 페이지를 덱 끝에 1장 고정한다.

## 렌즈 B. 페이지 문법

- 관찰: 표준 증거 페이지(5, 6, 13, 25)는 위에서 아래로 — 리드 문단(4~9줄, "Exhibit N" 참조 포함) → 눈썹 라벨 "Exhibit N"(소형) → 결론 문장 제목(굵게, 마침표로 끝남) → 측정 대상 부제("Use of AI..., % of respondents": 앞은 굵게·단위는 보통 굵기) → 범례 → 차트 1개 → 각주 3~5줄(아주 작게) → "McKinsey & Company" 태그. 제목이 주제어가 아니라 항상 결론문이다.
  → 규칙: 차트 제목은 3층 고정 — 눈썹(도표 번호) / 결론 문장(마침표) / 측정치+단위 부제. 주제어형 제목 금지.
- 관찰: 왼쪽 여백이 페이지 폭의 약 25%로 넓고, 본문·제목·차트·각주·범례가 전부 같은 왼쪽 정렬 축 하나에 매달린다(5, 6, 9, 13, 25). 본문 칼럼 폭은 약 55~60%. 요소끼리 겹침이 원천 차단되는 이유 = 단일 칼럼 + 수직 적층(글 위·차트 아래)이고, 글이 차트를 감싸는 배치가 없다.
  → 규칙: 페이지당 정렬 축 1개(왼쪽 고정), 요소는 수직 적층만. 텍스트 랩어라운드 금지.
- 관찰: 한 페이지 = 차트 1개. 32장 중 도표 19개인데 도표 2개짜리 페이지가 없다. 13·25는 아래 절반이 통째로 여백인데도 두 번째 차트를 넣지 않았다.
  → 규칙: 1페이지 1증거. 공간이 남아도 두 번째 차트를 넣지 않고 여백으로 둔다.
- 관찰: 강조는 색이 아니라 배치·크기로 — 배수 주석 "2.8×"(15), "3.0×"(17), "3.6×"(15), "4.9×"(21)를 브래킷과 함께 차트 안 빈 공간에 크게. 25는 누적 막대 아래에 "32% / 13%" 박스를 가는 괘선으로 두르고 해당 구간 바로 밑에 정렬해 화살표 없이 연결한다.
  → 규칙: 핵심 수치 1개는 차트 안 전용 여백에 대형 주석(배수·%박스)으로 올리되, 화살표 대신 수직 정렬로 대상과 연결한다.
- 관찰: 표형 도표(21)는 왼쪽에 분류 눈썹(Strategy/Talent...) + 굵은 용어 + 설명 텍스트 칼럼(약 60%), 오른쪽에 점 비교 플롯(약 40%), 행마다 가는 수평 괘선. 줄무늬 배경 없음.
  → 규칙: 표는 세로줄 없이 가는 수평 괘선만, 텍스트 칼럼과 수치 플롯을 좌우 분리, 행 단위 정렬.
- 관찰: 인용 페이지(25)는 왕블루 대형 문장(4줄)을 왼쪽 위 1/3에 놓고 나머지는 빈 공간. 해설 페이지는 연파랑 밴드 + 원형 인물사진 + 좁은 칼럼 2~4문단.
  → 규칙: 인용 페이지는 요소 2개 이하(문장 + 여백/이미지). 채우려 들지 않는다.

## 렌즈 C. 정리 방식

- 관찰: 수치는 전부 정수 %. 소수점 없음. 단위는 부제에서 "% of respondents"로 1회만 선언하고 개별 숫자에는 % 기호를 안 붙인다(5, 6, 13). n수는 부제나 각주에 명시(n = 1,933 / n = 1,753). "반올림 때문에 합이 100이 안 될 수 있음" 상비 각주.
  → 규칙: 차트 안 수치 = 정수, 단위 선언은 부제에서 1회, n수와 반올림 각주 의무.
- 관찰: 출처는 항상 차트 바로 아래 각주 블록 마지막 줄 "Source: McKinsey Global Survey..., June 25–July 29, 2025" 형식(조사명+표본+기간). 부제의 조건은 위첨자 숫자 각주로 단다.
  → 규칙: 출처 = 차트 하단 고정 위치, "출처명 + 표본 + 기간" 한 줄 형식.
- 관찰: 막대는 세그먼트 안 직접 수치 라벨, 라인 차트는 전 점 직접 라벨(5, 9). 격자선 의존 없음. 작은 세그먼트 값은 밖으로 뺀다(6).
  → 규칙: 축 눈금 대신 직접 라벨. 들어갈 자리가 없으면 밖으로 빼되 겹치지 않게.
- 관찰: 팔레트 역할 분담 — 데이터 = 네이비~시안 파랑 단일 계열(단계 = 진행도: 연할수록 실험, 진할수록 완전 정착, 6), 회색 = 부정·중립·무응답, 왕블루 = 인용문 전용, 배경 밴드 하늘색/연파랑 = 페이지 유형 신호. 빨강·초록 부재.
  → 규칙: 데이터 색 1가족(파랑 단계) + 중립 회색 + 강조 텍스트색 1개로 제한, 배경색은 페이지 유형 표시로만.
- 관찰: 텍스트 밀도 — 본문 페이지는 리드 1문단 + 차트 + 각주가 전부. 인용 페이지는 1문장. 밀도가 페이지 유형별로 이분화돼 있다.
  → 규칙: 페이지 유형을 "밀도 높은 증거형"과 "밀도 낮은 호흡형" 둘로만 나누고 중간형을 만들지 않는다.

## 이식 가치 top 3

1. 제목 3층 구조 (눈썹 / 결론 문장 / 측정치+단위) — 모든 차트 페이지가 자동으로 논증이 되고, 제목만 이어 읽어도 덱 전체 주장이 복원된다.
2. 1페이지 1증거 + 단일 왼쪽 정렬 축 + 수직 적층 — 요소 충돌·겹침을 규칙이 아니라 구조로 원천 차단하는 가장 싼 방법.
3. 3~4장마다 대형 인용 호흡 페이지 (본문 수치를 문장으로 반복) — 리듬과 기억 포인트를 동시에 만들고, 생성기 입장에선 템플릿 1개 추가로 끝난다.
