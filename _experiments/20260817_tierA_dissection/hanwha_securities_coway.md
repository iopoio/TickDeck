# 한화투자증권 코웨이 4Q23 리포트 조판 해부 (어휘 추출)

## 렌즈 A. 논리 뼈대

- 관찰(p1): 표지 부제가 이미 결론문("4Q23 리뷰: 경쟁사 압도 중"). 본문도 결론 선행 3블록 — 실적 리뷰 → 전망 근거 → 투자의견/목표주가. → 규칙: 문서 첫 화면에 판정 한 줄을 부제로 박고, 본문은 [사실 → 해석 → 판단] 3블록 고정 순서로 쓴다.
- 관찰(p1→p2→p4→p5): 페이지 역할이 층위별로 분리 — p1 판단+요약, p2 근거 표/차트, p4 원천 재무제표, p5 고지. 뒤로 갈수록 해설이 줄고 숫자만 남는다. → 규칙: 한 페이지 한 층위(판단/근거/원천/부록), 해설 밀도는 뒤로 갈수록 단조 감소.
- 관찰(p1 우측): 소제목 3개 중 2개가 완결 문장형 결론("국내 M/S 확대 지속과 태국의 이익 기여 본격화 전망"). → 규칙: 섹션 제목 = 명사 나열이 아니라 주장 문장. 제목만 이어 읽어도 논지가 성립해야 한다.
- 관찰(p1~p5): 매 페이지 상단에 동일 러닝헤더(종목명+코드 좌 / 리서치 브랜드 우 / 밑줄 1개), 빈 페이지(p3)조차 이 틀 유지. → 규칙: 러닝헤더+페이지 번호 틀은 내용 유무와 무관하게 전 페이지 반복 — 반복 리듬이 신뢰 신호.

## 렌즈 B. 페이지 문법

- 관찰(p1): 2단 비대칭 그리드 — 좌측 레일 약 35% 폭(투자의견 박스·시세 스탯·미니표·미니차트 수직 스택), 우측 약 62% 본문. 두 단은 절대 서로 침범하지 않고, 좌측 레일 내부 블록은 전부 레일 전폭 + 수평 구분선으로만 분리. → 규칙: 겹침 방지의 핵심 = 부동(float) 배치 금지, 고정 폭 레일 + 전폭 블록 수직 스택 + 구분선.
- 관찰(p1 좌상): 판정 박스 = 연회색 배경 밴드 안에 오렌지 대형 "Buy"(페이지 최대 활자) + 목표주가 1줄. 페이지에서 색+크기 최강 요소는 이 박스 하나뿐. → 규칙: 페이지당 최상위 강조는 1개 요소에만 허용(색·크기 동시 최대), 나머지는 흑백 위계.
- 관찰(p1 좌측 스탯): "현재 주가 / 시가총액 / 발행주식수..." 라벨 좌측·값 우측 정렬의 2열 리스트, 행간 균일, 테두리 없이 상하 굵은 선만. → 규칙: 지표 나열은 카드가 아니라 라벨-값 우측정렬 리스트로, 선은 상하 경계 2개만.
- 관찰(p2): 요소 배치가 표(전폭) → 차트 2개(각 약 48% 폭, 사이 여백 약 4%) → 소형 표(중앙) 순 수직 흐름. 차트 두 개는 같은 높이·같은 캡션 형식으로 짝을 이룬다. → 규칙: 병렬 증거는 동형 2-up(같은 크기·같은 캡션 문법)으로만 나란히 둔다.
- 관찰(p4): 재무제표 4개를 2x2 사분면 그리드에 배치, 각 표가 자기 셀 폭을 넘지 않음. 열 폭이 좁아지자 행 라벨을 들여쓰기 2단계로 압축. → 규칙: 다표 페이지는 사분면 그리드 고정, 표 폭 = 셀 폭 상한, 위계는 들여쓰기로 해결.
- 관찰(p1 본문): 한국어 본문은 양끝 정렬 + 넉넉한 행간(활자 대비 약 1.7배)으로 글자 밀도를 버틴다. 문단 사이보다 소제목 위 여백이 훨씬 큼. → 규칙: 한국어 장문은 양끝 정렬 + 행간 170% 내외, 위계는 "위 여백 크게/아래 여백 작게"로 소속을 표시.
- 관찰(p1, p5): 구분 장치 어휘가 3종뿐 — 회색 배경 밴드(판정), 수평선(블록 경계), 대괄호 제목("[ 재무제표 ]", "[ Compliance Notice ]"). 박스 테두리 상자는 없음. → 규칙: 테두리 상자 남용 금지, 밴드/수평선/대괄호 라벨 3종만으로 구획.

## 렌즈 C. 정리 방식

- 관찰(p2 표1): 13열 표를 세로선 2개로 3개 열 그룹(분기 실적 | 분기 전망 | 연간)으로 절단, 그룹 안에는 세로선 없음. 핵심 행(연결 매출액)만 살구색 밴드, YoY 행은 이탤릭 보조 처리. → 규칙: 광폭 표는 열 그룹 경계에만 세로선, 강조는 핵심 행 1개 배경 밴드, 파생 지표 행은 서체만 낮춘다.
- 관찰(p2, p4): 숫자 전부 우측 정렬 + 천 단위 쉼표, 단위는 셀에 안 쓰고 캡션 줄 우측 끝에 "(단위: 억 원)" 1회 선언. 페이지마다 단위 통일(p1 십억 원, p2 억 원). → 규칙: 표 안 단위 반복 금지 — 캡션 우측 단위 선언 1회 + 표 전체 단위 통일 + 숫자 우측정렬.
- 관찰(p2 헤더): 전망치는 4Q24E처럼 E, 잠정치는 4Q23P처럼 P 접미사로 실적과 즉시 구분. → 규칙: 실측/잠정/전망을 값 뒤 한 글자(P/E)로 태깅, 별도 각주로 미루지 않는다.
- 관찰(p1 본문): 숫자 인용 형식 고정 — "1,662억원(+1.5% YoY, OPM 16.5%)": 절대값 먼저, 괄호 안에 증감+비교 기준. 증감엔 +/- 부호 명시, %는 소수 1자리. → 규칙: 본문 수치 = 값(부호+증감률 기준표기) 괄호 문법으로 통일, % 소수 1자리 고정.
- 관찰(p2, p4, p5): 모든 표/차트 바로 아래 "자료: ..." 좌측 소형 표기, 추가 설명은 "주:" 접두. 캡션은 "[표1]/[그림1] + 제목"으로 번호 체계 분리. → 규칙: 출처는 해당 요소 직하단 1줄(자료:/주: 접두), 표와 그림은 번호 체계를 나눈다.
- 관찰(p1, p2): 색 역할 3분 — 오렌지 = 브랜드·판정·핵심 강조(Buy, 핵심 행 밴드, 차트 보조선), 빨강 = 당사 종목 데이터(주가선, 상승여력 ▲), 회색 계열 = 비교 대상·참조선 전부. 그 외 색 없음. → 규칙: 색 팔레트는 [주인공 데이터 1색 + 판정/강조 1색 + 회색 층] 3역할로 제한.
- 관찰(p2 그림1·2): 범례는 차트 상단 한 줄, 당사 종목 선만 굵은 유채색, 배수 밴드 선은 가는 회색/오렌지 계열로 뒤에 깔림. → 규칙: 다중 선 차트는 주인공 1선만 굵게+유채색, 나머지는 가는 무채색 보조선.
- 관찰(p5): 의견 변동 이력을 표+회색 셀 음영으로, 목표주가 대비 괴리율까지 숫자로 공개. → 규칙: 과거 판단 이력은 서술이 아니라 표(날짜·의견·값·괴리)로 남긴다.

## 이식 가치 최상위 규칙 후보 3

1. **고정 폭 레일 + 전폭 블록 수직 스택 (렌즈 B-1)** — 겹침·파고듦 사고를 구조적으로 없애는 가장 값싼 문법. 자동 생성기의 배치 버그를 배치 원리 차원에서 차단한다.
2. **광폭 표의 열 그룹 세로선 + 핵심 행 1개 배경 밴드 (렌즈 C-1)** — 숫자 밀도 높은 표를 시선 2번에 읽게 만드는 핵심 장치. 우리 표 렌더러에 규칙 2줄로 이식 가능.
3. **캡션 우측 단위 1회 선언 + P/E 접미사 태깅 (렌즈 C-2·C-3)** — 셀 안 단위 반복과 전망치 혼동을 동시에 제거, 표 폭도 절약. 수치 신뢰성 문법이라 장르 불문 재사용된다.
