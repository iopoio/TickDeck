## 되돌린 것 (본부 판단)

코과장이 함께 제안한 CSS 봉인(`.split-body { flex:0 0 auto; min-height:min-content }` +
`.split-note-row { flex-shrink:0 }`)은 **본부가 되돌렸다.** 실물 렌더로 확인해 보니 겹침은
사라지지만 리드 문장이 잘리고 note 밴드가 화면 밖으로 밀려 사라진다 — 겹쳐서 읽기 힘든 상태가
조용히 안 보이는 상태로 바뀔 뿐이고 정보 손실은 오히려 커진다. 근본 해결은 "넘치는 페이지를
게이트가 막는 것"이므로 예산 가산 쪽에 둔다. 겹침 자체는 새 검사가 렌더마다 콘솔로 알린다.

## 검사 자체도 한 번 고쳤다

코과장 첫 판은 `.split-outer`의 **직계 형제만** 비교해서 정작 p09를 못 잡았다. 넘쳐 나오는 건
`.split-body` 박스가 아니라 그 안 카드이기 때문이다(박스는 `min-height:0`으로 압축되고 자식만
흘러나온다). 그려지는 블록끼리 비교하되 조상-후손 쌍을 빼고, 세로·가로가 동시에 겹칠 때만
경고하도록 본부가 다시 썼다. 그러고 나서야 p09와 p07이 잡혔다.
