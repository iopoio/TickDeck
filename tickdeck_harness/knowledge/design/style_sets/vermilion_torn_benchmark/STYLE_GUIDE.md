## 언제 쓰나

- 설문·벤치마크·업계 조사 리포트류 — 수치가 많고 "질문 → 데이터 → 답" 리듬으로 흐르는 덱
- 청중 = 실무 리더·의사결정권자 (B2B 톤이되 캐주얼한 편집 감각을 원할 때)
- 정서 = 대담·저널리스틱·손맛(찢은 종이·형광펜) — 차분한 컨설팅 톤이 필요하면 senior_orange_editorial 쪽

## 출처

- body: `background:#DDE1E7; display:flex; align-items:center; justify-content:center;` 가운데 스테이지 1개
- 폰트 스택: `"Pretendard Variable",Pretendard,-apple-system,"Apple SD Gothic Neo","Noto Sans KR","Malgun Gothic",sans-serif`

## 색 체계 (교체 가능 — 브랜드·주제에 맞게 갈아 끼운다)

- **패턴명**: 투톤 대비(고채도 액센트 + 잉크 블랙) + 파생 스택 스케일
- **유지할 것** (색을 바꿔도 지켜야 하는 관계):
  - 주연 2색 = 고채도 액센트 1 + 잉크 블랙 — 큰 면(풀블리드·대각 분할·검정 칩)끼리 부딪히는 대비가 아이덴티티. 크림은 무대, 다크 페이지는 웜 블랙(순검정 X)
  - 액센트 훼밀리는 2톤까지(브랜드 면용 + 차트 강조/CTA용 근접색) — 그 밖의 제3 유채색 금지 (원본의 "빨강·초록·파랑 금지" 일반화)
  - 다단계 스택 스케일 = 검정 → 액센트 → 액센트의 저채도 파생(밝은 틴트 2단 + 탁한 딥 1~2단) 5~6단 — 스택·다단 차트 전용, 본문 강조엔 진입 금지
  - 비교군·탈락 = 그레이 / 형광펜·테이블 틴트 = 액센트의 옅은 버전
  - 차트 = 액센트 주인공 + 검정 기준의 역할 관계 유지 (레버 6)
- **아래 hex는 예시 기본값**: 다른 브랜드/주제 덱에 쓸 때는 위 관계를 지키면서 실제 색상만 브랜드 팔레트로 교체한다. 스택 파생과 형광펜은 새 액센트에서 다시 뽑는다. 대체 팔레트 예시 —
  - 코발트: 면 #2148D1 · 차트 #1D51F5 · 형광펜 #D6E0FB
  - 포레스트 그린: 면 #1E7A4A · 차트 #12934F · 형광펜 #D2ECD9
  - 마젠타: 면 #C92B62 · 차트 #E0336F · 형광펜 #F9D7E4

## DNA 8레버 (필수 문법 — p_cover.html · p_body.html 이 정본)

1. **투톤 대비** — 버밀리온 vs 잉크 블랙 두 색이 주연. 페이지가 큰 면(풀블리드·대각 분할·검정 칩)으로 이 둘을 부딪힌다. 크림은 무대, 살구는 조연
2. **검정 배지 반전** — 제목 속 핵심 단어와 차트 섹션 라벨은 배경 반전 칩(라이트 배경 = 검정 칩 + 흰 글씨, 다크 배경 = 크림 칩 + 검정 글씨). 페이지당 배지 라벨 2~4개가 콘텐츠 존을 구획한다
3. **찢은 종이 모티프** — 표지·부 간지의 아이덴티티. 불규칙 폴리곤 clip-path 대각 분할 + 찢긴 단면(크림 테두리) + 안쪽에 흑백 추상 패턴 또는 반대색 면. 본문 데이터 장에는 쓰지 않는다 (간지 전용)
4. **질문형 헤드라인** — 본문 h1은 "~할까?" 질문문 또는 수치 포함 주장문 그대로. 제목만 읽어도 덱이 요약되게
5. **형광펜 하이라이트** — 해설 문단의 결론 문장·핵심 수치에 옅은 오렌지 마커(`background:#FBDCC5`). 문단당 1~2군데, 과용 금지
6. **차트 = 오렌지 주인공 + 검정 기준** — 강조 시리즈만 오렌지, 나머지는 검정(비교군 탈락은 그레이). 값 라벨은 바 위/안에 볼드 직접 표기, 축은 옅은 그레이 보조선만
7. **다크 허브 페이지** — 목차·챕터 진행 장은 웜 블랙(#191816) 풀블리드 + 좌측 세로 타임라인(점·선, 활성만 흰색) + 크림 카드에 체크박스 리스트
8. **오렌지 요약 장** — 부 마무리는 버밀리온 풀블리드 + 다단 칼럼 + ✳ 별표 불릿 + 검정 밑줄 강조 (덱에 1~2장만)

## 차트 문법

- 축·그리드: 옅은 그레이(#E5DED6 계열) 가로 보조선만, 축 라벨 11~12px #9B9B9B
- 값 라벨: 모든 주요 바에 볼드 직접 표기 (`38.0%` 식) — 라이트 바 위엔 검정, 다크 바 안엔 흰색
- 세로/가로 바: 강조 오렌지 + 기준 검정, 각진 사각. 합계·구간 강조는 오렌지 "총 NN%" 브래킷 주석
- 100% 스택바: 톤스케일(검정→오렌지→살구→브라운) 순서 고정, 범례는 상단 한 줄
- 테이블: 헤더 행 검정 배경 + 흰 글씨, 강조 행 틴트(#FCE8DB), 강조 셀 오렌지 볼드
- 파이: 최대 조각 검정, 강조 조각 오렌지, 나머지 톤스케일 — 리드선 + 바깥 라벨

## 콘텐츠 계약 (위반 = 실격)

- **수치는 briefs/pXX.json의 metrics 값만** 사용 — value·unit·scope 그대로. 수치 발명·반올림 변경·단위 생략 금지. 쓰지 않는 metric은 생략 OK
- note의 `==키워드==`는 `<b class="hl">키워드</b>`(하이라이트)로 변환
- footnote(정직 각주)는 반드시 유지 — 옅은 배경 카드로, "ⓘ" 머리
- 출처 푸터: brief의 sources에서 그 페이지에 실제 쓴 출처 기관명만
- 문체: 명사형 종결 위주·불릿 끝 마침표 없음·이모지 0·한자 0·brief 원문 워딩 우선 (다듬기 금지 — 원문 그대로 하류 전달)

## 페이지 다양성 (단조 금지)

- 직전·직후 페이지와 같은 실루엣 금지
- 찢은 종이는 간지에만 — 본문에 남발하면 아이덴티티가 죽는다
- 다크 허브·오렌지 요약·찢은 간지가 리듬을 만든다: 크림 본문 3~4장마다 톤 전환 1장
- 목차·출처·클로징은 조용하게 — 장식 최소, 타이포 위주
