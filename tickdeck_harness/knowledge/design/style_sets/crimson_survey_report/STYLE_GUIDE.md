# 크림슨 설문 리포트 스타일 정본 (crimson_survey_report)

## 언제 쓰나

- 설문·서베이 기반 트렌드 리포트 — Q&A 단위로 수치를 풀어가는 장문(40~60p급) 자료에 최적
- B2B 리드젠 리포트(무료 배포용 화이트페이퍼)처럼 "데이터 → 진단 → 자사 솔루션" 흐름이 있는 덱
- 브랜드 컬러가 레드 계열 단일 포인트이고, 밝고 에너지 있는 세일즈 톤이 필요할 때 (차분·중후 요구엔 부적합)

## 출처

학습 소스 = 팀스파르타 「2026 스파르타 AX 교육 트렌드 리포트」(63p PDF·후추님 지정) — **디자인 문법만 흡수**, 원본 문구·데이터·로고 복제 금지.

## 산출물 계약 (엄수)

- 파일: `pages/pXX.html` — **단독 완결 HTML** (외부 리소스 0 · CSS 인라인 `<style>` · JS 없음)
- 스테이지: `.stage` 고정 **1280×720px**, `overflow:hidden`. 콘텐츠가 720 안에 다 들어와야 함 — 넘칠 것 같으면 요소를 줄인다 (폰트 축소보다 블록 수 축소 우선)
- body: `background:#DDE1E7; display:flex; align-items:center; justify-content:center;` 가운데 스테이지 1개
- 폰트 스택: `"Pretendard Variable",Pretendard,-apple-system,"Apple SD Gothic Neo","Noto Sans KR","Malgun Gothic",sans-serif`

## 디자인 토큰

```
--red:#F5333F  --red-deep:#B01217  (강조·톤스케일 끝)
톤스케일(강조 순위): #F5333F → #F76A72 → #FA9BA1 → #FDD3D8   비교군·저순위 = #4A4D54 → #8B8E94 → #C6C9CE
--ink:#1B1C20  --sub:#6E7177  본문 배경 #FFFFFF  차트 패널 #F6F6F8  라인 #E8E9EC
다크 페이지 배경: #33363C  다크 카드: #43464D  (챕터 요약·스테이트먼트 전용)
간지/표지 그라디언트 메시: 좌상 흰빛 → #F5605A → #E32F27 → 우하 #8E0D10 (대형 radial 블롭 2~3개 겹침·경계 소프트)
Q 칩: 레드 그라디언트 캡슐(#F5333F→#C41A22) · 흰 700 · 카드 좌상단
말풍선 콜아웃: #17181A 라운드 12px + 삼각 꼬리 · 흰 13px 700 — 페이지당 결론 수치 1~2개에만
카드: radius 12~16px · 그림자 거의 없음(플랫) — 패널 색 대비로 구획
페이지 푸터: 우하 "Chapter N. 장제목  NN" 12.5px 700 #7C7F85 (페이지 번호만 ink로 진하게)
로고/브랜드 칩: 우상단 고정 (전 페이지 동일 위치)
```

## 타이포 위계 (관찰 수치)

- 좌측 레일 킥커: 13~14px 700 red (예: "세부 설문 결과 및 인사이트")
- 좌측 레일 제목: 26~30px 800 ink · 2줄 분절 · 자간 -0.02em — 핵심 구절만 red 스팬
- 우상단 해설 문단: 14~15px 400 `--sub` · 줄간 1.6 · 2~4줄 (제목과 같은 높이에서 시작)
- 설문 질문: 20~22px 800 ink · 2~3줄
- 바/파이 값 라벨: 15~18px 800 (강조 바는 바 안 흰색, 나머지는 바 끝 ink)
- KPI 빅넘버: 48~64px 800 ink · 위에 red 13px 700 라벨 · 아래 구분선 + sub 설명
- 표지 타이틀: 52~56px 800 흰색 2줄 · 위에 18px 600 흰 서브카피 1줄

## DNA 8레버 (필수 문법 — exemplar 2장이 정본: p_cover.html · p_body.html)

1. **좌측 레일 그리드** — 킥커+제목은 좌측 ~1/3 고정, 콘텐츠는 우측 2/3. 해설 문단은 상단 띠에서 우측 정렬로 흐름. 이 비대칭이 전 페이지의 뼈대
2. **설문 Q 카드 문법** — 회색 패널(#F6F6F8) 위에 [Q칩 → 질문 → 차트 → 💡인사이트 문단] 4요소 세로 스택. 인사이트는 패널 좌하단 14px, 수치 재인용 포함
3. **레드 톤스케일 = 순위** — 강조 상위 항목은 red 계열 그라데이션 순서, 하위·비교군은 무채색 계열. 색만 봐도 순위가 읽히게. 임의 다색 금지 (예외 = 산업 분류 같은 병렬 카테고리 한정)
4. **말풍선 콜아웃** — 페이지의 결론 수치 1개를 검정 말풍선(+꼬리)으로 차트 위에 띄운다. 남발 금지(1~2개)
5. **3모드 리듬** — 간지(레드 그라디언트 풀블리드·좌 "Chapter N." 우 흰 제목) ↔ 본문(백) ↔ 챕터 요약/스테이트먼트(다크 #33363C). 장 단위로 명도 리듬을 만든다
6. **그라디언트 필** — 강조 바·파이 조각·캡슐엔 상→하 red 그라디언트(밝→진). 플랫 단색은 비강조용
7. **다이어그램 = 얇은 red 아웃라인 원 + 점선 커넥터** — 프로세스·구조도는 흰 원(red 1.5px 보더) + 점선 리더 라인 + 하단 설명 텍스트. 채운 원은 강조 1개까지
8. **말하는 숫자 스택** — 좌측 레일에 빅넘버(100명/106명/124명식) 세로 나열 + 점선 리더로 설명 연결. 표 대신 숫자 자체를 타이포로 세운다

## 콘텐츠 계약 (위반 = 실격)

- **수치는 briefs/pXX.json의 metrics 값만** 사용 — value·unit·scope 그대로. 수치 발명·반올림 변경·단위 생략 금지. 쓰지 않는 metric은 생략 OK
- note의 `==키워드==`는 `<b class="hl">키워드</b>`(레드)로 변환
- footnote(정직 각주)는 반드시 유지 — 옅은 배경 카드(#FDECED·보더 #F8C9CD)로, "ⓘ" 머리
- 출처 푸터: brief의 sources에서 그 페이지에 실제 쓴 출처 기관명만
- 문체: 명사형 종결 위주·불릿 끝 마침표 없음·이모지 0·한자 0·brief 원문 워딩 우선 (다듬기 금지 — 원문 그대로 하류 전달)
  - 단 본 세트의 💡 인사이트 머리 기호는 예외 허용 (원본 문법의 시그니처 — 그 외 이모지 주석은 흡수 X)

## 페이지 유형 목록 (원본 관찰)

표지(그라디언트 메시) / INDEX 2단 번호 목차 / 챕터 간지(레드 풀블리드) / 설문 Q 싱글 카드 / 설문 Q 듀얼 카드 / 풀와이드 그룹 바차트 / 비교 테이블 + 우측 해설 카드 4분면 / 다크 챕터 요약(번호 칩 6카드) / 다크 스테이트먼트(중앙 타이포) / 프로세스 스텝(원 4개 + 점선) / 버블 스택(면적=%) / 3단 정보 카드 / KPI 빅넘버 3카드 / 로고 월 / 상품 테이블 + CTA 카드

## 페이지 다양성 (단조 금지)

- 직전·직후 페이지와 같은 실루엣 금지. Q 카드 장이 연속되면 싱글↔듀얼·차트 형태(바/파이/버블)를 교차
- 다크 모드 페이지는 덱당 2~3장(챕터 요약·스테이트먼트)만 — 남발하면 리듬이 죽는다
- 목차·출처·outro는 조용하게 — 장식 최소, 타이포 위주

## 차용 시 유의 (원본에서 흡수하지 않는 것)

- 클립아트풍 인물 일러스트·실물 스크린샷 콜라주 → 톤 붕괴, 우리 기준 미달. 커스텀 SVG로 대체
- 근거 없는 다색 이탈(보라·청록 병용 장) → 레버 3의 톤스케일 원칙으로 교정
- 이모지 차트 주석(😭🤔⏰) 남발 → 💡 인사이트 머리만 선택 허용, 나머지 금지
