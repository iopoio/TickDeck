- 정서: 절제·학술적 신중함·아카이브 종이 느낌 — 목소리를 낮출수록 믿음이 가는 자리

## 산출물 계약 (엄수)

- 파일: `pages/pXX.html` — **단독 완결 HTML** (외부 리소스 0 · CSS 인라인 `<style>` · JS 없음)
- 스테이지: `.stage` 고정 **1280×720px**, `overflow:hidden`. 콘텐츠가 720 안에 다 들어와야 함 — 넘칠 것 같으면 요소를 줄인다 (폰트 축소보다 블록 수 축소 우선)
- body: `background:#DDE1E7; display:flex; align-items:center; justify-content:center;` 가운데 스테이지 1개
- 폰트 스택: `"Pretendard Variable",Pretendard,-apple-system,"Apple SD Gothic Neo","Noto Sans KR","Malgun Gothic",sans-serif`

## DNA 8레버 (필수 문법 — exemplar 2장이 정본, 반드시 먼저 열어볼 것: exemplar_cover.html · exemplar_body.html)

1. 제목은 밴드 안에 — 본문 페이지 제목은 상단 슬레이트 그라디언트 밴드 위 흰 글자·완결 평서문 그대로. 밴드 밖 본문에서 강조는 `<b class="hl">`(슬레이트)
2. 지면은 종이 — 순백 배경·radius 0·카드 테두리 대신 헤어라인과 여백으로 구획. 그림자·글로우 금지
3. 차트는 직접 라벨 — 선 끝에 계열명·값을 선 색으로 직접 표기 (범례 매핑 숙제 금지). 비교군은 점선 + 그레이
4. 데이터 = 뮤트 5색 톤스케일만. 채도 높은 원색 금지. semantic 예외: 부정 #B42318·긍정 #13795B
5. **주장 자체를 그린다** — 벌어지는 격차·경계선 같은 주장 형태를 커스텀 SVG로 (exemplar_body의 갈라지는 두 선처럼)
6. 스탯 카드는 조용하게 — 옅은 그라디언트 필 + 슬레이트 상단 룰 1개·큰 수치는 슬레이트. 페이지당 스탯 카드 최대 2장
7. 시그니처 모티프: 점선 별자리 경로 (아주 옅게, 지면 우하단, 콘텐츠 뒤) · 표지 5색 룰 바
8. 검증 칩: 수치 있는 페이지 우측/하단에 `✓ 이 페이지 수치 n/n — 출처 원문 대조` (슬레이트 보더 pill). n = 그 페이지에 실제 표기한 registry 수치 개수

## 콘텐츠 계약 (위반 = 실격)

- **수치는 briefs/pXX.json의 metrics 값만** 사용 — value·unit·scope 그대로. 수치 발명·반올림 변경·단위 생략 금지. 쓰지 않는 metric은 생략 OK
- note의 `==키워드==`는 `<b class="hl">키워드</b>`(슬레이트 #5A6F92)로 변환
- footnote(정직 각주)는 반드시 유지 — 옅은 배경 카드(#F2F4F8·보더 #DCE1EA)로, "ⓘ" 머리
- 출처 푸터: brief의 sources에서 그 페이지에 실제 쓴 출처 기관명만
- 문체: 명사형 종결 위주·불릿 끝 마침표 없음·이모지 0·한자 0·brief 원문 워딩 우선 (다듬기 금지 — 원문 그대로 하류 전달)

## 페이지 다양성 (단조 금지)

- 직전·직후 페이지와 같은 실루엣 금지 (타이틀 밴드는 공통 크롬이라 예외 — 밴드 아래 골격을 바꾼다)
- 비정형(statement·풀블리드 다크 간지) 최소 2장으로 종이 페이지 사이 리듬 교차
- 목차·출처·outro는 조용하게 — 장식 최소, 타이포 위주
