# pop_electric_dark 스타일 정본 (demo_batch3_pop 데모에서 발굴)

> 출전: `_workspace/demo_batch3_pop.html` (theme-pop-dark — 팝 다크·다색 필 블록·오렌지 북엔드, 후추님 7/4 스샷 스타일 계보). 디자인만 배운다 — 콘텐츠·수치는 각 런의 검증분만.

## 언제 쓰나

- 주제: 크리에이터 이코노미·컨슈머 트렌드·신제품 쇼케이스 등 에너지가 본체인 주제
- 청중: 젊은 실무자·커뮤니티·데모 관객 — 첫 3초 임팩트가 체류를 결정하는 자리
- 정서: 볼드·전기 오르는 팝·자신감 — 점잖으면 지는 판에서 손드는 덱

## 산출물 계약 (엄수)

- 파일: `pages/pXX.html` — **단독 완결 HTML** (외부 리소스 0 · CSS 인라인 `<style>` · JS 없음)
- 스테이지: `.stage` 고정 **1280×720px**, `overflow:hidden`. 콘텐츠가 720 안에 다 들어와야 함 — 넘칠 것 같으면 요소를 줄인다 (폰트 축소보다 블록 수 축소 우선)
- body: `background:#DDE1E7; display:flex; align-items:center; justify-content:center;` 가운데 스테이지 1개
- 폰트 스택: `"Pretendard Variable",Pretendard,-apple-system,"Apple SD Gothic Neo","Noto Sans KR","Malgun Gothic",sans-serif`

## 디자인 토큰 (기본 예시 — 아래 "색 체계" 참고)

```
--accent:#FF5A1F (일렉트릭 오렌지)  --accent2:#2B3BE8 (코발트)
지면: --c60:#131118 (거의 검정·웜 틴트)  --c30:#1C1922  body 밖 #0D0B11
--ink:#F5F2EC (웜 화이트)  --muted:#A7A2AE  라인 rgba(245,242,236,.16)
카드: rgba(255,255,255,.06) · radius 22px (라운드 블롭 — 이 세트의 물성)
톤스케일(팝 4+1): #FF5A1F → #2B3BE8 → #E8347C(마젠타) → #8A2BE8(퍼플) → #F5F2EC
메트릭 = 컬러 필 블록: 보더 없음·톤스케일 순환 필(1번째 오렌지·2번째 코발트·3번째 마젠타…)·글자는 흰색
표지·간지 = 오렌지 풀블리드 북엔드: 배경 #E8551A·잉크 #17120E (다크 본문과 강한 리듬 교차)
러닝 헤드 크롬: 상단 중앙 문서 제목(모노·자간 넓게) + 우상단 "NN / NN"
킥커: 좌측 대시(—) + 모노 대문자 오렌지
```

## 색 체계 (교체 가능 — 브랜드·주제에 맞게 갈아 끼운다)

**패턴명**: 다크 베이스 + 고채도 보색 듀오 + 4색 순환 필 블록 (강조 1개 원칙)

**유지할 것** (색을 바꿔도 지켜야 하는 관계):
- 액센트 = **고채도 대비 페어** — 웜 주역 1 + 쿨 보조 1. 뮤트 금지 — 채도가 이 세트의 물성. 인접색 페어로 바꾸면 팝이 죽는다 (그건 navy_glow 문법)
- 톤스케일 = **유채 4색 + 잉크 1 (4+1)** — 필 블록이 순환하며 색을 낸다 (카테고리 순환 인코딩). 한 페이지 안 계열당 1색 고정·의미 없는 무지개 금지
- 지면 = 거의 검정 다크 (주 액센트 온도의 틴트). 색은 필 블록만 낸다 — 지면 장식으로 색 뿌리기 금지
- 강조 1개 원칙: 비교 묶음에서 주 액센트 풀 필은 하나만·나머지는 다크 유리 카드
- 북엔드: 표지·간지 = 주 액센트 풀블리드 1~2장만 (풀블리드 잉크는 어두운 웜 잉크)

**아래 hex는 예시 기본값** — 다른 브랜드/주제 덱에선 위 관계를 지키고 실제 색상만 브랜드 팔레트로 교체:
- 브랜드가 그린 주역이면: --accent #21D07A + --accent2 #7A2BE8(퍼플) · 순환 = #21D07A → #7A2BE8 → #E8347C → #2B3BE8 → 웜 화이트 · 북엔드 = 그린 풀블리드
- 브랜드가 옐로 주역이면: --accent #FFC21F + --accent2 #1FA8FF(시안) · 순환 3·4번째는 마젠타·퍼플 유지

## DNA 8레버 (필수 문법 — exemplar 2장이 정본, 반드시 먼저 열어볼 것: exemplar_pricing.html · exemplar_statement.html)

1. 제목은 헤비 — h1 850·자간 -.01em·주장문 그대로. 본문 텍스트는 눌린 그레이(다크 공통 문법) — 흰 잉크는 제목·필 블록 안에만
2. **카드가 곧 팝 오브제** — 메트릭·비교 카드는 테두리 없는 컬러 필 블록(radius 22). 페이지의 색은 필 블록이 낸다. 지면 장식으로 색 뿌리기 금지
3. 강조 1개 원칙 — 비교 카드 묶음에서 미는 것 하나만 오렌지 풀 필, 나머지는 다크 유리 카드 (exemplar_pricing의 가운데 카드처럼)
4. 데이터 = 팝 톤스케일 순환. 단 한 페이지 안에서 의미 없는 무지개 금지 — 계열당 1색 고정
5. **주장 자체를 그린다** — 큰 수치는 코발트 필 블록에 태워서. 기성 차트 복제보다 블록·도형 구성이 이 세트의 언어
6. 시그니처 모티프: 점선 별자리 경로(옅은 오렌지 톤, 콘텐츠 뒤) + statement 장 우측 세로 고스트 워드마크(회전 대형 타이포·전용 여백 컬럼 확보 — 본문과 겹치지 않는다)
7. 표지·간지 오렌지 풀블리드는 북엔드로만 (덱당 표지+간지 1~2장) — 남용하면 팝이 죽는다
8. 검증 칩: 수치 있는 페이지 우측/하단에 `✓ 이 페이지 수치 n/n — 출처 원문 대조` (오렌지 보더 pill). n = 그 페이지에 실제 표기한 registry 수치 개수

## 콘텐츠 계약 (위반 = 실격)

- **수치는 briefs/pXX.json의 metrics 값만** 사용 — value·unit·scope 그대로. 수치 발명·반올림 변경·단위 생략 금지. 쓰지 않는 metric은 생략 OK
- note의 `==키워드==`는 `<b class="hl">키워드</b>`(오렌지 #FF5A1F)로 변환
- footnote(정직 각주)는 반드시 유지 — 유리 카드(흰 6% 필·radius 22)로, "ⓘ" 머리
- 출처 푸터: brief의 sources에서 그 페이지에 실제 쓴 출처 기관명만
- 문체: 명사형 종결 위주·불릿 끝 마침표 없음·이모지 0·한자 0·brief 원문 워딩 우선 (다듬기 금지 — 원문 그대로 하류 전달)

## 페이지 다양성 (단조 금지)

- 직전·직후 페이지와 같은 실루엣 금지
- 오렌지 풀블리드·필 블록 그리드·statement 워드마크 장으로 리듬 교차 — 비정형 최소 2장
- 목차·출처·outro는 조용하게 — 장식 최소, 타이포 위주
