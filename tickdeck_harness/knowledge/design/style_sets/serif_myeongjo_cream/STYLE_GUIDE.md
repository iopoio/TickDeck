# serif_myeongjo_cream 스타일 정본 (demo_batch3_serif 데모에서 발굴)

> 출전: `_workspace/demo_batch3_serif.html` (theme-editorial-serif — 크림 지면·명조 제목·카드리스 인쇄 조판. 7/3~7/4 그리드 리팩터 3차까지 반영분). 디자인만 배운다 — 콘텐츠·수치는 각 런의 검증분만.

## 언제 쓰나

- 주제: 인문·문화·브랜드 에세이형 리포트, 긴 호흡의 관점 글을 덱으로 옮길 때
- 청중: 활자에 익숙한 독자·브랜드 감도가 높은 클라이언트 — 인쇄물 품위가 신뢰인 자리
- 정서: 고전적 품위·조용한 권위·잡지 아카이브 — 데이터보다 문장이 주인공일 때

## 산출물 계약 (엄수)

- 파일: `pages/pXX.html` — **단독 완결 HTML** (외부 리소스 0 · CSS 인라인 `<style>` · JS 없음)
- 스테이지: `.stage` 고정 **1280×720px**, `overflow:hidden`. 콘텐츠가 720 안에 다 들어와야 함 — 넘칠 것 같으면 요소를 줄인다 (폰트 축소보다 블록 수 축소 우선)
- body: `background:#DDE1E7; display:flex; align-items:center; justify-content:center;` 가운데 스테이지 1개
- 폰트 스택: `"Pretendard Variable",Pretendard,-apple-system,"Apple SD Gothic Neo","Noto Sans KR","Malgun Gothic",sans-serif`

## DNA 8레버 (필수 문법 — exemplar 2장이 정본, 반드시 먼저 열어볼 것: exemplar_pricing.html · exemplar_statement.html)

1. 제목은 명조로 — h1 세리프·주장문 그대로. 세리프는 제목·대형 수치 전용, 본문까지 세리프 금지
2. **카드리스** — 박스·테두리·그림자 전부 벗긴다. 구획 = 여백 + 헤어라인 + 옅은 틴트 필(잉크 4~8%)만. 강조 1개만 와인 헤어라인 프레임 허용 (exemplar_pricing의 가운데 칸처럼)
3. 메트릭은 러닝 스탯 — 라벨 이탤릭(소) 위·세리프 대형 수치(와인) 아래. 카드 필 금지·수치가 활자로 서게
4. 데이터 = 뮤트 톤스케일만·차트 모서리 각지게(rx 0)·차트 숫자도 세리프 조판 — "기술 대시보드 각바" 관례에서 이탈
5. **주장 자체를 그린다** — 콜아웃은 좌측 세로 룰선 하나로 본문에 녹인 풀쿼트 (인용 박스 금지)
6. 시그니처 모티프: 우측 세로 고스트 워드마크(회전 대형 명조 타이포·전용 여백 컬럼) + 점선 별자리 경로(고스트 톤, 콘텐츠 뒤)
7. 지면 골격 자체를 바꾼다 — 팔레트 스와핑에 그치면 "테두리만 없앤 버전"으로 읽힌다 (7/3 후추님 지적). 제본선 여백·분할 비율(1.35:1)·마지막 행 하단 앵커까지가 세트
8. 검증 칩: 수치 있는 페이지 우측/하단에 `✓ 이 페이지 수치 n/n — 출처 원문 대조` (와인 헤어라인 pill). n = 그 페이지에 실제 표기한 registry 수치 개수

## 콘텐츠 계약 (위반 = 실격)

- **수치는 briefs/pXX.json의 metrics 값만** 사용 — value·unit·scope 그대로. 수치 발명·반올림 변경·단위 생략 금지. 쓰지 않는 metric은 생략 OK
- note의 `==키워드==`는 `<b class="hl">키워드</b>`(와인 #6B2E2E)로 변환
- footnote(정직 각주)는 반드시 유지 — 옅은 배경 카드(#F1EBE1·보더 #E2D8C6)로, "ⓘ" 머리
- 출처 푸터: brief의 sources에서 그 페이지에 실제 쓴 출처 기관명만
- 문체: 명사형 종결 위주·불릿 끝 마침표 없음·이모지 0·한자 0·brief 원문 워딩 우선 (다듬기 금지 — 원문 그대로 하류 전달)

## 페이지 다양성 (단조 금지)

- 직전·직후 페이지와 같은 실루엣 금지
- 간지 거대숫자·2단 칼럼(칼럼 룰선)·statement 워드마크 장으로 리듬 교차 — 비정형 최소 2장
