### **프리미엄 차트 디자인 실전 규칙 (McKinsey/Bloomberg 수준)**

#### **1) 차트 종류 선택: 스토리에 맞는 차트 고르기**
*   **시계열 (시간 경과 데이터):**
    *   **Line Chart (선 차트):** 기본. 2개 이상의 시계열 비교 시 사용.
    *   **Area Chart (면적 차트):** 1개 시계열의 '누적' 또는 '비중' 강조 시. 색상 투명도 10%로 처리.
    *   **Slope Chart (기울기 차트):** 2개 시점(예: 2020년 vs 2023년)의 값 변화를 강조할 때. 직관적.
*   **비교 (카테고리 간 값 비교):**
    *   **Bar Chart (막대 차트):** 기본. 카테고리 이름이 길거나 많을 때는 **가로 막대 차트** 사용.
    *   **Dot Plot (점 차트):** 카테고리가 10개 이상일 때. 막대보다 공간 효율적이고 깔끔함.
*   **비중 (전체 중 비율):**
    *   **Donut Chart (도넛 차트):** 1개의 핵심 비중을 한눈에 보여줄 때만 사용. (예: 시장 점유율 35%)
    *   **피해야 할 것:** 파이 차트 (비중 비교가 어려움), 3D 효과, 5개 이상의 세그먼트.
*   **분포 (데이터의 흩어짐):**
    *   **Histogram (히스토그램):** 연속형 데이터의 빈도 분포.
    *   **Box Plot (상자 수염 그림):** 데이터의 사분위수, 이상치를 보여줄 때.
*   **관계 (변수 간 상관관계):**
    *   **Scatter Plot (산점도):** 기본. 점의 크기/색상으로 3차원 데이터 표현 가능.
*   **오용 피하기:**
    *   **이중축 (Dual Y-axis):** 절대 금지. 두 축의 스케일이 다르면 비교가 왜곡됨. (대안: 두 개의 별도 차트를 나란히 배치)
    *   **3D 차트:** 가독성을 떨어뜨림. 2D로 처리.

#### **2) 라인 차트 프리미엄 디테일**
*   **축 (Axis):**
    *   축선: `#CCCCCC` (회색), 두께 `0.5px`.
    *   눈금 (Tick): 축선과 동일 색상, 길이 `3px`.
*   **그리드 (Grid):**
    *   주 그리드 (Major Grid): `#EEEEEE` (연한 회색), 두께 `0.5px`.
    *   보조 그리드 (Minor Grid): `#F5F5F5` (아주 연한 회색), 두께 `0.3px`, `stroke-dasharray: 2,2` (점선).
*   **값 라벨 (Value Label):**
    *   위치: 데이터 포인트 바로 위/아래에 배치. 텍스트 색상 `#666666`, 크기 `12px`.
    *   표시: 값 변화가 크거나 중요한 지점에만 표시. 모든 포인트에 표시 금지.
*   **영역 채움 (Area Fill):**
    *   색상: 메인 라인 색상과 동일, 투명도 `0.1` (10%).
*   **강조선 vs 보조선:**
    *   강조선 (예: 전년도 평균선): 실선, 두께 `2px`, 색상 `#FF5722` (강조 색).
    *   보조선 (예: 분기별 기준선): 점선, 두께 `0.5px`, 색상 `#CCCCCC`.
*   **끝점 강조 (Endpoint Emphasis):**
    *   마지막 데이터 포인트: 크기 `4px`의 원, 채움 색상 `#FFFFFF`, 테두리 색상 메인 라인 색상.
*   **주석 (Annotation):**
    *   위치: 차트 바깥쪽, 화살표로 연결. 배경색 `#FFFFFF`, 테두리 `#DDDDDD`, 여백 `8px`. 텍스트 `14px`, `#333333`.
*   **여백 (Gutter):**
    *   차트 전체를 감싸는 여백: 최소 `20px`.

#### **3) 막대 차트 (Bar Chart)**
*   **가로 vs 세로:**
    *   **가로 막대 (Horizontal Bar):** 카테고리 이름이 5글자 이상이거나 7개 이상일 때. 가독성이 높음.
    *   **세로 막대 (Vertical Bar):** 카테고리가 6개 이하일 때.
*   **그룹/누적:**
    *   **그룹 막대 (Grouped Bar):** 2~3개의 하위 카테고리를 비교할 때.
    *   **누적 막대 (Stacked Bar):** 전체의 구성 비율을 보여줄 때. 5개 이상의 세그먼트는 피함.
*   **정렬 순서:**
    *   **절대 원칙:** 값 크기 순으로 내림차순 정렬. (자연스러운 순서가 있을 경우 제외, 예: 연령대)
*   **색 강조:**
    *   **원칙:** 하나의 강조 색상만 사용. (예: 1위 막대만 `#FF5722`, 나머지는 `#CCCCCC`)
