# 차트 디자인 캐논 흡수 종합 — 데이터 시각화 (GLM·Qwen·MiniMax 3-way, 2026-06)

## PART A. 백본 (3사 수렴 — 지키느냐 마느냐)

### A1. 차트 종류 매칭 (인지작업 ↔ 시각인코딩)
- 시계열 = **line**(2+ 시리즈 비교·≥7점) · **area**(단일·누적/볼륨·투명도 8~12%) · **slope**(정확히 2시점 비교)
- 비교 = **bar**(라벨 길거나 ≥5개면 가로·값 내림차순 정렬) · **dot**(10+ 카테고리)
- 비중 = **donut**(단일 핵심 비중·세그먼트 ≤4~5·중앙 KPI) · **stacked bar**(시간별 비중)
- 분포 = histogram/box · 관계 = scatter
- **금지(3사 공통)**: 이중 Y축 · 3D · 6+ 파이 · 레이더 · 알파벳 정렬

### A2. 라인 차트 프리미엄 디테일
- 그리드 = **가로만**(세로 제거·흐름 끊음)·연한 회색
- 위계 = 강조선 2~2.5px 실선 / 보조선 1.5px **점선** 회색
- 영역 채움 = 강조선 아래만·**투명도 8~12%**(20% 넘으면 무거움)·보조선엔 X
- 라벨 = **직접 라벨링**(범례보다)·끝점 강조(r=4·흰 채움+액센트 테두리="여기가 지금")
- 주석 = 변곡점에만 leader line + 11px 회색(화살표 자제)

### A3. 막대 차트
- 가로 if 라벨 ≥5자 또는 ≥5개 · 값 **내림차순**(시계열 제외) · **강조 1색**(나머지 회색 #CCC)
- **baseline 0 절대**(자르면 비율 거짓말) · 데이터 라벨(안=흰/밖=회색·6px 이격)
- 그룹 ≤3 시리즈(4+ = small multiples) · 누적은 합이 의미 있을 때만

### A4. 비중(도넛)
- 세그먼트 ≤4~5 · 두께 = 외경의 25~40% · 중앙 = 가장 중요한 KPI(40~56px) + 작은 라벨

### A5. 다수치 요약판(stat-grid) — 메조·KPMG 시그니처
- 격자 4열(데스크탑) · 셀 위계 3단: **라벨**(11~12px·대문자/회색·자간) → **큰숫자**(40~54px·800·`tabular-nums`) → **델타**(13~14px·▲녹 #2E9E6B/▼적 #C8553D)
- 구분 = 박스섀도 대신 얇은 보더/상단 룰

### A6. 색·타이포·정직
- **1색 강조** + 중립 회색 + 배경. 의미색(증가 녹/감소 적). 데이터-잉크 최대(불필요 그리드·테두리·범례 박스 제거)
- 제목 = **결론 문장**(서술적). 숫자 우측정렬·`font-variant-numeric:tabular-nums`·천단위 콤마
- 거짓차트 회피: 잘린 축 X·체리피킹 X·면적 왜곡 X
- 에디토리얼 = 제목(결론) → 출처(우상단) → 차트 → 해석 1~2줄

## PART B. 발산 렌즈 (좋은 디테일 — 골라 쓰기)
- **유령막대/벤치마크 오버레이**(Qwen): 실막대 뒤 opacity .1 회색막대 = 업계평균/목표 → 눈으로 비교선 안 그어도 앞섬/뒤처짐 직관
- **단위 통합**(Qwen): Y축에 1,000,000 X → 상단 "(단위: 백만)" + 축은 1·2·3
- **스퀸트 테스트**(Qwen): 흐리게 봐도 강조색·결론이 먼저 보여야. 다 튀면 나열일 뿐
- **slope 차트**(MiniMax·GLM): 2시점 전후/순위변동 강조
- **dot plot**(GLM): 10+ 카테고리에 막대보다 깔끔
- **small multiples**(MiniMax): 4+ 시리즈는 분할(이중축 대신)

## PART C. 엔진 코드화 현황 (engine.py)
- ✅ `L_line` — 가로 그리드·강조/점선 보조·영역 12%·끝점 강조·직접 값라벨·범례·KEY INSIGHT
- ✅ `L_donut` — 중앙 KPI + 측면 보조통계
- ✅ `L_statgrid` — 4~6 수치 3단 위계 격자(라벨→큰숫자→델타·의미색·tabular-nums)
- ✅ tabular-nums(kpi·statgrid)
- ⬜ 백로그: `L_slope`(2시점)·`L_dot`(10+)·막대 내림차순 정렬+유령막대 옵션(`L_bar` 보강)·단위 통합 헬퍼
