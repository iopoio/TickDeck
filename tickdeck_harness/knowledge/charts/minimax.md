# minimax (minimax/minimax-m3)

# 프리미엄 차트 디자인 실전 규칙 — 10개 챕터 완전판

> 원칙: **"데이터-잉크 비율을 극대화하라. 장식은 제거하고, 강조는 1색으로만."** — Edward Tufte의 정신을 2026년 에디토리얼 워크플로에 맞게 재해석.

---

## 1) 차트 종류 선택 — 매트릭스

| 목적 | 차트 | 임계값 / 규칙 | 피할 것 |
|---|---|---|---|
| **시계열** (연속) | Line | 데이터 포인트 ≥7개, X축이 시간 | 포인트 <5개면 bar |
| **시계열** (불연속·이벤트) | Bar (세로) | 분기/월별 등월별 변동 | line 쓰면 거짓 부드러움 |
| **카테고리 비교** | Bar (가로) | 카테고리 ≤7개, 라벨 길 때 | 세로 bar (라벨 겹침) |
| **카테고리 비교 (순위)** | Bar (정렬) | 값 기준 내림차순 정렬 | 알파벳 정렬 (의미 없음) |
| **2시점·2그룹 비교** | Slope chart | 정확히 2개 시점, 2~5그룹 | line (중간값 오해) |
| **부분-전체** | Donut | 세그먼트 ≤5개, 합=100% | 6개+ 세그먼트, 3D pie |
| **누적·볼륨** | Stacked area | 시간축, 3~4 시리즈 | 5+ 시리즈 (읽기 불가) |
| **관계 (X-Y)** | Scatter / Dot | 연속 변수 2개 | 버블 (3번째 차원 오용) |
| **분포** | Histogram / Box | n≥30 | 평균만 (분산 숨김) |
| **지리** | Choropleth | 지역별 비율 | 절대값 (면적 편향) |

**경고 신호 (쓰지 마):**
- ❌ **이중 Y축** — 두 스케일을 임의로 매칭, 거의 항상 거짓말. 대신 small multiples 또는 인덱스(100 기준) 변환.
- ❌ **3D 차트** — 원근이 길이를 왜곡. 항상 2D.
- ❌ **Pie 6개+** — 각도 비교 불가. bar로 전환.
- ❌ **레이더 차트** — 면적 오해, 순서 의존. 사용 자제.

## 2) 라인 차트 프리미엄 디테일

### 핵심 수치 (픽셀 단위)

```
캔버스: 720 × 405 (16:9) 또는 600 × 400
plot 영역 패딩: 좌 60px / 우 40px / 상 30px / 하 40px
라인 두께: 2px (단일) / 1.5px (멀티)
엔드포인트 원: r=4px, fill=accent, stroke=white 1.5px
그리드: 가로만, #E5E7EB, 1px, 점선 아님
축선: #CBD5E1, 1px (또는 제거)
축 라벨: 11px, #64748B, sans-serif
값 라벨: 11px, #0F172A, 마지막 포인트 우측 8px 간격
주석 폰트: 11px, #475569
```

### SVG 예시 (단일 시리즈, 엔드포인트 강조)

```svg
<svg viewBox="0 0 720 405" font-family="Inter, sans-serif">
  <!-- 그리드 (가로만) -->
  <g stroke="#E5E7EB" stroke-width="1">
    <line x1="60" y1="80"  x2="680" y2="80"/>
    <line x1="60" y1="160" x2="680" y2="160"/>
    <line x1="60" y1="240" x2="680" y2="240"/>
    <line x1="60" y1="320" x2="680" y2="320"/>
  </g>
  <!-- 메인 라인 -->
  <path d="M60,260 L180,220 L300,180 L420,150 L540,110 L660,90"
        fill="none" stroke="#2563EB" stroke-width="2"
        stroke-linecap="round" stroke-linejoin="round"/>
  <!-- 엔드포인트 강조 -->
  <circle cx="660" cy="90" r="4" fill="#2563EB" stroke="#fff" stroke-width="1.5"/>
  <!-- 값 라벨 (직접 라벨링) -->
  <text x="672" y="94" font-size="11" fill="#0F172A" font-weight="600">$4.2M</text>
  <!-- 주석 (annotation) -->
  <line x1="420" y1="150" x2="420" y2="120" stroke="#94A3B8" stroke-width="1" stroke-dasharray="2,2"/>
  <text x="425" y="115" font-size="11" fill="#475569">신제품 출시</text>
</svg>
```

### 7가지 프리미엄 디테일

1. **직접 라벨링 > 범례(legend)** — 라인은 끝에 값, 시리즈는 색으로 식별. 범례는 시선 이동 강제.
2. **그리드는 가로만** — 세로 그리드 제거. 데이터 흐름을 끊지 않음.
3. **영역 채움(area fill)**은 `rgba(37,99,235,0.08)` 정도의 8% 불투명도. 20% 넘으면 무거워짐.
4. **강조선 1개** — 비교 기준선(예: 목표치)은 점선 `stroke-dasharray="4,3"`, 색 `#94A3B8`.
5. **엔드포인트 강조** — 마지막 점에 4px 원 + 흰색 1.5px 테두리. "여기가 지금" 신호.
6. **주석은 leader line + 텍스트** — 11px, 본문과 같은 회색(#475569). 화살표 사용 자제.
7. **여백** — plot 영역 위 30px, 아래 40px. 답답하면 premium 느낌 사라짐.

## 3) 막대 차트 — 가로/세로, 정렬, 강조

### 선택 규칙

| 조건 | 선택 |
|---|---|
| 카테고리 라벨 >8자 또는 5개+ | **가로(horizontal)** |
| 시계열·순서 의미 | **세로(vertical)** |
| 값 비교가 핵심 | **가로** (길이 비교가 자연스러움) |

### 정렬 순서 원칙

- **값 기준 내림차순** (랭킹 의도) — 가장 일반적
- **시간/순서** (시계열) — 시간순 유지
- **알파벳순은 거의 항상 잘못** — 의미 없음

### 강조 1색 원칙 (가장 중요)

```
기본 색: #CBD5E1 (light gray)
강조 색: #2563EB (또는 #DC2626) — 단 1개 막대만
라벨 색: #0F172A (검정)
```

**Before / After:**

```
❌ Before: 모든 막대가 다른 색 (무지개)
🟦🟩🟨🟪🟥 — 시각적 소음, 비교 불가

✅ After: 1개만 강조
⬜⬜⬜🟦⬜ — "이게 주인공" 즉시 인식
```

### 데이터 라벨 위치

- **세로 bar**: 막대 위 4px, 11px, `#0F172A`, `font-weight: 600`
- **가로 bar**: 막대 오른쪽 6px, 11px, 동일
- **0에 가까울 때**: 막대 안쪽 흰색 텍스트 (충분히 두꺼울 때만)

### Baseline 0 원칙

- 막대 차트는 **반드시 Y축 0 시작**. 잘리면 비율 거짓말.
- 예외: 줌인 차트는 "축이 0부터 시작하지 않음" 명시 + 물결표(✂) 표시.

### 그룹/누적

- **그룹(grouped)**: 비교 ≤3 시리즈. 4+ 되면 small multiples로 분할.
- **누적(stacked)**: 전체 합이 의미 있을 때만. 100% stacked는 비중 비교 전용.
- 막대 사이 간격: 막대 폭의 30~50%. 너무 붙으면 분리감 없음.

## 4) 비중 — 도넛 / 게이지

### 언제 쓰고 언제 피하나

| ✅ 사용 | ❌ 회피 |
|---|---|
| 세그먼트 ≤5개 | 6개+ (bar로) |
| 합=100% 명확 | 음수 포함 |
| "1개가 과반" 강조 | 정밀 비교 필요 (각도 비교 약함) |
| 중앙 KPI 강조 | 시계열 변화 |

### 중앙 수치 처리 (메조·KPMG 스타일)

```
중앙 큰 숫자: 40~56px, font-weight 700, #0F172A
중앙 라벨:    11px, uppercase, letter-spacing 0.05em, #64748B
예: "총 매출" (11px) / "$12.4M" (48px)
```

### 도넛 두께

- **stroke-width = 외경의 30~40%** (예: r=80 → stroke 28px)
- 너무 얇으면 bar처럼 보임, 너무 두르면 가운데 공간 없음.

### SVG 예시

```svg
<svg viewBox="0 0 200 200">
  <!-- 배경 트랙 -->
  <circle cx="100" cy="100" r="70" fill="none" stroke="#F1F5F9" stroke-width="28"/>
  <!-- 세그먼트 (62%) -->
  <circle cx="100" cy="100" r="70" fill="none" stroke="#2563EB" stroke-width="28"
          stroke-dasharray="272.6 439.8" transform="rotate(-90 100 100)"
          stroke-linecap="butt"/>
  <!-- 중앙 수치 -->
  <text x="100" y="98" text-anchor="middle" font-size="44" font-weight="700" fill="#0F172A">62%</text>
  <text x="100" y="118" text-anchor="middle" font-size="10" fill="#64748B"
        letter-spacing="1.5">시장점유율</text>
</svg>
```

## 5) 다수치 요약판 (Stat Grid) — 메조·KPMG 스타일

### 4~6개 KPI를 위계 있게 배치

**그리드 사양:**

```
컨테이너: max-width 1200px, padding 32px
열 수: 4 (데스크탑) / 2 (태블릿) / 1 (모바일)
gap: 1px solid #E2E8F0 (구분선) 또는 24px 여백
각 셀: padding 24px 28px
```

**위계 (3단 구조):**

```
[라벨]      11px, uppercase, letter-spacing 0.08em, #64748B
[큰 숫자]   40~48px, font-weight 700, #0F172A, tabular-nums
[델타]      12px
