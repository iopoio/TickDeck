## PART A. 수집·검증 백본 (수렴·엄격 — 지키느냐 마느냐)

### A1. 소스 티어링 (3사 합의)
- **T1 (필수·단독 인용 가능)**: 정부/규제 공시, 통계청, SEC 10-K/실적, 특허 DB, peer-reviewed 학술.
- **T2 (2개+ 교차 시 확증)**: McKinsey·BCG·Gartner·Forrester·IDC·협회 백서.
- **T3 (현상 감지용·단독 수치 인용 금지)**: 언론·뉴스레터(1·2차 인용한 것만).
- **금지/FLAG**: 날짜 없는 인포그래픽·스폰서드 미표기·블라인드/Quora·AI 이미지 속 수치 → `UNRELIABLE`.

### A2. 수치 1개 인용 전 체크(3사 공통)
원문 PDF/HTML 직접 열람 · 발행연도·분기 · 지역 scope · 표본 N·방식 · 환율/단위 · 이해관계(COI). 하나라도 없으면 강등/삭제.

### A3. 교차검증 + 좀비/세탁 차단
- 수치 1개 = **2+ 독립 소스**(단 T1 원자료는 단독 OK). 차이 **±10~15%** 이상 = `DISCREPANCY` 플래그 + 조건(지역/표본/연도) 명시 후에만 병기.
- **좀비 수치**(출처 사라진 채 복제): 연도+정확한 보고서명 없으면 폐기. `current_year - publish_year > 3` & 테크 도메인 → 자동 zombie.
- **출처 세탁**: 언론 도메인인데 본문에 원본 링크(.gov/.pdf) 없으면 `circular_citation`. (Graph DB로 순환 인용 탐지)

### A4. CED/CEMS 데이터 구조 (수치-출처-한계 강결합)
모든 정보 단위 = **Claim · Evidence · Metric · Source · Limitation**. *Metric 비면 주장은 메인 배치 불가(서브 or 삭제).* Limitation 없으면 `UNAUDITED`.

### A5. 약한 데이터 자동 분류 — DWS 점수 → 라우팅
`DWS = Tier×0.4 + Recency×0.3 + Sample×0.2 + Method×0.1` (각 0~10)
- ≥8 정량 → **MAIN_EVIDENCE**(빅넘버) · 5~8 → **QUALITATIVE_SUPPORT**(불릿·박스) · <5 & 방향일관 → **DIRECTIONAL_SIGNAL**(수치 숨기고 증감 화살표만) · 그 외 → **삭제**.
- 도메인별 Data Decay(반감기): 테크 0.5/6mo · 소비 0.2 · 거시 0.05 → confidence 자동 감점.

### A6. 출처 표기 표준
`[기관, 《보고서명》, 연도, p.XX] · 조건: [지역/N/방식] · 태그: [1·2·3차/후원/투자의견]`. 약한 건 `(Est.)·(Proj.)·(Anecdotal)`.

## PART B. 분석 렌즈 라이브러리 (발산·풍부 — 주제마다 골라 겹쳐 쓰기)

> ⚠️ 여기는 압축하지 않는다(후추님). 리포트마다 2~4개 렌즈를 겹쳐 깊이를 만든다. 각 렌즈 = *실제 실행 방법*이 핵심. 풀버전·예시는 원본(01·02·03·r2_*)에.

### B1. 마찰 추적 (Follow the Friction · Qwen)
진짜 트렌드는 매끄럽게 도입되지 않는다 — 기득권·규제·노조·프라이버시와 *마찰*하는 지점이 변곡점.
- 실행: 산업 내 최근 1년 **소송·노조 파업·보이콧·규제 샌드박스 신청** 데이터 크롤링 → 마찰 최대 영역을 "가장 잠재력 큰 트렌드"로 역설계해 핵심 챕터에 배치.

### B2. Talent×Capital 괴리 (Qwen)
미디어는 '인기'를, 돈·인재는 '살아남을 것'을 말한다.
- 실행: `Media Hype Index`(언론 언급량) vs `Smart Money Index`(T1 VC 투자 + LinkedIn 핵심 인재 이동) 교차.
- `Hype > Capital` → **거품 경고** 섹션 / `Capital > Hype` → **숨은 알파** 섹션(리포트의 핵심 가치가 됨).

### B3. 네거티브 스페이스 (GLM)
"무엇이 뜨나"가 아니라 *무엇이 사라지나·안 거론되나*를 역추적해 미래를 본다.
- 실행: 최근 2년 T1 기업의 **실패·철수 사업** 크롤링 → 공통 원인 분석 → 예: "모두가 초개인화를 외칠 때, 콜드스타트 문제로 B2B SaaS 3社가 라인 폐기" 발견 → "초개인화의 역설: 하이브리드 회귀" 트렌드를 추가(구조적 한계 도출).

### B4. 증거 역검색 (Inversion · Kimi)
확증편향 차단 — 가설을 세운 뒤 *반대(NOT A)*를 먼저 검색.
- 실행: "생성형 AI가 개발자 생산성 40%↑" 가설 → `"AI coding productivity no improvement"`, `"developer productivity flat after copilot"`를 먼저 검색 → 반론 1건+ 발견 시 메인 클레임에 **병렬 배치** + "제한적 반론" 2줄 의무.

### B5. 반사실 슬롯 (Counterfactual · GLM·Kimi)
- 실행: 각 주요 챕터 *마지막*에 "이 트렌드가 2026까지 실패/지연된다면 결정적 원인은?" 3줄 이내 의무 삽입. AI가 만들기 쉬운 단방향 예측을 차단.

### B6. 언어간 시차 (Inter-Language Lag · Kimi)
- 실행: 영문 1차 베이스 + 한/일/중 보고서 1건+ 수집 → 글로벌 vs 로컬 어조의 **시차** 측정. 예: 글로벌은 "EV 전환 기정사실"인데 한국어 보고서는 "수소·하이브리드 논의 30%+" → 이 **틈새**가 전략 기회. 어조 20%p+ 차이면 `Regional Variance` 박스 생성.

### B7. 적대적 셀프리뷰 (3페르소나 · Kimi)
- 실행: 초안 완성 후 3인칭 자가 반박 — ① 15년차 임원("가장 허술한 근거 3개") ② 경쟁사 애널("thesis 뒤집는 반론 200자") ③ 학계 심사자("Methodology 약한 인용 색출"). **2명+ 같은 지적 = 해당 섹션 재작성 의무.**

### B8. TTA 역추산 / Historical Analog (Kimi·GLM)
- 실행: 과거 도입곡선 단순 매칭 금지. 현재 시점의 **투자·특허·채용** 데이터로 도입속도 v(t) 추정. 현재 v(t)가 과거 스마트폰 대비 2배면 TTA(도달시간)는 1/2로 — "동적 도입 모델"로 시나리오 작성.

### B9. Trigger Point (GLM)
리포트 = 읽을거리가 아닌 의사결정 도구.
- 실행: 각 트렌드 끝 부록에 "[지표]가 [수치] 도달 시 [부서/역할]이 [행동] 개시". 예: "CBAM 본격 과세 전환(2026 Q3 예상) 시, 공급망팀은 중국 2차 벤더 비중을 15% 축소."

### B10. Tombstone 섹션 (Qwen)
- 실행: 낙관 편향 차단 — 최근 2년 내 **실패한 유사 트렌드/기업**을 분석하는 섹션 의무화.

## PART C. 스토리·구성 + 안티패턴 (혼합)

### C1. 관통 명제(Thesis) — "A는 B를 C한다"
추상 제목 금지. "[거시변인]이 [기술/행동]과 결합해 [구조]를 [형태]로 재편한다." **So-What 3회**(누구 이익/손실·규모·타임라인) 통과 필수.

### C2. 챕터 프레임 (렌즈로 고르되 골격은 수렴)
`Tension(긴장·기존믿음 vs 현상) → Diagnosis(수량화) → Mechanism(왜·인과체인) → Scenarios(낙/기/비 + 트리거) → Convergence(전략 함의) → Action(30/60/90 or 오늘 할 3가지)`. 챕터별 데이터:내러티브 비율 명시(예 Opener 3:7, Diagnosis 8:2). 전환엔 논리 접속사 필수.

### C3. 데이터-내러티브 배치
**내러티브가 데이터를 리드.** 차트엔 *반드시 해석 1문장*("그림1 보면" 금지 → "X가 2.3배 → DTC 경제성 붕괴"). 강한 수치는 인트로/클로징.

### C4. 안티패턴 (REJECT 신호)
대칭 나열(장3 단3) 금지 → 비대칭 리스크 가중 · 버즈워드 샐러드 금지 · 주어 없는 문장("많은 기업") → "상위10중 7개(출처)" · 추상 액션("유연 대응") → 예산/조직/기한 중 하나 건드리기 · 클리셰 서두 금지 → 첫 문장은 최근 3개월 구체 사건/이례치 · **Ctrl+F 삭제어**: `landscape·paradigm shift·game changer·delve·tapestry·in today's world`.

## PART D. 우리 파이프라인 통합 (라운드2 — 자동화 코드)

우리 흐름 [디깅(신야 GLM/Qwen :online) → 풀 → 스토리 → tickdeck_ds 엔진]에 박을 것:

1. **디깅 에이전트 강제 스키마**: 검색 결과를 {url·tier·year·sample·region·COI·paywall_flag·zombie_flag·circular_citation}로 *구조화 반환*. 프롬프트 핵심 = "훈련 지식으로 빈칸 채우지 말 것·실제 방문 URL에서만·1차 방문 못 했으면 tier 강등".
2. **CED→슬라이드 JSON**: 모든 수치 블록에 source+limitation+confidence. 렌더 시 자동 강등/삭제(`value None or conf<0.6 → 삭제` / `conf<0.8 or tier∉{T1,T2} → 정성 fallback`).
3. **자동 검증 vs 사람(HITL) 경계**:
   - **AI 100%**: 크롤링·티어링·페이월/좀비/세탁 필터·수치 교차대조(Math-Verifier)·역검색(Devil's Advocate)·DWS 라우팅·렌더.
   - **사람만**: 어떤 Tension이 *전략적 울림*인지 타겟팅 · Limitation을 어떻게 *우아하게 프레이밍*해 신뢰 방어 · 최종 어조 튜닝.
4. **풀→스토리**: 풀 임베딩 DBSCAN 클러스터 → 방향 상충/기대-현실 괴리 노드 = `Tension_Point` → LLM Director가 챕터 프레임에 배치(required_data_ids로 슬라이드와 연결).
