# 냉정 외부 리뷰 종합 + v2 개선 플레이북 (2026-06-28)

> 후추님 지시: 내부(저자 클로드) 말고 외부에 냉정 리뷰 → 개선안까지.
> 리뷰어 4: **Qwen3.7·GLM-4.6·MiniMax-M3**(신야 격리 레인·중국) + **destroyer**(비저자 클로드).
> 평균 ~2.3/10. 4개가 강하게 수렴 — 내부 저자 리뷰가 못 잡았을 결함들.

## 메타 교훈 (가장 중요)
**변수는 모델 브랜드가 아니라 '저자 vs 비저자 + 잔혹 프레이밍'이다.** destroyer(비저자 클로드)가 중국 AI만큼, 어떤 면은 더 날카로웠다(명제 **반증 불가능** 지적은 중국 3사도 못 짚음). 신야의 값어치는 *더 잘함*이 아니라 *다른 사각지대*(다른 학습)+쌈. → 큰 산출물은 "됐다" 선언 전 **비저자 비평 1회**를 기본값으로(저자는 자기 걸 채점하지 않는다).

## 합의된 7대 결함 (타당도·sharpest 출처)
1. **명제 진부 + ⭐반증 불가능(destroyer)** — "AI 자동화 *안 해도* 차별화는 적합성으로 이동" → AI에 논리 의존 X·인과 없음·2022년에도 유효.
2. **지역 정합성 붕괴(전원 합의)** — 통계청(한국) + Deloitte EMEA(유럽 규제환경) + Statista(글로벌) 혼재. EMEA 신뢰 42%는 EU AI Act/GDPR 수치라 한국 대입 불가. MiniMax: 60% 커뮤니티는 Deloitte 미국 holiday survey·한국 소셜그래프(카카오/네이버)와 정반대.
3. **Deloitte 과의존 + ⭐이해충돌(destroyer)** — 단일펌 3회 반복. Deloitte는 MarTech 컨설팅 수익자 → "Deloitte가 MarTech 팔잖아요" 한마디면 18% 리프트 날아감. MarTech 18%=역인과(매출 큰 기업이 더 씀·MiniMax).
4. **자기모순 ROI** — 투자 85%·추가 91%인데 유의미 ROI 10% → CFO: "90% 낭비냐, 예산 깎겠다." 덱 자기 논리가 자기를 침.
5. **So-What 얕음 + ⭐3레버 본문 미정의(MiniMax)** — 전 챕터 현상 나열. "실행 3레버"가 표지 암시뿐 본문에 정의 없음 = 기획 누수.
6. **반대 증거 0** — Temu/Shein(속도·가격 승)·Spotify/Netflix(AI가 차별화)·코카콜라 AI(감정 결여 역풍)·ChatGPT 할루시네이션 3~27%·Z세대 신뢰(투명성>일관성) 전무.
7. **Ch2(니치 커뮤니티) vs Ch4(DOOH·GEO 거시) 전략 모순** — 우선순위·트레이드오프 답 없음.
- (부수) DOOH 36% 출처 한국지방재정공제회 = 공공 조달 통계 의심·범주 오류 가능(추적 불가 시 삭제).

## v2 개선 플레이북 (각 결함 best fix · Qwen·GLM·MiniMax 종합)
1. **명제 재정의** → "AI가 제작 한계를 0으로 만들면, 2026 마케팅은 무한 노이즈 중 **검증된 맥락(Contextual Truth)** 점유 전쟁이다" / "AI 에이전트가 대신 선택하는 시대, 마케팅은 인간이 아니라 **AI를 설득하는 최적화(AIO/GEO)**" / 신뢰 대상이 브랜드→모델로 이동(quotability).
2. **한국 1차 앵커** → 통계청 + KOCCA + NIA + 과기정통부 'AI 산업동향' + OpenSurvey 'AI 소비자 인사이트'로 교체. Deloitte EMEA는 "글로벌 선행지표"로 1회만. 한국 덱/글로벌 덱 둘 중 하나로 결정하고 섞지 않는다.
3. **삼각측량** → Gartner Hype Cycle(시기) + McKinsey State of AI(효율) + eMarketer(예산규모). 슬라이드 하단에 각 출처 역할 명기. Statista 2차 인용 삭제.
4. **ROI 10% → 무기화(J-Curve)** → "10%는 AI를 *대체재*로 쓴 자동화 단계의 한계. 2026 예산을 AI *수익엔진(GEO/AIO)*으로 이관하면 J-Curve." CFO 액션: "자동화 예산 15% 삭감 → 생성형 발견 최적화로 재배치."
5. **3레버 정의 + So-What 박스** → ①맥락 적합성 ②제로파티 신뢰 ③생성형 발견(GEO). 모든 챕터 말미 `[데이터 현상] → CMO/CFO 딜레마 → [3레버 액션]` 박스 강제 + 자사 진단 체크리스트.
6. **Red Flag 반례 페이지** → 코카콜라 AI 광고(감정 결여)·Temu/Shein(가격·속도 승)·할루시네이션·Z세대 신뢰. "신뢰가 해자 아닌 경우: 가격민감·impulse·신규시장" 섹션.
7. **Micro-Macro Loop** → 니치 커뮤니티=제로파티 데이터 확보·검증 단계 / 거시(DOOH·GEO)=검증된 맥락 증폭 단계. "니치서 검증 안 된 메시지는 거시 집행 안 함" 원칙.

## 우선순위 (먼저 고칠 것)
1순위 = ②지역 앵커(한국 1차) + ③삼각측량 (출처 신뢰가 전부 무너지면 나머지 무의미)
2순위 = ④ROI 무기화 + ⑤3레버 정의 (자기모순·결론 공백이 발표를 멈춤)
3순위 = ①명제 + ⑥반례 + ⑦루프 (날카로움·균형)
