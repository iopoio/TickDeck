## 후보 C와 출력 불변

- viz 선택 문자열 필드 `exhibit`·`title`·`subtitle`을 스키마에 선언했다. `title`은 기존 필드다.
- 세 값이 모두 있을 때만 눈썹 → 결론문 → 측정치+단위 3층을 렌더한다.
- 하나라도 없으면 기존 렌더 분기를 그대로 쓴다.
- 기준 커밋 렌더러와 수정 렌더러를 45개 실덱에 같은 입력으로 직접 호출해 비교했다.
  - HTML 생성 가능 41덱: 41개 바이트 동일 / 변경 0개
  - 기존부터 렌더 불가 4덱: 변경 전후 오류 종류·메시지 동일 / 차이 0개
- 3층 viz는 기존 높이 보정값을 재사용하지 않도록 `title_layers=3` 서명으로 분리했다. 측정값이 없으면 `RENDER_MEASURE_REQUIRED`로 닫힌다.
- 무필드 출력 바이트 불변을 확인한 뒤 calibration의 renderer 구조 해시만 현재 코드 계산값으로 재봉인했다.
